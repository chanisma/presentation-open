# prompt-log — 수업 자료의 프롬프트를 그 자료 폴더에 남긴다

> **로딩 시점**: 덱·활동지·quiz.json을 **만들거나 고치는 작업을 끝내기 직전**.
> 사용자가 그 자료를 위해 입력한 프롬프트를 자료 폴더의 `prompts.md`에 덧붙인다.

## 왜

수업 자료는 한 번 만들고 끝나지 않는다. 다음 학기에 같은 수업을 다시 열 때, 다른 과목에
비슷한 자료를 만들 때, 무엇을 어떻게 요청했는지가 필요하다. 그런데 그 기록은 세션
jsonl에만 남고, 세션 파일은 지워진다. 2학기 4개 수업의 프롬프트를 세션에서 복구한 것이
2026-08-23인데, 세션이 하나라도 없었으면 복구가 안 됐다.

## 파일

```
data/<그룹>/<과목>/<수업>/prompts.md
```

자료 폴더당 하나. `plan.md`·`deck.tsx`·`quiz.json`·`활동지.html` 옆.

## 형식

```markdown
# <과목> · <수업> · 프롬프트 기록

> 이 수업을 만들고 고칠 때 사용자가 실제로 입력한 프롬프트. 시간순.

## 2026-08-09 13:49 · 최초 요청 · /lesson-deck-planner
> 세션 8954975d

(프롬프트 전문 — 한 글자도 고치지 않는다)

첨부 이미지: 8954975d · #2, 8954975d · #3

## 2026-08-10 14:09 · 수정 요청
> 세션 8954975d

인공지능 기초에서 3, 4, 5페이지는 삭제해줘
```

항목 하나 = 사용자 발화 하나. 머리글은 `시각 · 종류 [· 스킬]`, 그 아래 세션 id 인용, 본문은
**전문 그대로**. 요약하지 않는다 — 요약하는 순간 재현이 안 된다.

### 무엇을 남기는가

| 남긴다 | 남기지 않는다 |
|---|---|
| 자료를 만들라는 요청 (긴 조사 내용을 붙여 넣은 것도 **전문**) | 슬래시 명령 (`/model`, `/clear`, `/login`) |
| 내용·구성·디자인을 바꾸라는 지시 | 스킬 본문 로딩, bash 입출력, task-notification |
| "진행", "고치고 검증 진행" 같은 **승인 발화** | 배포 URL·시트 ID·토큰 같은 설정값 (이건 `.classroom.json` 등이 맡는다) |
| 첨부 이미지 — 세션 id와 순번만 | 이미지 파일 자체 (base64 복원은 하지 않는다) |
| 같은 세션의 저장소 작업이라도 **이 자료에 영향을 준 것** | 이 자료와 무관한 저장소 작업 (허브·콘솔·스킬 개선) |

### 종류

- `최초 요청` — 그 자료를 처음 만들라는 발화. 스킬로 들어왔으면 `· /스킬명`
- `수정 요청` — 그 뒤의 모든 변경 지시
- 승인 발화("진행")도 `수정 요청`으로 둔다. 분류를 더 잘게 나누지 않는다

## 절차 — 스킬이 끝내기 직전에

1. 이번 작업에서 사용자가 이 자료를 위해 입력한 발화를 시간순으로 모은다
2. `prompts.md`가 없으면 머리글과 함께 만들고, 있으면 끝에 덧붙인다
3. 첨부 이미지가 있었으면 현재 세션 id와 순번을 적는다 (세션 id는 `~/.claude/projects/D--presentation/`의 jsonl 파일명 앞 8자)
4. 전문 그대로 넣었는지 확인한다 — `<command-args>` 안의 내용은 태그를 벗기고 본문만

이 절차는 `lesson-deck-planner` · `lesson-script-planner` · `pd-scene` · `react-deck-builder` ·
`notebooklm-lesson-deck` · `composite-deck-builder` · `activity-sheet-builder` · `live-quiz-builder` ·
`live-upgrade`의 마지막 단계에 붙어 있다. 그 외 경로로 자료를 고쳤을 때도 같은 규칙이다.

## 과거 자료 복구

세션 jsonl이 남아 있으면 복구할 수 있다. 2026-08-23에 2학기 4개 수업을 복구한 스크립트의
핵심은 **세션 + 시각 구간 → 수업** 매핑이다. 자료의 `deck.tsx` 최초 커밋 시각(`git log
--diff-filter=A`)과 세션 파일의 수정 시각을 맞춰 구간을 정하고, 그 구간의 사용자 발화를
뽑은 뒤 무관한 것을 제외 목록으로 걸렀다. 같은 방법으로 1학기 자료도 복구할 수 있다.
