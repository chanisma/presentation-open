# Scene Grammar (슬라이드덱판) — 장면 조립 수칙

> newVideoGen `.claude/rules/scene-grammar.md` v2.x를 이 저장소 매체(bolt
> 슬라이드덱: 클릭 빌드 + t 타임라인 + 브라우저 렌더)로 변형한 룰셋.
> **로딩 시점**: dynamic-scene-builder / react-deck-builder의 씬(scene form)
> 저작 시작 시 명시적으로 Read.

## 한 페이지 요약 (5문장)

1. **품질이 안 오를 때 규칙을 더 추가하지 마라 — 표현 층을 해방하고 결과물만 검증하라.**
2. **씬 본문은 자유 TSX가 기본값.** 씬 템플릿·공통 표현 컴포넌트·패턴 카탈로그는 DSL 재발명이며 단조 회귀의 직접 원인이다.
3. **씬 1장당 고유 시각 메타포** — 같은 구도가 3장 이상 반복되면 즉시 멈추고 메타포를 재발명한다.
4. **"AI가 못한다"는 대부분 "발휘할 무대가 좁다"이다.** 룰 추가 충동이 들면 표현 층을 여는 방법부터 고민.
5. **코드 통과 ≠ 픽셀 통과.** 매 씬 스크린샷 검수를 빠뜨리지 마라 (tsc·스모크는 레이아웃 붕괴를 못 본다).

## 🚨 Lazy Defaults — 자동으로 손 뻗는 본능에 이름표 (씬 시작 전 30초)

아래로 자동으로 손이 가면 멈춘다. 답이 하나라도 "그렇다"면 메타포부터 재설계.

- **색**: ❌ 순수 `#000`/`#fff` 직접 사용, Tailwind 팔레트 그대로 → ✅ `tokens.css` 변수(`var(--bg)`, `var(--primary)`, `color-mix`) 또는 registry theme
- **레이아웃**: ❌ 균등 카드 그리드 나열 · 모든 요소 중앙정렬 · 단순 상→하 스택 · 풀스크린 그라데이션 → ✅ 비대칭: dominant 1개 + 작은 secondaries
- **타이포**: ❌ 일률 font-weight · display/body 동일 취급 → ✅ 헤딩 800+ / 본문 400~500 (base.css 클래스 활용)
- **장식**: ❌ 의미 없는 이모지·글로우·파티클 뿌리기, 가짜 수치(99%, 10x) → ✅ 의미 있는 flourish 단 1개, 수업 내용의 실제 수치만
- **에셋**: ❌ figural을 inline path로 직접 그리기 → ✅ `assets/manifest.json` 검색 → 재사용(SVG는 `reusable: true`만, 덱 디자인에 맞게 판단·변형) → 없으면 생성(인물·생물은 image-asset-builder 크롭이 1순위, 그 외 사물·소품은 svg-asset-builder)

## 표현 층 해방 — 매 씬 고유 메타포 (ABSOLUTE)

### 금지 — DSL 재발명 패턴

1. ❌ 씬 N개용 "구도 카탈로그" 사전 설계 (좌hero/중앙mega/split/그리드 6종 = 새 DSL)
2. ❌ 재사용 씬 컴포넌트(Kicker→Hero→Subline 4단 구조 반복) — 5장째에 시청자가 패턴을 인식한다
3. ❌ `templates[idx % N]` 식 모듈로 반복 생성
4. ❌ **figural SVG를 inline path로 직접 저작** — 예외 경로는 두 갈래뿐:
   ① **인물·생물·비례가 있는 사물** → `image-asset-builder`로 생성 이미지 크롭 (원+캡슐+선의 "졸라맨"은 newVideoGen에서 영상 점수 20점을 깎은 실패다 — scene-grammar §17)
   ② 그 외(사물·기계·도구·소품) → svg-asset-builder (`clean-hand-illustration` · 면 계획 + PNG 자가 검수 + manifest 등록·contexts 기록, 덱당 ≤5). 순수 추상 도형(퍼즐 조각·화살표)은 인라인 경로로 그려도 된다
5. ❌ edge-cling — 요소를 좌우 가장자리에만 배치하고 가로축 중앙 40~60%가 공백. dominant 요소나 메타포 연결선이 중앙을 통과해야 한다
6. ❌ 외부 CDN 아이콘 직접 호출 — 사전 다운로드·manifest 등록 자산만

### 원칙 — 씬당 워크플로우

```
1. 핵심 메시지 읽기 → 2. 감정 추출 → 3. 메타포 발명 (직전 씬들과 다르게)
→ 4. JSX 자유 설계 → 5. 코드 (매 씬 처음부터) → 6. 스크린샷 검수
```

자가 검증: "이 씬을 직전 씬들과 *시각적으로* 어떻게 다르게 만들 것인가?"
— 답이 "텍스트만 다르고 구도 같음"이면 멈추고 재발명.

메타포 어휘 예시: 궤도/게이지/심전도/타자기/영수증/시계 dial/분기 트리/
별자리/트랙·결승선/카드 슬롯/여정 지도/저울/컨베이어 벨트 (씬마다 다르게)

## 레이아웃 계약 — 겹침·가림 4대 원인 사전 차단

(newVideoGen 반복 사고의 이식 — 좌표 눈대중 대신 처음부터 계약)

- **(a) zone 분리**: 텍스트 밴드와 그래픽 밴드를 좌표로 분리. 그래픽 dominant가 텍스트 bbox를 침범 금지.
- **(b) z-order**: 텍스트는 항상 장식 위 — JSX 후순위 자식 또는 명시적 zIndex. 라벨은 도형 bbox 바깥에.
- **(c) 헤드라인 가변 높이**: `.headline`/`.display`는 max-width 때문에 절대배치에서 좌측 쏠림·줄바꿈이 난다 — **`marginInline: 'auto'` + `wordBreak: 'keep-all'` 필수**, 아래 요소는 고정 y 대신 충분한 간격.
- **(d) 선/화살표 앵커**: 선은 도형 중심이 아니라 가장자리에서 시작·종료. 화살표 머리는 실제 방향 벡터로 회전(`Math.atan2(y2-y1, x2-x1)`).
- **(e) 다크 배경 가시성**: 다크 배경에서 안 보이는 에셋 = 없는 에셋. 삽입 전 대비 확인.

## 결정론 (t-purity)

씬의 모든 모션은 `useSceneTime()` t(초)의 순수 함수 — 같은 t, 같은 화면.
`Date.now()`·`Math.random()` 금지. 클릭 상태(`<Build>`)와 t는 직교 — 섞어
쓰되 서로를 참조하지 않는다. 썸네일(isStatic)에서는 freeze 상태로 안전해야
한다.
