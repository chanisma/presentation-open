# 프롬프트 뼈대 — 갈래마다 관점을 좁혀야 검증이 날카로워진다

각 프롬프트는 파일로 저장해 `"$(cat p1.txt)"`로 넘긴다. 셸 따옴표 지옥을 피하려면
프롬프트에 큰따옴표를 쓰지 말고 홑따옴표나 「」를 쓴다.

공통 꼬리말을 모든 프롬프트에 붙인다.

```
출력은 한국어 마크다운으로. 칭찬은 최소한으로 하고 결함 위주로 써라.
문제가 없으면 없다고 쓰고 억지로 만들지 마라. 파일을 절대 수정하지 마라.
```

## ① 사실 검증 (웹 검색 필수)

```
너는 고등학교 수업 자료를 검증하는 엄격한 팩트체커다. <stdin>에 붙은 텍스트는 실제
수업에서 학생에게 보여 줄 슬라이드 전체와 활동지, 실시간 문항의 문구다.

과제: 이 자료에 담긴 모든 사실 주장(수치·금액·연도·비율·기업명·기관명·사건)을 빠짐없이
뽑아 하나씩 검증하라. 웹 검색을 쓸 수 있으면 반드시 사용하고, 검색이 불가능하면 그
사실을 결과 맨 위에 명시하라.

특히 다음 항목은 반드시 개별 확인하라.
1. <자료에 등장하는 수치를 번호로 하나씩 나열한다 — 이 목록이 검증의 밀도를 정한다>
…

출력 표 형식:
| 번호 | 슬라이드 | 주장(원문 인용) | 판정 | 근거·출처 | 고칠 문구 제안 |

판정은 다섯 중 하나만: 확인됨 / 부분적으로 맞음 / 틀림 / 과장 / 검증 불가.
표 아래에 '즉시 고쳐야 할 것'과 '교사가 수업 전에 직접 확인해야 할 것'을 목록으로 나눠라.
사소한 표현 문제는 다루지 말고 사실관계에만 집중하라.
```

**포인트** — 번호 목록을 주지 않으면 훑고 만다. 자료의 수치를 미리 세어 그대로 나열한다.

## ② 교육 설계 적대 검토

```
너는 이 수업을 심사하는 까다로운 동료 교사다. <stdin>은 <과목·차시> 수업 자료 전문이다.
수업 목표는 <한 문장>이다.

과제: 이 수업을 실패시킬 수 있는 지점을 찾아 공격하라.

반드시 다루어야 할 관점.
1. 시간 배분 — 실제로 들어가는가. 어디서 무너지는가.
2. 개념 분류의 논리적 결함 — 겹치거나 빠지는 영역, 사례 판정이 실제로 맞는지.
3. 문항의 타당성 — 정답 판정에 반론이 가능한가.
4. 학생이 막힐 지점 — 어느 단계에서 실제로 손이 멈추는가.
5. 지시의 모호함 — 두 가지로 해석되는 문장을 원문 인용해 지적하라.
6. 교사가 개입하지 않으면 결과물이 어떻게 망가지는가 (실패 시나리오 3개).
7. 학생 눈높이에서 어려운 개념·어휘.

지적마다 (원문 인용) → (무엇이 문제인가) → (구체적 수정안) 세 줄 구조를 지켜라.
마지막에 '치명적 3가지'를 골라 우선순위를 매겨라.
```

## ③ 일관성·편집 잔재

```
너는 수업 자료의 일관성을 검사하는 교정자다. <stdin>은 슬라이드·활동지·문항의 전체
문구다. 이 자료는 여러 차례 수정을 거쳤기 때문에 이전 판의 흔적이 남아 있을 수 있다.

과제:
1. 모순 — 슬라이드끼리, 슬라이드와 활동지·문항 사이에 어긋나는 서술(용어·숫자·절차·
   단계 이름·소요 시간).
2. 편집 잔재 — 지금은 없어진 기능이나 활동을 여전히 가리키는 문구.
   참고로 다음은 이미 삭제된 것들이다: <삭제한 기능을 빠짐없이 나열한다>
3. 끊긴 참조 — '앞에서 본', '1단계에서'처럼 가리키는 대상이 없거나 어긋난 경우.
4. 학생이 오해할 표현 — 지시문이 실제 화면 구성과 다르게 읽히는 곳.
5. 한국어 문장 오류 — 비문, 조사 오류, 번역투, 용어 불일치.
6. 입력칸과 지시문의 불일치.

출력 표: | 위치 | 원문 인용 | 문제 유형 | 무엇이 어긋났나 | 고칠 문구 |
```

**포인트** — 2번의 '삭제한 것 목록'이 이 갈래의 성패를 가른다. 무엇을 지웠는지 알려
주지 않으면 잔재를 못 찾는다.

## ④ 용어·비유 검토

```
너는 고등학교 수업 자료의 용어를 검토하는 교과 전문 검수자다. <stdin>은 <과목> 수업
자료 전문이다. 문구가 그대로 슬라이드 화면 텍스트와 발표자 노트가 된다.

배경: 이 수업 자료는 비유로 개념을 여는 전통이 있고, 비유 자체는 결함이 아니다.
문제는 두 가지다.
(1) 정확한 용어가 있어야 할 자리(화면의 라벨·정의 문장·활동지 칸 이름·문항 선지)에
    비유어가 대신 앉는 경우 — 학생이 수업 밖에서도 통하는 어휘를 배우지 못한다.
(2) 한국어에서 통용되지 않거나 다른 뜻으로 통용되는 표현 — 오히려 오해를 만든다.

과제: 자료의 모든 비유어·신조어를 뽑아 하나씩 판정하라. 특히 다음은 개별 검토하라.
1. <자료의 비유어를 미리 뽑아 「비유어」(가리키는 개념, 등장 위치) 형태로 나열한다
   — 한국어 관용 의미와 충돌할 만한 것은 그 관용 의미까지 적어 준다>
…

판정은 셋 중 하나만:
- 유지 — 비유가 도입·해설에만 쓰이고, 정식 용어가 라벨·정의 문장에 병기되어 있다
- 병기 필요 — 비유는 유효하나 정식 용어가 화면 어디에도 없다. 병기 위치를 제안하라
- 교체 필요 — 비유가 정확한 용어의 자리를 차지했거나 한국어 관용 의미와 충돌한다.
  대체 표현을 제안하라

추가 과제: 이 수업을 마친 학생이 알아야 할 정식 용어 목록을 만들고, 자료가 각 용어를
화면 텍스트에서 실제로 정의·사용하는지 대조하라.

출력 표: | 비유어 | 등장 위치 | 가리키는 개념 | 판정 | 근거(한국어 관용 의미 포함) | 제안 |
표 아래에 '정식 용어 대조표': | 정식 용어 | 화면에 등장하는가 | 어디서 | 보완 제안 |
```

**포인트** — 비유어 목록을 미리 뽑아 주지 않으면 훑고 만다. 판정을 셋으로 고정해야
"비유를 다 빼라" 식의 과잉 교정을 막는다. 이 갈래는 2026-08-26 사용자 지적(통용되지
않는 비유·정확한 용어 자리의 비유가 학생을 헷갈리게 한다)에서 나왔다.

## ⑤ 눈높이(ELI5) 검토

```
너는 <학년/과목> 학생의 입장에서 수업 자료를 읽는 검수자다. <stdin>은 수업 자료
전문이고, 화면 텍스트와 발표자 노트가 모두 들어 있다.

배경: 이 자료는 ELI5 원칙으로 쓰였다. 원칙은 일곱 가지다.
(1) 장마다 ① 무엇인가 ② 이미 아는 것에 잇는 비유 ③ 세부 ④ 그래서 나에게 무슨
    의미인가(so what) 순서 (2) 새 용어는 나오는 즉시 한 문장 풀이 (3) 비유는 학생의
    생활에서 가져오되 정식 용어를 대체하지 않음 (4) 한 문장에 생각 하나, "여러분"
    주어 (5) 목적을 먼저, 원리는 그 뒤 (6) 단순화한 자리에 "실제로는 …" 한 줄
    (7) 한 장에 새 용어 셋 이하.

과제: 원칙을 지키지 못한 곳을 **장 번호와 함께** 전부 찾아라. 특히 다음을 하나씩
판정하라.
1. 풀이 없이 지나간 용어 — 그 용어가 처음 나온 장과, 풀이가 있는지
2. 새 용어가 넷 이상인 장
3. 비유가 없는 장, 또는 앞 장의 비유와 겹치는 장
4. so what(학생에게 무슨 의미인지)이 없는 노트
5. 한 문장에 생각이 둘 이상 들어간 문장 — 원문을 인용하고 끊어 쓴 안을 제시
6. 단순화했는데 "실제로는 …"이 없는 설명 — 무엇이 실제와 다른지 함께 적어라
7. 어린애 취급하는 어조, 또는 반대로 학생이 모를 전제를 깔고 지나간 곳

각 지적에 대해 판정은 셋 중 하나만:
- 통과 — 원칙대로다
- 보완 — 한 문장을 더하면 해결된다. 그 문장을 써라
- 다시 — 설명 순서 자체가 뒤집혔다. 어떤 순서로 바꿔야 하는지 적어라

마지막에 "이 자료를 읽은 학생이 수업 뒤 설명할 수 있게 되는 것"과 "여전히 막힐
것"을 각각 세 줄로 요약하라.

출력 표: | 장 | 원칙 | 문제가 된 문장/용어 | 판정 | 제안 |
```

**포인트** — 검증자를 "학생 입장"에 세우는 것이 핵심이다. 전문가 입장으로 두면
"더 정확히 쓰라"는 반대 방향의 지적이 돌아온다. 원칙 일곱 가지를 번호로 주고
장 번호를 요구해야 훑지 않는다. 이 갈래는 2026-09-16 사용자 결정(ELI5를 공식
설명 방식으로 채택)에서 나왔다. 원칙 원문은 `.claude/skills/eli5/SKILL.md`.

## ⑥ 씬 연출 심사 (이미지 첨부)

```
너는 수업용 슬라이드덱의 장면 연출을 심사하는 까다로운 아트 디렉터다. 첨부한 N장은
동적 씬 M개를 시간·클릭 순서대로 캡처한 것이다. 파일명이 곧 순서다.

- s02-* : 슬라이드 2 「제목」 — <이 장면이 무엇을 보여 주려 하는지 한 줄>. 진입 → 클릭1 → …
- …

채점 기준(각 씬마다 판정):
1. 메타포의 전달력 — 나레이션 없이 3초 안에 읽히는가. 아니라면 무엇이 방해하는가.
2. 씬마다 고유한 메타포 — 두 씬 이상이 같은 구도로 수렴하지 않는가.
3. 레이아웃 계약 — (a) 텍스트와 그래픽 존 분리 (b) 라벨이 도형에 묻히지 않는가
   (c) 헤드라인 줄바꿈 (d) 선·화살표가 도형 가장자리에서 시작·종료하는가
   (e) 어두운 배경에서 실제로 보이는가.
4. Lazy Defaults — 균등 그리드 나열, 중앙정렬 일색, 상→하 스택, 의미 없는 장식,
   가로축 중앙이 비고 양 끝에만 요소가 붙는 edge-cling.
5. 여백과 균형 — 비어 보이는가 과밀한가. dominant 하나가 분명한가.
6. 모션의 필연성 — 프레임 사이 변화가 의미를 만드는가. 클릭 단계 구분이 필요한가.
7. 정지 화면 문제 — 마지막 프레임에 이야기의 두 축이 함께 남아 있는가.

씬마다 형식:
### 슬라이드 N — 한 줄 총평 (10점 만점 점수)
- 읽히는가:
- 문제점: (프레임 파일명) → (무엇이 잘못됐는지) → (구체적 수정안)

마지막에 '씬 사이의 다양성' 평가와 '고칠 것 우선순위 5개'를 정리하라.
```

## ⑦ 학생·접근성 관점 (이미지 첨부)

```
너는 이 수업을 처음 보는 고등학교 2학년 학생이다. 동시에 색각 이상·저시력 학생과
교실 뒷자리에서 보는 학생까지 고려해야 하는 접근성 검토자다. 첨부한 N장은 …

1. 오해 — 그림을 보고 잘못 이해할 수 있는 지점(화살표 방향, 색의 의미, 숫자의 단위,
   무엇이 원인이고 결과인지).
2. 가독성 — 교실 뒤에서 볼 때 너무 작은 글자, 대비 부족, 촘촘한 정보.
3. 색 의존 — 색으로만 구분되고 모양·라벨로는 구분되지 않는 정보.
4. 정보량 — 한 장면이 요구하는 이해의 양. 잘라야 할 것.
5. 흥미 — 지루하거나 뻔한 장면과 그 이유.

지적마다 (프레임 파일명) → (어떻게 오해하거나 못 읽는가) → (수정안).
마지막에 '학생에게 가장 위험한 오해 3가지'를 뽑아라.
```

**포인트** — 이 갈래가 잡은 대표 사례: *"AI가 예측한 구조 2억 건을 모두 실험으로 확인된
사실로 오해한다"* — 신뢰도가 다른 두 데이터를 같은 모양으로 그렸기 때문. 연출 심사는
이걸 못 잡았다. **두 갈래를 모두 돌려야 하는 이유다.**
