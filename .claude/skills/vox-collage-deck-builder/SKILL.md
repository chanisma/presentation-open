# Vox Collage Deck Builder — 넓은 종이 세계 + 카메라 여행

> **한 줄 정의**: 한 화면에 다 안 들어가는 **관계**를 다룰 때 쓴다. 프레임(1920×1080)보다
> 넓은 종이 위에 오려 붙인 조각을 펼쳐 놓고, 조각은 각자 표류하며, 카메라가 그 위를
> 팬·줌으로 여행한다. 관계는 흐르는 쐐기·점선 궤적·스캔원 같은 모션그래픽이 그린다.

- **매체**: 네이티브 React 덱 전용 (`form: collage` 슬라이드).
- **정체성**: *세계가 넓고 카메라가 움직인다.* diorama(무대 정지 + 배우 연기)와 정반대다.
  화면에 다 들어오는 내용이면 이 스킬을 쓰지 마라 — 카메라만 움직이는 빈 여행이 된다.
- **오디오 없음**: 영상판의 SFX·BGM은 이식하지 않았다. 등장 스냅과 종이 파편 버스트
  (`EntryBurst`)가 그 강조를 대신한다.

## 비주얼 헌장 (요약 — 상세는 references)

**hand-cut editorial collage** — 잡지·색종이에서 가위로 오려낸 뒤 종이 위에 다시 붙인 듯.
매트한 종이 결, 살짝 비뚠 가위 자국, 조각 둘레의 얇은 오프화이트 **종이 테두리**,
부드러운 물성 그림자. 매끈한 3D 렌더·플랫 벡터·세피아 빈티지는 금지.

팔레트 8색 고정: `#26456e` 네이비 · `#e8b02a` 머스터드 · `#c85a26` 번트오렌지 ·
`#e0554a` 코랄 · `#2f5d3f` 딥그린 · `#1a1a18` 잉크 · `#e3d7c3` 웜베이지 · `#f3ece0` 오프화이트.
한 슬라이드에 주요 색 3~5개까지.

인물은 **한국·동아시아 성인 6등신**, 얼굴은 최소한의 눈·입만 — 감정은 자세가 전달한다.
치비·아동·서양 이목구비 금지.

## 러닝타임 — `src/vox` (import: `../../../../src/vox`)

좌표는 **월드 px**. 화면(프레임)은 1920×1080이고 월드는 그보다 넓다(가로 2600~3600 권장).

| export | 역할 |
|---|---|
| `useCam(keys, world)` | 카메라 키프레임 보간 + 월드 경계 클램프 (`mx = w/2 − 960/s`) |
| `<Collage world cam bg grain>` | 종이 세계 + 카메라 + 종이 결 그레인(0.06~0.14) |
| `<Cutout src x y w at entry drift depth dim rot flip z fx>` | 조각. entry: pop/slide/tear/drop, drift는 **필수**, depth로 패럴랙스 |
| `<EntryBurst>` | 등장 순간 색종이 파편 (Cutout이 자동 발화, `fx={false}`로 끔) |
| `<ArrowFlow from to>` | 쐐기가 경로를 계속 흘러간다 — 방향·전이 |
| `<DashTrail points>` | 점선 궤적 + 선두 점 왕복 — 여정·추적 |
| `<CircleScan x y r>` | 회전 조준원 + 십자 — 대상 지목 |
| `<PulseDot>` · `<RadialBurst>` · `<Strike>` · `<InkCircle>` | 주목·확산·부정·단발 주석 |
| `<AnchorBox x y w h label labelSide>` | 모서리 브래킷 + 라벨칩 — 대상에 이름 붙이기 |
| `<Tag x y size bg rot>` | 월드에 붙는 타이포 — 나레이션의 핵심 단어를 화면에 박는다 |
| `VOX` · `VOX_HUES` | 팔레트 토큰 · 색 순환 |

## `src/vox`를 쓰지 않고 vox를 흉내 낼 때 (실제로 밟은 함정)

덱이 자체 `Fit` 박스(1920×1080 설계 박스를 통째로 `scale`)를 쓰고 있으면 `src/vox`를 그대로
import하기 어렵다 — vox는 `vh` 기준이라 **이중 스케일**이 된다. 그래서 겉모습만 손으로
재현하게 되는데, 이때 vox가 대신해 주던 다섯 가지가 조용히 빠진다. 정보과제연구
「데이터의 가치와 활용」 S2에서 다섯 개가 전부 발생했다(2026-08-24 확인).

| vox가 하던 일 | 손으로 재현하면 | 증상 |
|---|---|---|
| 글자 크기 `(size/1080)*100vh` — **세계에 붙은 물체** | `fontSize: 26` 같은 화면 px | 1920 캔버스에서 9~13pt급으로 작아진다 |
| `Collage` 컨테이너가 **자식 전부**에 `scale(cam.s)` | `<img>`에만 `scale` | 배경만 1.3~1.7배, 글자는 1배 → 상대적으로 더 작아 보인다 |
| `useCam`의 월드 경계 클램프 `mx = w/2 − 960/s` | 배율·좌표를 직접 계산 | 프레임 가장자리에 빈 배경이 드러난다 |
| `useSceneTime()` t의 순수 함수 | CSS `transition: transform 2.4s` | t-purity 위반 — 썸네일·캡처가 전이 중간에 걸린다 |
| `Cutout`의 `drift`·`depth`·`EntryBurst` | 배경 이미지 한 장 | 조각도 표류도 패럴랙스도 없다 → 사실상 KenBurns + 자막 |

### 글자 크기 — vox의 `size`를 px로 그대로 옮긴다

`Fit` 박스 안에서는 `vh`를 쓰지 말고(이중 스케일), **vox의 `size` 값을 설계 박스 px로 그대로**
적는다. 설계 박스가 1920×1080이므로 숫자가 곧 같은 뜻이 된다.

```
Tag 본문 기본  size 44  →  fontSize: 44   (헤드라인 62px 옆에서 이게 정상 비례다)
AnchorBox 라벨 size 30  →  fontSize: 30
보조·출처 한 줄        →  fontSize: 20~24
```

웹 감각으로 고른 `16`·`18`·`26`은 **1200~1280 레이아웃 시절 값**이다. 1920 박스에서는 절반이다.
`base.css`의 `.kicker`(`clamp(12px, 1.1vw, 15px)`)·`.headline`(`clamp(32px, 5.2vw, 62px)`)도
상한에 걸려 멈추므로, 박스 안에서는 **클래스에 기대지 말고 크기를 명시**한다.

### 왜 vox 페이지에서만 티가 나는가

다른 페이지는 글자가 카드·패널 안에 있어 눈이 글자를 **상자 크기**와 견준다. 12px도 그에 맞는
작은 카드 안이면 어색하지 않다. vox 페이지에는 컨테이너가 없고 비교 대상이 **화면 전체**라,
같은 절대 크기가 갑자기 작아 보인다. 여기에 배경만 확대되는 효과가 겹친다.

### 덱 컨셉을 지키면서 vox 역학만 가져오는 법 (권장 경로)

팔레트를 vox 종이색으로 갈면 덱 전체 컨셉이 깨진다. **역학과 양식은 분리해서 가져온다.**

| 가져온다 (역학) | 두고 온다 (양식) |
|---|---|
| 월드 > 프레임, 카메라 여행, 경계 클램프 | 종이 팔레트 8색 |
| `Collage` 단일 변환 컨테이너 — 글자·그래픽이 함께 탄다 | 종이 결 `grain` (`grain={0}`) |
| `ArrowFlow`·`DashTrail`·`AnchorBox`·`PulseDot` 관계 어휘 | 찢긴 종이 가장자리·종이 그림자 |
| 월드 좌표 타이포 | |

`Collage`에 `bg="var(--bg)"` · `grain={0}`을 주면 덱 배경색 위에서 vox 역학만 돈다.
모션그래픽 색은 `VOX_HUES` 대신 덱의 액센트 토큰을 넘긴다.

**배경 일러스트 한 장을 그대로 세계로 쓴다.** 조각 에셋이 없을 때 가장 빠른 길이다 —
풀블리드 일러스트(1920×1080)를 월드(예: 2880×1620 = 1.5배)에 `objectFit: cover`로 깔면
① 세계가 빈틈없이 차서 **빈 배경이 드러날 수 없고** ② 카메라가 그림 위를 여행하며
③ 그림 안의 서사(왼쪽 사람 → 가운데 서버 → 오른쪽 금화)가 곧 스테이션이 된다.
조각의 `drift`·패럴랙스는 포기하지만, 관계 어휘와 카메라는 온전히 살아난다.

**스테이션마다 보이는 사각형을 먼저 계산하고 그 안에만 요소를 둔다.** 이걸 안 하면
월드 좌표에 잘 적어 놓고도 화면 밖이라 안 보인다(실제로 한 번 밟았다).

```js
// 월드 W×H, 카메라 (cx, cy, s) 일 때 보이는 사각형
mx = max(0, W/2 - 960/s);  my = max(0, H/2 - 540/s)      // 클램프 여유
cx = clamp(cx, W/2-mx, W/2+mx);  cy = clamp(cy, H/2-my, H/2+my)
view = { x: [cx-960/s, cx+960/s], y: [cy-540/s, cy+540/s] }
```

**슬라이드 헤드라인은 월드가 아니라 화면에 고정**한다(`Collage` 바깥). 제목은 세계의
물체가 아니라 슬라이드의 요소다 — 레퍼런스 덱 `?deck=vox-demo`의 `Headline`과 같은 관례.
클릭 구동 덱이면 t가 아니라 클릭 상태로 퇴장시킨다(교사가 첫 스테이션에서 말하는 동안
제목이 사라지면 안 된다).

클릭으로 스테이션을 넘기는 덱은 `Collage`의 `camTransition`을 쓴다 — `useCam`으로 t 보간할
때는 **지정하지 않는다**(이중 보간).
### 카메라를 손으로 짤 때의 최소 안전장치

`useCam`을 못 쓰면 클램프만이라도 옮긴다. 배율 `s`, 초점 `fx`(0~1)일 때 프레임 가장자리에
빈 배경이 안 나오려면 `|(0.5 − fx) × 100 × s| ≤ (s − 1) / 2 × 100` 이어야 한다.
S2의 스테이션은 좌우 여유가 **19px·13px**(1920 중 1.0%·0.7%)뿐이었다 — `fx`를 0.02만 움직여도
배경색이 드러난다. 스테이션을 고치면 **반드시 각 스테이션에서 이미지 bbox를 실측**한다.

그리고 카메라를 CSS transition으로 돌리면 t의 함수가 아니게 된다. 클릭으로 스테이션을 넘기되
스테이션 **안**의 움직임은 t로 두거나, 최소한 캡처·썸네일이 전이 시간(예: 2.4초)보다 오래
기다리도록 검수 절차에 적어 둔다.
## 파이프라인

### Phase 0 — 월드 설계

슬라이드마다 **월드 크기 · 카메라 안무 · 스테이션**을 먼저 정한다:

```
- slide 1 | form: collage
  world: 3200×1080 | camera: 롱 팬 (760 → 2260, s 1.18 → 1.02)
  intent: 내 손에서 출발한 것이 어디로 가는가
  stations: 사람(620) → 위치핀(1120) → 눈(1400) → 동전(1700) → 카트(1980) → 서버(2620)
  mg: ArrowFlow(사람→서버) · DashTrail(하단 궤적) · AnchorBox("어딘가의 데이터센터")
```

설계 게이트 (BLOCKING):
1. **카메라 총 이동 ≥ 600 월드px** — 그보다 작으면 넓은 월드를 쓸 이유가 없다(정지 슬라이드로).
2. **경로 위에 스테이션을 촘촘히** — 카메라가 지나는 동안 1초 이상 빈 종이가 보이면 실패다.
   (2026-08-18 검수에서 실제로 두 번 걸린 항목)
3. **안무를 슬라이드마다 다르게** — 롱 팬 / 줌아웃 리빌 / 대각 여행 / 정지 프레임.
4. **슬라이드당 조각 5~7개** + 모션그래픽 3~5개. 조각은 **나열이 아니라 관계**로 배치.
5. **무의미 도형 금지** — 빈 카드·장식 사각형으로 여백을 메우지 마라. 지웠을 때 이야기가
   약해지지 않는 요소는 지운다.

### Phase 1 — 자산 (`image-asset-builder`)

시트 배경은 **중간 회색 `#8f9296`**으로 요청한다 — 조각의 흰 종이 테두리가 배경과 같은
색이면 크롭이 테두리를 먹어 버린다(실제로 겪은 사고). `--tol 55`로 그림자까지 함께 지운다.

프롬프트 필수: 팔레트 8색 나열 · 종이 질감 · 가위 자국 가장자리 · 흰 종이 테두리 ·
6등신 한국 성인 · 셀 간 넓은 여백 · **이미지 안 텍스트 금지**.

#### 이미 있는 배경 일러스트에서 조각을 오려 내는 길 (생성 없이)

덱에 풀블리드 일러스트가 이미 있고 새로 생성하기는 과할 때, 그 그림에서 조각을 떼어
낼 수 있다. 새 이미지 생성이 필요 없고 **원본과 화풍이 100% 일치**한다는 게 장점이다.

배경을 월드로 깔고(위 「권장 경로」), 그 위에 같은 그림에서 오려 낸 조각을 얹어 `drift`·
`depth`를 준다. 조각이 배경의 자기 자리 위에서 살짝 떠서 움직이므로 깊이가 생긴다.

```python
# 페더 마스크로 오려 내기 — 가위 자국 대신 부드러운 경계 (다크 배경에서 자연스럽다)
from PIL import Image, ImageDraw, ImageFilter
im = Image.open(src).convert("RGBA")
box = (x0, y0, x1, y1)                     # 원본 1920×1080 기준
cut = im.crop(box)
m = Image.new("L", cut.size, 0)
ImageDraw.Draw(m).ellipse((0, 0, *cut.size), fill=255)   # 또는 rounded_rectangle
cut.putalpha(m.filter(ImageFilter.GaussianBlur(cut.size[0] * 0.06)))
cut.save(f"images/cut-{name}.png")
```

주의: **조각을 얹은 자리의 배경은 그대로 남아 있다.** 조각이 크게 움직이면 배경의 원본이
드러나 겹쳐 보인다 — `drift`를 작게(`|x|+|y| ≤ 40px`) 두거나, 배경 쪽 해당 영역을 어둡게
덮는 그라데이션을 함께 깐다. 밝은 종이 팔레트 덱에서는 경계가 티가 나므로 이 방법은
**다크 배경 덱에서만** 쓴다.

`assets/manifest.json` 등록은 원본 일러스트의 `origin`·`license`를 그대로 물려 적는다
(파생물이다).
### Phase 2 — 슬라이드 저작

```tsx
const W = { w: 3200, h: 1080 };
const cam = useCam([{ t: 0, x: 760, y: 560, s: 1.18 }, { t: 2.4, x: 760, y: 560, s: 1.18 },
                    { t: 7.5, x: 2480, y: 560, s: 1.02 }], W);
<Collage world={W} cam={cam}>
  <Cutout src={P.phone} x={620} y={640} w={200} at={0.2} entry="pop" drift={{ x: 18, rot: -2, to: 8 }} />
  <ArrowFlow from={[840, 560]} to={[2330, 600]} at={2.4} color={VOX.brick} />
  <Cutout src={P.servers} x={2620} y={620} w={400} at={4.6} entry="drop" />
  <AnchorBox x={2620} y={620} w={450} h={580} label="어딘가의 데이터센터" at={6.2} labelSide="top" />
</Collage>
<Headline … />   {/* 고정 헤드라인은 Collage 밖 — 여행이 시작되면 물러난다 */}
```

- **등장은 스냅** — 0.3초. 전경 조각 스태거는 슬라이드 앞 40% 안에 끝낸다.
- **표류 하한**: dominant는 `|x|+|y| ≥ 60px` 또는 `rot ≥ 5°`. 정지한 조각은 죽은 조각이다.
- **크기**: dominant 세로 480~760px · 조연 240~420 · 배경 90~200(dim 낮춤).
  크롭 원본보다 크게 늘리지 마라.
- **텍스트 규약**: 고정 헤드라인은 여행 시작 시 물러나고, 이후 설명은 카메라 안의
  `Tag`·`AnchorBox`가 이어받는다. 라벨은 대상 bbox **바깥**에.

카메라가 움직이므로 **슬라이드당 최소 3시점**(초·중·말)을 찍는다. 확인 항목:
빈 종이 구간 · 조각↔라벨 겹침 · 라벨이 칩 배경에 가려지지 않는지(z) · 화면 밖 잘림 ·
마지막 프레임에 이야기의 두 축(주장과 반증 등)이 함께 남아 있는지.

## 절대 금지

1. **정지한 조각** — `drift` 없이 등장만 하는 조각
2. **빈 세계 여행** — 카메라 경로 위 빈 종이 1초 이상
3. **무의미 필러 도형** — 빈 카드·장식 사각형으로 여백 메우기
4. **카메라 모션 블러** — 흐려지면 종이의 물성이 사라진다
5. **팔레트 이탈·6색 이상** — 에디토리얼 절제가 깨진다
6. **매끈한 3D·플랫 벡터 조각 / 세피아 빈티지** — 헌장 위반
7. **이미지 안 텍스트** — 라벨·수치는 `Tag`·`AnchorBox`로만
8. **한 화면에 들어오는 내용에 이 스킬 사용** — 그건 diorama나 static의 몫
9. **`src/vox` 없이 흉내 내면서 글자만 화면 px로 두기** — 위 「`src/vox`를 쓰지 않고」 절 참조.
   좌표계를 반만 옮기면 글자가 세계에서 떨어져 나온다
