> 머리말을 채우고 본문 문항만 교체하는 방식. **프레임은 100% 보존**한다.

## 프레임/본문 경계

`section0.xml`의 **첫 `<hp:p>` 한 문단**이 secPr·머리말 제목표·꼬리말 페이지번호·
저작권 박스를 모두 담은 **프레임**이다. 둘째 문단부터가 본문(샘플 문항)이다.
`exam_helpers.split_after_frame()`이 `<hp:p>` 태그 깊이를 추적해 이 경계를
바이트 단위로 분리하므로, 프레임은 재직렬화 없이 그대로 보존된다.

## 생성 워크플로우 (build_exam.py)

```bash
# 1) 샘플 스펙 출력
python scripts/build_exam.py --print-sample > spec.json

# 2) 스펙 편집 후 생성 (fix_namespaces + validate 자동 수행)
python scripts/build_exam.py spec.json -o 시험지.hwpx
```

### 스펙(JSON) 필드

| 필드 | 설명 |
|------|------|
| `year`/`grade`/`semester`/`round` | 시험명 구성("2025년 1학년 1학기 2차 …") |
| `exam_name` | 시험 종류(기본 "정기시험") |
| `title` | 시험명 전체를 직접 지정(위 4개 대신) |
| `subject` | 과목명 |
| `date` | "2025. 7. 9." |
| `examiner` | 출제자 이름(결재란에 채움) |
| `total_pages` | 꼬리말 "N면 중" 총면수 |
| `counts` | (선택형,단답형,서술형) 개수. 생략 시 문항에서 자동 산출 |
| `instruction` | 서답형 직전 안내문(예: "※ 단답형은 OMR카드 …") |
| `questions[]` | 문항 목록 |

### 문항(question) 필드

| 필드 | 적용 | 설명 |
|------|------|------|
| `type` | 필수 | `choice`(선택형) / `short`(단답형) / `essay`(서술형) |
| `stem` | 필수 | 질문 |
| `points` | 선택 | 배점(3.1 → "(3.1점)", 3.0 → "(3점)") |
| `jimun` | 선택 | 보기 박스 지문(문자열 또는 줄 리스트) |
| `code` | 선택 | 코드 박스(줄 리스트) |
| `choices` | choice | 선택지 리스트(①②③… 자동) |
| `answer_lines` | short/essay | 답란 빈 줄 수(기본 단답형 1, 서술형 3) |
| `num` | 선택 | 번호 직접 지정(생략 시 유형별 자동) |
| `continuation` | 선택 | 이 문항 뒤 연속표시 삽입(예: "다음 장에 계속") |

> 번호는 유형별 자동: 선택형 1·2·3…, 단답형 [단답형 1·2…], 서술형 [서술형 1·2…].
> 종료 표시 "- 끝. 수고하셨습니다. -"는 항상 마지막에 자동 추가된다.

## 자체 거증(self-verification) 체크리스트

생성 후 반드시 확인한다. (불필요한 내용이 추가되지 않았는지 거증)

1. `validate.py` → VALID
2. `verify_hwpx.py --result` → PASS (XML 유효)
3. `clone_form.py --analyze`로 텍스트 추출 후:
   - 머리말 값이 모두 채워졌는가 (시험명/과목/날짜/출제자/문항수/총면수)
   - **잔여 플레이스홀더 없음**: `2026년  학년`, `(2026. . .)`, `선택형 (  )문항` 부재
   - 문항/선택지/안내문/종료표시가 의도대로 존재
   - **불필요한 빈 줄(빈 양식의 패딩 295줄)이 남지 않았는가** — 본문 문단 = 프레임 1 + 생성 문항만
4. 프레임 보존: section0.xml에 `<hp:secPr>`, `colCount="2"`, `<hp:header>`, `<hp:footer>`,
   `autoNum`, `저작권` 문자열, B4(`width="72852"`)가 모두 존재
