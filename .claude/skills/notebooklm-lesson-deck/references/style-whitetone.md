# Whitetone 스타일 가이드 (기본 스타일)

깔끔한 화이트톤 미니멀 벡터 인포그래픽 — **스타일 언급이 없을 때의 기본값**.
Critter의 클린 벡터 베이스에서 동물 캐릭터를 뺀 순수 버전. 과목·단원을 가리지
않는 중립적 톤이라 어떤 수업에도 무난히 어울린다.

## 디자인 자산 위치

| 파일 | 위치 | 용도 |
|------|------|------|
| 디자인 프롬프트 | `data/2026-1/정보/slide_prompt_whitetone.txt` | NotebookLM 자료 2번 |
| 스타일 참조 이미지 | `data/2026-1/정보/slide_template_whitetone.png` | NotebookLM 자료 3번 |
| 참조 이미지 소스 | `data/2026-1/정보/_style_template_whitetone.html` | 재생성용 (Playwright 1600×900 @2x 렌더) |

## 4색 팔레트 (이 네 개 외에는 쓰지 않는다)

| 역할 | 색상 | 용도 |
|------|------|------|
| 배경 | `#FDFDFB` | 오프화이트 종이. 텍스처·그라데이션 금지 |
| 틸 | `#3E9C93` | 주개념, 제목, 강조 도식 |
| 코랄 | `#E8705A` | 경고, 함정, 자주 하는 실수 |
| 머스터드 | `#E4B04A` | 하이라이트, 핵심 결과 |
| 슬레이트 네이비 | `#33415C` | 본문 텍스트, 코드 |

**한 슬라이드에 액센트 3색 이상 쓰지 않는다.** 흰 여백을 크게 남긴다.

## Critter와의 차이 (핵심)

- **동물 캐릭터·마스코트 없음.** 사람·컴퓨터·사물이 필요하면 같은 얇은 스트로크
  언어의 **단순 기하 픽토그램**으로만 — 점 눈 이상의 얼굴 디테일 금지, 도식 옆
  보조 위치, 본문·코드 위 겹침 금지.
- 나머지(팔레트·스트로크·여백 원칙)는 Critter와 동일.

## NotebookLM Instruction (반복 사용)

```
디자인_프롬프트.txt와 스타일_참조.png에 묘사된 화이트톤 미니멀 벡터
인포그래픽 스타일(오프화이트 배경, 얇은 균일 선, 틸·코랄·머스터드·슬레이트네이비
4색만 절제 사용, 넓은 여백, 동물 캐릭터·마스코트 없음, 인물·사물은 단순 기하
픽토그램으로만)로 모든 슬라이드를 디자인해 주세요.
```

숫자·수식이 나오는 수업이면 반드시 덧붙인다:

```
표와 수식의 숫자는 수업계획서에 적힌 값을 한 글자도 바꾸지 말고 그대로 표기하세요.
```

## HTML 인프라 — 색상 변수

`index.html`(Deck Contract 미니멀 골격)의 `:root`에는 두 변수만 쓴다:

```css
:root{
  --paper:#FDFDFB;              /* 오프화이트 종이 (레터박스) */
  --dk-accent:#33415C;          /* 슬레이트 네이비 — deck.js 진행바 색 */
}
```

진행바를 네이비로 쓰는 이유: 틸은 Critter 시리즈의 정체성 색이라 구분한다.

## HTML 차별화 요소

`references/html-template.md`의 골격에서 다음만 바꾼다:

| 위치 | Whitetone 값 |
|------|-------------|
| `<title>` | `<주제> — <시리즈 부제>` |
| `data-deck-title` | `<주제>` |
| `--paper` | `#FDFDFB` |
| `--dk-accent` | `#33415C` (슬레이트 네이비) |

## pages.json gradient (Whitetone 시리즈)

시작 색은 `#33415C` (슬레이트 네이비) 고정, 끝 색으로 수업을 구분:

```
기본             navy → teal     linear-gradient(90deg, #33415C, #3E9C93)
경고·실수 중심    navy → coral    linear-gradient(90deg, #33415C, #E8705A)
성과·결과 중심    navy → mustard  linear-gradient(90deg, #33415C, #E4B04A)
```

(Critter는 teal 시작 — 시작 색으로 시리즈를 구분한다)

## 적합 단원

- **기본값** — 사용자가 스타일을 언급하지 않은 모든 수업
- 깔끔한 도식·코드·표가 중심인 단원 전반
- 손그림 감성(Whiteboard/Etching)이나 캐릭터(Critter)가 굳이 필요 없는 경우

단원 성격상 다른 스타일이 명확히 유리하면(흐름·분기 → Whiteboard, 추상·이론 →
Etching, 정서·저학년 → Critter) 그 스타일을 제안하고 1회 확인한다.
