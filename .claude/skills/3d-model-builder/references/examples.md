# 레퍼런스 모형 해설

두 모형은 같은 골격(three.js r169 벤더 · 아트보드 · 자가 점검 API)을 쓰지만 메타포·손잡이·
차트는 소재에서 새로 발명했다. 새 모형을 만들 때 **어느 기법을 어디서 봤는지** 찾는 용도로
읽는다. 룩(라이트 스튜디오·종이 카드·앰버)은 두 모형의 선택일 뿐 규칙이 아니다.

## 확산모델-노이즈에서-그림으로 (`data/dev/테스트 수업 자료/확산모델-노이즈에서-그림으로/`)

- **체감 한 문장**: AI는 지우개질(노이즈 걷어내기)을 배운 것이다.
- **주인 변수**: 단계 t ∈ [0,1] (표시는 0~50). 생성은 t 감소, 학습은 t 증가.
- **진짜 계산**: `x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε`, 코사인 스케줄 `ᾱ(t) = f(t)/f(0)`, 픽셀 2,304개 × 3채널.
- **장난감**: 목표 이미지 4종은 암시 함수로 그렸고 시드로 조금씩 변형. 역과정은 정과정을 되짚는다.
- **메타포**: 48×48 픽셀이 큐브가 되고 높이 = 값. 노이즈일 때 산맥, 그림일 때 부조.
- **기법**: `InstancedMesh` 2,304개(드로우콜 1) · `setColorAt(SRGB)` · 클릭 → `instanceId`로 픽셀 추적 ·
  높이 평탄화 토글(`flatAmount`) · SVG 스케줄 차트(스크러버 겸용) · 히스토그램 + N(0,1) 점선 ·
  픽셀 하나의 R·G·B 궤적 차트 · 자동 시연 상태 기계(생성 → 정지 → 학습 → 정지 → 다음 프롬프트).
- **검산**: t=1에서 평균 0.002·표준편차 0.988, t=0에서 원본 오차 0, 드로우콜 5.

## 어텐션-배는-어디를-보는가 (`data/dev/테스트 수업 자료/어텐션-배는-어디를-보는가/`)

- **체감 한 문장**: 같은 낱말이 다른 뜻이 되는 것은 어디를 보느냐(어텐션) 때문이다.
- **주인 변수**: 계산 진행도 t ∈ [0,1] (① 점수 → ② 소프트맥스 → ③ 가중합) + 읽는 토큰 Q.
- **진짜 계산**: `score = q·k/√d`, 인과 마스크, 소프트맥스, `out = Σ w·v`. 임베딩 9차원(의미 7 +
  위치 cos·sin 2), Q·K 4차원, V 3차원(뜻 성분 → 색).
- **장난감**: 임베딩과 W 행렬을 손으로 설계. 두 헤드가 V를 공유. 화면에 명시.
- **기존 덱과의 관계**: 「LLM은 어떻게 말을 고를까」 S11의 예문·형광펜 색 언어를 이어받고, 그 덱이
  "오늘 다루지 않는다"고 한 Q·K·V 계산을 맡는 자매편.
- **메타포**: 토큰 기둥, 형광펜 기둥(Q)에서 뻗는 파란 빔(점수) → 굵기가 가중치인 노란 튜브 →
  값 꾸러미가 출력 구슬로 모여 색이 정해짐. 뒤쪽 토큰은 반투명 가림막.
- **기법**: `TubeGeometry` 굵기 ∝ w(값이 바뀔 때만 재생성) · `Line.setDrawRange`로 빔이 자람 ·
  `curve.getPoint(p)`로 꾸러미 이동 · HTML 토큰 라벨(클릭 = Q 선택) · 기둥 클릭(레이캐스트) = K 선택 ·
  n×n 행렬 히트맵(칸 클릭) · 살아 있는 계산 카드(q·k 항별 대입 → ÷√d → e^s/Σe^s → Σw·v) ·
  카운터 직관 결과를 안내문으로 프레이밍(가림막을 켠 '배가'는 앞 문맥 쪽으로 기울어진다).
- **검산**: 행 합 1, 헤드 1 가림막 켬 고파서→배가 0.84, 헤드 2 가림막 끔 세 '배'가 각자 타고·고파서·먹었다 ≥ 0.60.

## 토큰화-말이-숫자가-되기까지 (`data/dev/테스트 수업 자료/토큰화-말이-숫자가-되기까지/`) — 스캐폴드로 만든 첫 모형

- **체감 한 문장**: 컴퓨터는 말을 조각으로 자르고, 조각마다 숫자 묶음을 표에서 꺼내며, 뜻이 비슷한 조각은 이웃이 된다.
- **주인 변수**: t ∈ [0,1] (① 자르기 → ② 표에서 꺼내기 → ③ 뜻 공간으로) + 입력 문장(자유 입력).
- **진짜 계산**: BPE를 페이지 안 말뭉치 56문장으로 즉석 학습(병합 규칙 51개, 어휘 127개) → 아무 문장이나
  자른다. 임베딩 표 조회, 코사인 이웃, 벡터 산술(왕 − 남자 + 여자 ≈ 여왕 0.997), 9차원 → 3차원 PCA(분산 65%).
- **장난감**: 낱말 41개와 조사의 9차원 벡터를 뜻 성분으로 설계, 나머지 조각은 무작위. "학습 전" 토글은 전부 무작위.
- **UI 컨셉**: 다크 네이비 무대 + 밝은 카드 + 인디고 액센트 — 앞의 두 모형과 다른 룩. 색 토큰만 바꿔 골격을 그대로 썼다.
- **메타포**: 절단대(글자 타일이 병합 규칙 순서대로 붙는다) · 임베딩 표 벽(어휘 × 9칸 InstancedMesh, 조회 행이 튀어나옴) ·
  뜻 공간(축 3개 + 낱말 점 InstancedMesh, 벡터 띠가 날아가 자리 잡음, 산술 경로 폴리라인).
- **기법**: 병합 단계별 레이아웃 스냅샷을 t로 보간(결정론) · 토큰별 시간차 창(`(b − k/n·.55)/.4`) · `QuadraticBezierCurve3`
  비행 · 자유 텍스트 입력 → 재구축 · 이웃 낱말만 이름표(라벨 풀 8개 재사용) · `snapshot().missingDesigned`로 설계 데이터 누락 검사.
- **잡은 함정**: HTML 안 제어 문자(U+0001) → Vite 500 · 낱말+조사 쌍이 먼저 병합 → 말뭉치 조사 분포 재설계 ·
  `(1−.67)/.33 < 1` 부동소수점 → 마지막 국면 요소가 안 켜짐.
