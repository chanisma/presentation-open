### 슬라이드 1 — 분위기는 잡히지만 표지의 정보 위계가 둘로 갈라진다 (7.5/10)

- 읽히는가: 제목과 노트북 이미지는 즉시 읽힌다. 다만 우하단의 6칩은 표지의 두 번째 초점이 아니라 작은 각주처럼 보인다.
- 문제점: (`s01-0`) → 제목의 쉼표 뒤 줄바꿈은 자연스럽지만 2행의 폭과 무게가 지나치게 커서 “바이브코딩”보다 “말이 설계가 되다”만 남는다 → 1행을 약간 키우거나 2행을 10% 줄여 두 문장을 한 덩어리로 묶어라.
- 문제점: (`s01-0`) → 우하단 여정 트랙은 글자가 작고 칩 간격도 촘촘해 프로젝션에서 사실상 읽히지 않는다 → 표지에서는 6칩을 단순한 6개 단계등으로 축약하고, 상세 명칭은 마무리 슬라이드에만 남겨라.
- 문제점: (`s01-0`) → 하단 뷰어 컨트롤과 여정 칩이 겹쳐 시각적 잡음이 생긴다 → 실제 발표 화면에서 컨트롤이 사라지는지 확인하고, 남는다면 여정 트랙을 최소 80px 위로 올려라.
- 문제점: (`s01-0`) → 창가·노트북·말풍선이 우측에 몰렸는데 좌측 제목도 무거워 중앙 연결부가 흐릿하다 → 작은 청록 말풍선 하나가 제목 방향으로 넘어오게 해 “말→화면”의 흐름을 만들어라.

### 슬라이드 2 — 시간 비교는 강하지만 첫 프레임이 ‘고장 난 시계’처럼 보인다 (7.5/10)

- 읽히는가: 완성 프레임에서는 45분·3시간·3주 사례가 명확하다. 클릭마다 시계가 멈추고 사례 카드가 켜지는 구조도 이해된다.
- 문제점: (`s02-0`) → 시계 중앙을 가로지르는 굵은 수평선이 숫자를 잘라, “정지 전 상태”보다 렌더링 오류처럼 보인다 → 뚜껑이 닫힌 표현이라면 숫자 위를 덮지 말고 상단 15~20%에 반투명 셔터로 표현하라.
- 문제점: (`s02-0`) → 세 시계와 우측 카드가 모두 흐려 첫 장면에서 무엇을 봐야 하는지 모호하다 → 첫 프레임부터 시계 외곽과 숫자는 선명하게 두고, 바늘과 사례 카드만 비활성화하라.
- 문제점: (`s02-1`) → 45분 시계만 살아났는데 나머지 두 시계의 잘린 숫자가 계속 강한 시각적 오류를 만든다 → 비활성 시계는 숫자를 숨기거나 단색 실루엣으로 처리하라.
- 문제점: (`s02-3`) → 45분 시계가 지나치게 커서 3시간·3주가 부차적 예외처럼 보인다 → 시간 단위의 차이를 크기로 표현하더라도 45분과 3시간의 지름 차이를 줄이고, 세 사례의 중심축을 더 정돈하라.
- 문제점: (`s02-3`) → 우측 카드 본문과 하단 각주가 작다. 특히 출처·ARR 설명은 교실 뒤에서 읽기 어렵다 → 카드에는 “무엇을 만들었나 / 얼마나 걸렸나”만 남기고 출처는 발표자 노트나 별도 참고 슬라이드로 이동하라.
- 문제점: (`s02-3`) → 마지막 캡션 카드와 스톱워치의 색 대응은 좋지만 연결 앵커가 없다 → 각 시계에서 대응 카드로 향하는 짧은 색상 리더선을 추가하면 대응 관계가 즉시 읽힌다.

### 슬라이드 5 — 주방 메타포는 보이지만 ‘AI가 빈칸을 멋대로 채운다’는 사건이 약하다 (6.5/10)

- 읽히는가: 주문서, 주방, 결과물의 순서는 보인다. 그러나 컨베이어의 이동과 도장 행위는 정지 화면만으로 충분히 전달되지 않는다.
- 문제점: (`s05-0`) → 주문서가 주방 장치 안에 이미 들어가 있어 “들어가는 과정”보다 문서 양식처럼 보인다 → 첫 프레임에서는 주문서를 컨베이어 왼쪽에 두고, 다음 프레임에서 주방 안으로 이동시키는 위치 변화를 크게 만들어라.
- 문제점: (`s05-0`) → 파란 도장 네 개가 빈칸을 채웠다는 의미보다 이미 인쇄된 버튼처럼 보인다 → 도장 각도를 불규칙하게 하고 잉크 번짐·스탬프 자국을 분명히 하며, 클릭 전에는 해당 칸을 실제 빈칸으로 보여라.
- 문제점: (`s05-1`) → 결과 웹페이지가 너무 작고 주방과 멀어 인과가 끊긴다 → 주방 출구에서 결과 카드까지 컨베이어를 연장하거나, 결과물을 30~40% 키워 “내가 시킨 것과 다름”을 화면 안에서 비교하게 하라.
- 문제점: (`s05-1`) → 41.1% 카드는 강한 분홍색으로 별도 통계 슬라이드처럼 튄다 → 주방 메타포 안의 “반품률 경고표”나 “오주문 전표” 형태로 통합하라.
- 문제점: (`s05-1`) → 통계 카드 본문과 인용 정보가 작고 대비가 낮다 → 41.1%, 한 줄 해석, 출처의 3단계만 남기고 나머지 문장은 삭제하라.
- 문제점: (`s05-0`, `s05-1`) → 상단과 좌측에 큰 무의미 공백이 남고 모든 사건이 하단 중앙에 edge-cling 한다 → 주방 장치를 15% 키워 좌중단으로 옮기고 결과물을 우중단에 배치해 화면 중앙을 사용하라.

### 슬라이드 6 — 비교 구조는 명료하지만 텍스트가 메타포를 대신한다 (7/10)

- 읽히는가: “모호한 한 줄”과 “여섯 요소가 담긴 부탁”의 차이는 읽힌다. 다만 3초 안에 보이는 것은 시각적 차이가 아니라 텍스트 양의 차이다.
- 문제점: (`s06-3`) → 좌우 카드가 모두 흰 사각형이라 “같은 부탁, 다른 결과”가 아니라 “짧은 문장, 긴 문장” 비교로 수렴한다 → 좌측에는 갈라지는 4개의 결과 미리보기, 우측에는 하나로 수렴하는 결과 미리보기를 붙여 결과 차이를 시각화하라.
- 문제점: (`s06-3`) → 우측 긴 문장은 프로젝션에서 읽기 부담스럽다 → 문장 전체 대신 6요소를 색상 토큰으로 분절하고 각 토큰 아래 한두 단어 설명만 남겨라.
- 문제점: (`s06-3`) → 하단 6칩과 우측 밑줄이 같은 내용을 중복 설명한다 → 밑줄 색과 하단 칩을 직접 연결하거나, 하단 칩을 범례로 축소하라.
- 문제점: (`s06-3`) → 좌측 물음표 태그들이 장식처럼 흩어져 있고 카드와의 연결선이 약하다 → 카드에서 실제로 갈라져 나오는 분기선 끝에 태그를 배치하라.
- 문제점: (`s06-3`) → 화면 중앙 하단이 비고, 콘텐츠가 상단 띠와 중단 두 카드로만 분리된다 → 비교 결과를 중앙 하단에 배치해 삼각 구도를 완성하라.

### 슬라이드 7 — 선반 비유가 개념을 과도하게 추상화한다 (6/10)

- 읽히는가: 위 6개는 고정하고 아래 4개는 맡긴다는 대조는 보인다. 그러나 “무엇을 고정하고 무엇을 맡기는가”를 읽으려면 작은 라벨을 전부 해독해야 한다.
- 문제점: (`s07-0`) → 지붕처럼 보이는 노란 삼각형이 의미 없이 가장 큰 도형이다 → 제거하거나 “무너지지 않는 구조”라는 의미가 드러나는 하중·기둥 메타포로 완성하라.
- 문제점: (`s07-0`) → 못이 위에서 태그를 누르는 모양이 아니라 태그 위에 작은 점이 떠 있는 모양이다 → 못 머리와 선반의 접점을 명확히 하고, 고정 태그에는 짧은 수직 핀을 관통시켜라.
- 문제점: (`s07-0`) → 아래의 느슨한 태그는 점선 테두리만 달라 자유 재량이라는 의미가 약하다 → 태그의 위치·각도·색조를 조금씩 다르게 하고, 선반 위에서 이동 가능한 레일 표시를 추가하라.
- 문제점: (`s07-0`) → 우측 판단 질문과 설명문이 본체에서 분리된 각주처럼 떠 있다 → 선반의 고정 영역과 질문 카드를 화살표로 연결하거나 질문을 저울·안전핀 형태로 메타포 안에 넣어라.
- 문제점: (`s07-0`) → 아래 설명, 우측 설명, 최하단 문장이 모두 작고 저대비다 → 핵심 판단 질문만 크게 남기고 나머지는 발표자 발화로 돌려라.
- 문제점: (`s07-0`) → 상·하 선반 사이 공백이 과도해 장면이 분절된다 → 두 선반 간 거리를 줄이고 위·아래의 대응 항목을 세로로 맞춰 비교성을 높여라.

### 슬라이드 8 — 덱에서 가장 명확한 모션 구조지만 초기 돌과 최종 별의 연결이 약하다 (8/10)

- 읽히는가: 계획→명령→확인→피드백의 반복과 3바퀴 진행은 빠르게 읽힌다. 클릭이 결과물의 형태를 바꾸므로 모션의 필연성도 있다.
- 문제점: (`s08-0`) → 중앙 초기 도형이 흰색이라 배경에 묻히고, 돌보다 톱니·폭발 표시처럼 보인다 → 회색 수채 질감과 불규칙한 외곽을 주고 “초안” 같은 짧은 라벨을 붙여라.
- 문제점: (`s08-0`) → 궤도 위 검은 현재 위치 점과 1번 계획 노드가 동시에 강조되어 시작점이 둘로 보인다 → 현재 위치 표시는 1번 노드와 합치고 진행 시에만 다음 구간으로 이동시켜라.
- 문제점: (`s08-3`) → 최종 별이 너무 상징적이어서 “더 나아진 결과”보다 “별 모양으로 바꾸기”로 오독될 수 있다 → 동일한 결과물 카드가 점차 정돈되는 방식이 교육적 의미에는 더 정확하다.
- 문제점: (`s08-3`) → 우측 바퀴 카드의 세 수정 문장이 작고 서로 비슷한 흰 막대로 보여 뒤에서 읽히지 않는다 → 각 바퀴의 핵심 동사만 굵게 키우고 나머지는 한 줄로 줄여라.
- 문제점: (`s08-0`, `s08-3`) → 좌하단 인용과 부연이 너무 작고 배경 이미지 위에 놓여 대비가 낮다 → 인용을 삭제하거나 반투명 단색 패널 위에 1행으로 올려라.
- 문제점: (`s08-3`) → 피드백 노드가 좌측 화면 가장자리에 가까워 제목·궤도의 중심 균형을 깨뜨린다 → 전체 궤도를 약간 우측으로 이동하거나 좌우 폭을 줄여라.

### 슬라이드 10 — ‘함정 넷’인데 지뢰밭이 아니라 떠 있는 메모 네 장이다 (5.5/10)

- 문제점: (`s10-4`) → 4번만 분홍 테두리라 특별히 더 중요한 이유가 불명확하다 → “프로젝트 삭제” 사례와 연결되는 결과이므로 4번에서 신문 조각으로 이어지는 빨간 인과선을 추가하라.
- 문제점: (`s10-4`) → 신문 조각은 작고 기울어져 있으며 본문이 프로젝션에서 읽히지 않는다 → 헤드라인만 크게 남기고 “고친 곳과 다른 곳이 망가짐”이라는 한 줄 캡션을 붙여라.
- 문제점: (`s10-4`) → 중앙 40~60%가 크게 비어 dominant가 없다 → 중앙에 진행 경로나 큰 지뢰 하나를 두고 카드들을 그 주변에 종속시켜라.

## 씬 사이의 다양성

전체적으로 수채 배경과 짙은 녹색·청록 강조색은 일관적이지만, 중반 이후 구도가 “상단 중앙 제목 + 흰 카드 여러 장 + 하단 작은 문장”으로 반복된다. 특히 슬라이드 6, 10, 12, 15, 17은 내용만 바뀐 카드 비교형으로 수렴한다. 메타포를 표방하지만 실제 화면에서는 메타포보다 흰 라운드 사각형이 더 자주 보인다.

장면군별 문제는 다음과 같다.

- 슬라이드 2·5·8·13은 클릭 장면이라는 고유성이 있다. 다만 13은 누적 등장 때문에 과밀해지고, 5는 이동량이 작아 모션의 의미가 약하다.
- 슬라이드 6·7·12·17은 모두 “요소를 명시하면 좋아진다”는 같은 메시지를 반복한다. 비교 카드, 선반, 매핑, 성장이라는 외피는 다르지만 텍스트 의존도가 높아 시각적 차이가 충분하지 않다.
- 슬라이드 10·15는 각각 지뢰밭과 처방전이라는 강한 메타포 이름을 갖고도 실제 구현은 떠 있는 카드와 2열 표에 머문다.
- 슬라이드 1·5·8·18의 사진성 수채 배경은 장면감을 주지만, 6·7·10·12·15·17은 거의 동일한 빈 종이 배경이라 덱 중반의 리듬이 평평하다.
