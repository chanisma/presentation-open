## 즉시 고쳐야 할 것

- Reddit 계약의 “연매출 1.4%”를 삭제한다. 최근 확정 연매출인 2025년 약 22억 달러를 기준으로 하면 약 **2.7%**다.
- “버스 노선망이 없던 아비장”을 삭제한다. 아비장에는 기존 버스망이 있었다.
- “통신사 데이터만으로 노선도를 설계했다”를 고친다. IBM은 통신 데이터 외에 기존 버스망과 OpenStreetMap 도로망도 사용했고, 노선 개선안을 제안했다.
- 직방의 “2025년 매출 1,241억 원”을 삭제하거나 감사보고서로 다시 확인한다. 현재 확인되는 자료와 불일치한다.
- “세 회사 모두, 새로 수집한 데이터 0건”을 삭제한다. 세 서비스 모두 공공데이터 외에 자체·이용자 생성 데이터를 다룬다.
- 실거래가 API 예시를 “실제 응답”처럼 제시하지 않는다. “실제 XML 응답의 주요 필드를 교육용 JSON으로 단순화”했다고 명시한다.
- N61 변경 설명을 “남부순환로·동일로 경유안에서 효령로·능동로 경유안으로 수정”으로 완성한다.
- AlphaFold 노벨상은 DB 자체가 아니라 Hassabis와 Jumper의 단백질 구조 예측 공로에 주어진 **화학상 절반**이라고 고친다.
- “PDB 50년치 데이터만 학습”으로 오해되지 않도록 단백질 서열·다중서열정렬 데이터도 사용했다는 점을 추가한다.
- Reddit 주가 사례에서 “보도만으로 30억 달러가 사라졌다”라는 단일 인과를 완화한다.
