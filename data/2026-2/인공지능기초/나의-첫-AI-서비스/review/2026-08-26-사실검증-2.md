## 즉시 고쳐야 할 것

- 활동지 읽을거리의 “이 회사들도 LLM을 밑바닥부터 만들지 않았습니다”는 삭제해야 한다. 네이버·카카오까지 포함하면 틀린 일반화다.
- S7의 “대부분의 AI 기능은 남의 모델을 API로 빌려 만든다”를 “많은 AI 서비스는…”으로 낮춰야 한다.
- `reasoning_effort:"low"`를 API 필수 필드처럼 설명한 문구를 고쳐야 한다. 수업 운영상 고정값일 뿐이다.
- Upstage 요금 식을 `입력 토큰×입력 단가 + 출력 토큰×출력 단가`로 고쳐야 한다.
- Duolingo의 Explain My Answer는 2026년 현재 Max 전용 기능이 아니다. “Max 기능으로 시작했다”는 시점을 밝혀야 한다.
- “3줄 위로” 소개에는 무관·장난 입력 시 1문장 예외가 있음을 표시해야 한다.
- 공개된 활동지 본문에 실제 형식의 Upstage 키가 들어 있다. 임시 키라 해도 학생에게 배포되기 전 쿼터·출처 제한·폐기 절차를 확인해야 하며, 가능하면 브라우저 코드에 시크릿을 넣지 않는 구조가 필요하다.

## 교사 확인

- `5,300억 원`의 원 뉴스 원문과 산정 범위를 다시 확인할 것. 국가 프로젝트·복수 팀 지원이라는 요지는 맞지만, 정부 공식 페이지에서 금액 자체가 직접 확인되지 않았다.
- 수업 당일 학교망에서 Upstage CORS preflight와 실제 POST 호출을 다시 확인할 것. “단일 HTML 더블클릭 실행”은 CORS가 막히면 실패한다.
- `reasoning_effort:"low"`와 생략 시 응답 시간을 동일 입력으로 여러 차례 비교할 것. 현재의 `0.5초`는 자체 1회 실측이라 일반화할 수 없다.
- ChatGPT 게스트 접속 가능 여부, 코드 블록 생성·복사 버튼, 사용량 제한을 학교 PC에서 확인할 것. 게스트 이용은 지역·배포 상태에 따라 로그인 요구가 나타날 수 있다.
- Windows 버전별 메모장 저장 화면에서 `.html`, “모든 파일”, UTF-8 절차를 직접 확인할 것.
- 활동지의 파일 자동 채움, API 키 마스킹, Google Sheets 기록을 실제 제출까지 종단 테스트할 것. 저장된 시트뿐 아니라 브라우저 요청과 서버 로그에도 원본 키가 남지 않는지 확인해야 한다.
- 세 데모의 정상 입력과 예외 입력을 각각 실행해 형식 준수 여부를 확인할 것. 프롬프트와 화면 문구의 정적 일치는 확인됐지만 모델 출력 준수는 보장되지 않는다.
