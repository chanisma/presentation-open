너는 수업용 슬라이드덱의 장면 연출을 심사하는 까다로운 아트 디렉터다. 첨부 이미지는 고등학교 '인공지능 기초' 덱 「나의 첫 AI 서비스」 19장을 시간·클릭 순서대로 캡처한 것이다. 파일명이 곧 순서다 — sNN-i-cK.png는 슬라이드 NN의 i번째 프레임(K번 클릭 후). 씬 슬라이드는 클릭 없이 시간이 흐르며 여러 프레임을 찍었다.

- s01: 표지 — 사원증(프롬프트가 취직) + 여정 5단계
- s02: 데모 3종 카드 지그재그 + 체험 미션
- s03: 라이브 문항 ① (챗GPT와 다른 점)
- s04: 씬 「무대 뒤」 — 서비스 앞면이 물러나고 대본·빈칸·우체통(API)이 드러나 입력이 끼워지고 발사·응답 귀환, 라벨 3개
- s05: 화이트보드 씬 「API 접수 창구」 — Solar 가게·화면(UI)·API 창구·우리 프로그램의 요청/응답 왕복·동네 축소·빨간 주석
- s06: 빌드 「API 요청 네 요소」 — 주문표 카드 + 응답 + 토큰 요금 띠
- s07: 실제 사례 4칩 + 공통 구조 미니 다이어그램
- s08: 개발자의 세 질문 + 나쁜 예→좋은 예
- s09: 라이브 문항 2개 (분야 설문 + 문제 워드클라우드)
- s10: 입력·출력 규칙 + temperature 3택
- s11: 시스템 프롬프트 전문 해부 (4 라벨)
- s12: 활동지 A·B·C 안내 + 링크
- s13: 코드 생성 프롬프트 = 내가 쓴 것 + 받은 것 + 키 윤리
- s14: walkthrough 씬 — ChatGPT 창→메모장→내 서비스 3창 릴레이 + 포인터 + 진행 레일 + 문제 카드 2
- s15: 기능 테스트 기본 2종 + 확장 1종
- s16: 씬 「고장 진단 정비소」 — 접수·분기 라벨·좌 리프트(문서가 열려 프롬프트 종이 2장)·우 리프트(ChatGPT 요청)
- s17: 라이브 문항 ③ (어디를 고쳤나)
- s18: 제출 3걸음 + 링크
- s19: 개발 사이클 링 + 마무리 문장

채점 기준(씬 s04·s05·s14·s16 각각 + 빌드/정적 장 전반):
1. 메타포 전달력 — 나레이션 없이 3초 안에 읽히는가.
2. 씬 간 고유성 — 같은 구도로 수렴하지 않는가.
3. 레이아웃 계약 — (a) 텍스트/그래픽 존 분리 (b) 라벨이 도형에 묻히지 않는가 (c) 헤드라인 줄바꿈 (d) 선·화살표 앵커 (e) 다크 배경 가시성 (f) 겹침·잘림·화면 밖 요소.
4. Lazy Defaults — 균등 그리드 나열, 중앙정렬 일색, edge-cling(중앙 공백).
5. 여백/과밀 — 비었나 과밀한가, dominant가 분명한가.
6. 프레임 사이 변화가 의미를 만드는가. 마지막 프레임이 이야기의 축을 다 담는가.
(주의: 씬의 중간 프레임은 애니메이션 진행 중이라 요소가 아직 안 나온 상태가 정상이다 — 마지막 프레임 기준으로 완성 상태를 판정하라.)
