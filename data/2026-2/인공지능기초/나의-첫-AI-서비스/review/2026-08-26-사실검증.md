## 즉시 고쳐야 할 것

- 공개된 Upstage API 키를 즉시 폐기·재발급해야 한다. 새 키도 슬라이드, 학생 HTML, Git 저장소에 넣지 말고 교사 관리 프록시 뒤에 둬야 한다.
- `reasoning_effort: "low"`를 “API 필수”라고 한 문구를 “수업 운영상 고정”으로 바꿔야 한다.
- 카카오톡 대화 요약 도입 연도를 2024년에서 **2023년 12월 18일**로 고쳐야 한다. 당시 기능명은 **‘안 읽은 대화 요약하기’**다.
- “배달의민족 리뷰 요약”은 실제 출시 기능으로 확인되지 않는다. 삭제하고 검증된 **Duolingo Max** 또는 정확히 설명한 **Notion AI**로 교체해야 한다.
- “토스 송금이 남의 API를 빌린 사례”는 “온라인 상점이 토스페이먼츠 결제 API를 연결하는 사례”로 바꿔야 한다.
- “시스템 프롬프트는 사용자가 볼 수 없다”는 문구를 삭제해야 한다. 이 수업 구조에서는 HTML 소스에서 그대로 읽힌다.
- “스픽은 프롬프트 설계만 잘해서 회사가 됐다”, “실제 서비스가 한 일은 프롬프트+API 두 가지가 전부” 같은 환원적 설명을 고쳐야 한다.
- ChatGPT 무료 계정의 “기본 모델 무제한” 문구를 삭제해야 한다.
- 5,300억 원은 모델 하나의 제작비가 아니라 여러 정예팀에 대한 GPU·데이터·인재 지원 총규모라는 점을 밝혀야 한다.
- “medium을 빼먹으면 2분 이상”을 일반 API 사실처럼 쓰지 말고 자체 시험 결과로만 표시해야 한다.
- 끊긴 코드는 “이어 쓰기”보다 “완전한 HTML 전체를 하나의 코드 블록으로 다시 출력”하게 해야 제출 오류가 적다.

## 교사가 수업 전에 직접 확인해야 할 것

- 새 API 키가 활성화됐는지, 호출 한도와 잔액이 충분한지.
- 학교망에서 Upstage API의 CORS preflight와 실제 POST가 모두 성공하는지.
- `reasoning_effort:"low"`에서 학급 규모 동시 호출 시 실제 응답시간과 429 발생률.
- Solar Pro 3가 수업 당일에도 `solar-pro3` 이름과 `/v1/chat/completions`에서 제공되는지.
- `response_format:{type:"json_object"}`가 필요하다면 실제 호출로 지원 여부 확인.
