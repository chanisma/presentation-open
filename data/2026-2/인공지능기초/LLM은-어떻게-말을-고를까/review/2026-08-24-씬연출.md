### 슬라이드 3 — 핵심 대비는 보이지만 ‘지형’보다 막대그래프로 먼저 읽힌다 (6.5/10)

- 읽히는가: 좌측의 `10` 대 우측의 `3·2·2·2·1`이라는 분포 차이는 3초 안에 읽힌다. 그러나 “좁고 깊은 골짜기로 답이 굴러 모인다 / 평평한 들판에서 여러 웅덩이로 나뉜다”는 공간적 메타포는 약하다. 현재 형광 막대가 너무 강해서 일반적인 빈도 그래프로 해석되기 쉽다.
- 문제점:
  - (`s03-0-c0.jpg`) → 골짜기와 들판의 지형선이 배경에 묻히고, 구슬도 막대 밑의 작은 발광점처럼 보여 “굴러간다”는 운동 원인이 드러나지 않는다 → 지형의 외곽 대비를 높이고, 시작 위치에서 골짜기나 웅덩이까지 이어지는 짧은 궤적·잔상을 남겨라. 막대보다는 실제 구슬의 누적 더미로 표현하는 편이 메타포에 맞다.
  - (`s03-0-c0.jpg`) → 좌측은 하나의 높은 막대, 우측은 다섯 막대여서 “뾰족한 확률분포 대 납작한 확률분포”보다 “큰 값 대 작은 값”으로 읽힌다 → 동일한 총 10개 구슬이 좌측에서는 한 웅덩이에, 우측에서는 다섯 웅덩이에 분산된 모습을 직접 보여라.
  - (`s03-0-c0.jpg`) → 그래픽이 화면 하반부에 얇게 깔리고, 헤드라인과 그래픽 사이가 지나치게 비어 있다 → 지형 전체를 위로 8~12% 올리고 높이도 키워 중앙의 빈 공간을 줄여라.
  - (`s03-0-c0.jpg`) → 하단 설명과 결론 캡슐이 발표 도구 모음에 너무 가깝다. 라임 라벨도 작아 지형에 묻힌다 → 지형 아래 설명을 간소화하고, 결론은 지형 사이 또는 그래픽 상단으로 이동시켜 인터페이스와 분리하라.
  - (`s03-0-c0.jpg` → `s03-1-c0.jpg` → `s03-2-c0.jpg`) → 세 프레임의 변화가 육안으로 거의 구별되지 않는다. “시간이 흐르며 쌓인다”는 설정이 캡처만으로 증명되지 않는다 → 첫 프레임은 소수 구슬, 중간은 이동 중인 구슬과 부분 누적, 마지막은 `10` 대 `3·2·2·2·1`의 완성 상태로 차이를 크게 벌려라.
  - (`s03-2-c0.jpg`) → 마지막에는 분포 결과만 남고, 구슬이 어디서 와서 왜 그렇게 나뉘었는지 보이지 않는다 → 최종 화면에도 희미한 유입 궤적과 두 지형의 입구를 남겨 원인과 결과가 함께 보이게 하라.

### 슬라이드 7 — 순환은 읽히지만 ‘같은 심장, 다른 껍데기’의 절반만 구현됐다 (6.8/10)

- 읽히는가: 네 단계가 원형으로 반복된다는 사실은 최종 프레임에서 즉시 읽힌다. 반면 “회사마다 이름은 달라도 내부 원리는 같다”는 제목의 ‘껍데기 차이’는 화면에 없다. 실제 장면은 사실상 “네 단계 순환”만 설명한다.
- 문제점:
  - (`s07-0-c0.jpg`) → 부분적으로 그려진 호와 흐린 라벨은 로딩 중인 UI처럼 보인다. 특히 `좌표로`, `서로 쳐다보기`가 어둡고 도형에 걸쳐 있다 → 단계가 등장할 때 노드와 라벨을 함께 명확히 밝히고, 라벨을 원 바깥의 고정 위치에 배치하라.
  - (`s07-0-c0.jpg`) → 우측 `좌표로` 라벨이 노드 뒤에 묻혀 첫 글자가 손상된다 → 라벨과 노드 사이에 최소 한 글자 폭의 간격을 두고, 원형 궤도 바깥쪽으로 밀어라.
  - (`s07-1-c0.jpg`) → 원형 반복 도식은 명확하지만 균등한 4분할 원이라는 매우 익숙한 기본값에 머문다 → 중앙의 “심장”을 실제 핵심 장치처럼 강화하고, 바깥에 서로 다른 회사명·제품명 껍데기가 잠깐 교체되거나 벗겨지는 구조를 추가하라.
  - (`s07-1-c0.jpg`) → `반복`과 `낱말 하나마다 한 바퀴`가 작고, 원의 넓은 내부가 대부분 비어 있다 → 중앙 문구를 확대하거나 네 단계를 구동하는 펄스·회전축을 넣어 빈 공간에 의미를 부여하라.
  - (`s07-0-c0.jpg` → `s07-1-c0.jpg`) → 끊긴 원이 완성되는 변화는 의미가 있다. 다만 제목의 핵심인 “껍데기를 벗긴다”는 변화는 발생하지 않는다 → 첫 프레임에는 서로 다른 외피, 마지막에는 외피가 사라지고 동일한 네 단계 심장이 남도록 모션의 국면을 바꿔라.
  - (`s07-1-c0.jpg`) → 최종 화면에는 공통 심장만 있고 서로 달랐던 껍데기가 남지 않아 이야기의 두 축을 비교할 수 없다 → 화면 가장자리에 벗겨진 외피 2~3개를 잔상처럼 남기거나, 작은 `겉 이름들 → 같은 내부` 비교 표식을 유지하라.

### 슬라이드 9 — 범주화는 명확하지만 ‘배가 어디에도 앉지 못한다’는 결론은 부정확하다 (7.1/10)

- 읽히는가: 타는 것·먹는 것·몸의 부위가 가까운 단어끼리 묶인다는 점은 잘 읽힌다. 다만 `배`는 실제로 먹는 것과 몸의 부위에 해당하므로 “세 칸 중 어디에도 앉을 수 없다”가 아니라 “여러 칸에 동시에 걸친다”가 맞다. 현재 시각화도 그 모순을 드러낸다.
- 문제점:
  - (`s09-0-c0.jpg`) → 좌측 텍스트와 우측 카드가 양 끝에 붙고 중앙이 비는 전형적인 edge-cling 구도다 → 제목·설명 폭을 줄이면서 오른쪽 카드를 중앙 쪽으로 당기거나, 중앙의 빈 공간을 단어 이동 경로로 사용하라.
  - (`s09-0-c0.jpg`) → 카드 내부가 동일한 3×3 균등 그리드라 “좌표 공간에서 가까운 말”보다 분류표로 보인다 → 단어를 자유 좌표에 배치하고 의미가 가까운 단어끼리 실제 거리로 군집시키거나, 적어도 각 행 안에서 위치 차이를 보여라.
  - (`s09-1-c0.jpg`) → `배`가 카드 밖에 놓이고 세 범주 모두에서 점선이 연결되어 있다. 이것은 “어디에도 앉지 못함”이 아니라 “세 후보와 모두 관련 있음”으로 읽힌다 → 의도가 다의어라면 “하나의 좌표로 고정할 수 없다”로 문장을 고치고, `배`가 문맥에 따라 `선박·과일·신체`의 세 위치로 갈라지는 모습을 보여라.
  - (`s09-1-c0.jpg`) → `배` 박스 오른쪽이 화면 가장자리에 가까워 결과가 부속 주석처럼 보인다 → 카드를 왼쪽으로 당기고 `배` 및 세 갈래를 그래픽 존 내부에 포함시켜 dominant 요소로 만들어라.
  - (`s09-1-c0.jpg` → `s09-2-c0.jpg`) → 두 프레임이 사실상 동일하다. 시간 기반 모션의 마지막 두 단계가 아무 의미도 추가하지 않는다 → 둘 중 하나를 제거하거나, 마지막 프레임에서 `배`가 세 의미로 분열되면서 “문맥이 필요하다”는 다음 장면의 질문까지 도달하게 하라.
  - (`s09-2-c0.jpg`) → 마지막에는 범주와 모호한 단어가 함께 남는 점은 좋지만, 점선 세 개가 같은 관계처럼 보여 모호함의 종류가 설명되지 않는다 → 각 경로 끝에 `타는 배 / 먹는 배 / 사람의 배`처럼 문맥 조각을 붙여 두 축을 완결하라.

### 슬라이드 13 — 클릭별 국면은 구분되지만 핵심 과정이 너무 작은 ‘설명용 대시보드’다 (7.4/10)

- 읽히는가: 네 단계가 한 조각을 만들고, 그 조각이 뒤에 붙어 다시 입력되며, 이 과정이 수백 번 반복된다는 논리는 세 프레임을 순서대로 보면 읽힌다. 클릭 1·2는 실제 국면 전환으로 기능한다. 다만 개별 정지 화면만 보면 정보량이 많고 핵심 이동이 작아 3초 독해에는 빠듯하다.
- 문제점:
  - (`s13-0-c0.jpg`) → 상단 문장, 네 개의 처리 박스, 우측 결과, 바퀴 수가 모두 비슷한 시각적 무게를 가져 dominant 요소가 없다 → 국면 1에서는 “문장 → 새 조각 1개”만 강하게 밝히고 나머지 장치는 한 단계 어둡게 처리하라.
  - (`s13-0-c0.jpg`) → 네 단계를 동일 크기 카드로 나열해 일반적인 가로 파이프라인처럼 보인다 → 네 카드의 역할을 유지하되 순환 장치나 하나의 기계 내부 모듈로 묶어 “한 바퀴”가 우선 읽히게 하라.
  - (`s13-0-c0.jpg`) → `눈이` 결과 박스와 `바퀴 001`이 우측에 따로 떨어져 있어 한 바퀴의 결과라는 관계가 약하다 → 결과 토큰이 카운터를 통과한 뒤 문장으로 돌아가는 하나의 연속 경로로 연결하라.
  - (`s13-1-c1.jpg`) → 형광 라임 반환선이 화면 오른쪽 끝까지 크게 우회한다. 선의 시작점도 결과 카드 가장자리와 정확히 맞지 않고, 화살촉은 새 토큰이 아닌 이전 문장 쪽을 가리켜 흐름이 혼동된다 → `평평` 토큰에서 시작해 문장 끝의 삽입 위치에서 끝나는 짧고 직접적인 곡선으로 바꿔라.
  - (`s13-1-c1.jpg`) → 새 조각 `평평`이 상단 문장과 떨어져 떠 있고 “붙었다”기보다 대기 중인 버튼처럼 보인다 → 문장 끝에 실제 토큰으로 결합한 상태를 먼저 보여 준 뒤 전체 문장이 다시 투입되는 모션으로 나눠라.
  - (`s13-2-c2.jpg`) → 428회 반복을 분홍색 괄호와 점선 토큰 다섯 개로 표현했지만, “수백 번”의 규모감은 카운터 숫자에만 의존한다 → 반복 잔상, 빠르게 누적되는 토큰 띠, 회전 속도 변화 등 시간 압축의 흔적을 강화하라.
  - (`s13-2-c2.jpg`) → 분홍 손그림 괄호가 형광펜 언어와 연결되기는 하지만, 다른 정교한 UI 도형과 선질이 달라 임시 주석처럼 보인다 → 같은 형광펜 질감을 반환선·선택 강조에도 일관되게 적용하거나, 괄호를 정식 모션 그래픽으로 정돈하라.
  - (`s13-2-c2.jpg`) → 마지막 화면에는 입력 문장과 누적 결과가 함께 남아 정지 화면 완결성은 있다. 다만 완성된 “긴 답변”의 길이가 화면상 9개 토큰뿐이라 428회의 결과로 느껴지지 않는다 → 문장이 화면 밖으로 계속 이어지는 압축 띠나 축소된 여러 줄 결과를 병치하라.

### 슬라이드 18 — 도면 메타포는 제목에만 있고 화면은 다시 가로 파이프라인으로 수렴한다 (6.2/10)

- 읽히는가: 받은 글에서 다섯 항목을 뽑아 표를 만들고, 표를 이용해 새 글을 만든다는 순서는 최종 프레임에서 읽힌다. 그러나 “치수를 재고 도면을 뜬 뒤 다시 짓는다”는 건축 메타포보다는 `문서 → 설정표 → 문서` 변환 UI에 가깝다.
- 문제점:
  - (`s18-0-c0.jpg`) → 왼쪽 문서와 가운데 표가 화면 왼쪽 절반에 몰리고 오른쪽 절반이 통째로 비어 있어 미완성 화면처럼 보인다 → 시간 기반 등장 전이라면 오른쪽에 희미한 건축 예정선·빈 프레임을 남겨 의도적 공백임을 보여라.
  - (`s18-0-c0.jpg`) → 다섯 항목의 점선이 문서의 특정 문장이나 위치에서 출발하지 않고 문서 오른쪽 가장자리의 동일한 지점들에서 나온다 → 실제 측정 대상에 형광 표시를 하고, 각 표시점에서 해당 치수 항목으로 선을 연결하라.
  - (`s18-0-c0.jpg`) → 가운데 표의 다섯 칸이 동일한 크기·간격으로 나열된 기본 폼 UI다. 치수나 도면이라는 물성이 없다 → 눈금, 측정선, 기준선, 값의 단위 또는 미니 프로파일을 넣어 “재어 적는다”는 행위를 시각화하라.
  - (`s18-1-c0.jpg`) → 우측 새 글이 등장하면서 화면은 전형적인 `왼쪽 원천 → 가운데 처리 → 오른쪽 결과` 파이프라인이 된다. 슬라이드 13의 흐름 구조와 시각 문법이 겹친다 → 도면을 중앙의 dominant 요소로 두고, 원문과 새 글을 위·아래 또는 앞·뒤 레이어로 배치해 ‘해체와 재건’ 구도로 차별화하라.
  - (`s18-1-c0.jpg`) → 가운데에서 오른쪽으로 향하는 라임 화살표가 표의 특정 출력부가 아니라 카드 사이 빈 공간에서 시작하는 것처럼 보인다 → 표 외곽의 출력 포트에서 시작해 새 문서 외곽에서 정확히 종료하도록 연결하라.

## 씬 사이의 다양성

다섯 장면의 표면적 도형은 서로 다르지만, 구성 문법은 충분히 다양하지 않다.

- 슬라이드 3은 하단의 좌우 비교, 슬라이드 7은 중앙 순환, 슬라이드 9는 좌측 설명·우측 결과로 구분되어 비교적 독립적이다.
- 슬라이드 13과 18은 모두 `왼쪽 입력 → 가운데 처리 모듈 → 오른쪽 출력`의 가로 파이프라인으로 수렴한다. 특히 동일 크기 카드, 점선 연결, 형광 외곽선이라는 표현까지 겹친다.
- 슬라이드 9 역시 넓게 보면 좌측 설명과 우측 분류 결과라는 양끝 배치여서 edge-cling 문제가 반복된다.
- 균등 나열도 반복된다. 슬라이드 7의 4등분 원, 슬라이드 9의 3×3 카드, 슬라이드 13의 4단계 카드, 슬라이드 18의 5개 항목이 모두 규칙적인 UI 컴포넌트로 처리돼 서로 다른 메타포가 같은 디자인 시스템 데모처럼 보인다.
- 전체적으로 형광펜은 “강조색”으로는 작동하지만, 긋기·겹치기·번짐·잔상·수정 같은 형광펜 특유의 행위 언어는 부족하다. 중심 은유라면 외곽선 색상 이상의 역할을 맡아야 한다.

## 고칠 것 우선순위 5개

1. **의미 없는 중복 프레임 제거 또는 재설계**  
   `s03-0/1/2`, `s09-1/2`, `s18-1/2`의 차이가 거의 없다. 시간 기반 장면은 시작·과정·결과가 캡처만으로 구별돼야 한다.

2. **슬라이드 9의 ‘배’ 논리 수정**  
   “어디에도 앉지 못한다”가 아니라 “문맥 없이는 한 좌표를 고를 수 없다”가 정확하다. 세 의미로 분기되는 장면으로 바꿔야 한다.

3. **슬라이드 18을 파이프라인이 아닌 ‘측정–도면–재건’ 장면으로 전환**  
   현재 가장 제목과 시각 메타포의 거리가 멀다. 측정점, 눈금, 실제 값, 구조적 대응 표시가 필요하다.

4. **슬라이드 3에서 막대그래프 인상을 제거하고 구슬·지형의 인과를 강화**  
   동일한 10개 답이 한곳에 몰리거나 여러 곳으로 갈라진다는 사실을 실제 구슬 누적으로 보여 줘야 한다.

5. **선과 라벨의 접속·가독성 정리**  
   `s07`의 노드에 묻힌 라벨, `s13`의 과도하게 우회하는 반환선, `s18`의 불명확한 화살표 시작점처럼 연결선이 관계를 설명하기보다 장식으로 보이는 부분을 우선 교정해야 한다.
