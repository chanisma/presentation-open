## 활동지 명세 (activity-sheet-builder 인계)

- 파일: `data/2026-2/인공지능기초/인공지능이-바꾸는-세상/활동지.html` · Google Sheets(GAS) 연동
- 헤더: 수업명·학번·이름 · 테마는 덱과 동일한 라이트 퓨처리스틱
- **학번은 GCCNN 5자리**(학년1+반2+번호2, 예 20317) — 숫자만 입력되고 "2학년 3반 17번"으로 자동 풀이 표시
- **모든 입력란 필수** — 미입력 시 개수·항목명 토스트 + 첫 미입력 칸으로 자동 스크롤
- 섹션 A 「오늘의 발견」: 9개 현장 중 가장 인상 깊은 것 1개 선택(칩 아이콘 셀렉터) + 이유 2~3문장
- 섹션 B 「나의 탐구」: 스스로 찾은 AI 기술 — 기술명 / 분야 / 무엇을 하나(3문장) / 출처 URL / 패턴 칩 판정(6개 중 복수 선택)
- 섹션 C 「칩 × 분야 아이디어」: 칩 1개 선택 × 관심 분야 입력 → 아이디어 제목 + 스케치(무엇이 달라지나·누가 좋아지나) — "뻔한 답 금지" 안내문 포함
- 섹션 D 「한 문장 피치 + 토론」: 아이디어 한 문장 요약 + Waymo 토론("사람보다 나으면 충분한가") 입장 선택+근거 1문장
- 제출: Sheets 자동 기록, TXT 백업 저장 지원
- 제출 확인(2026-08-17 추가): 제출 시 **제출 암호**(4자 이상, 필수)를 함께 정한다.
  암호는 시트에 SHA-256 해시로만 저장(원문 미저장). 학생은 상단 `[제출 확인]`에서
  반/번호 · 이름 · 암호로 **마지막 제출 1건**을 조회하고, 원하면 양식에 다시 불러올 수 있다.
  구현: Apps Script `doGet(action=lookup)` — 브라우저는 fetch(CORS) 우선, 실패 시 JSONP 폴백.
  응답 코드: `ok`(제출 시각+내용) / `denied`(암호 불일치) / `notfound`(반·이름 불일치)

## 제출 현황판 (2026-08-18 추가)

- 파일: `data/2026-2/인공지능기초/제출현황.html` — **과목 단위**(과제가 늘면 카드가 자동 추가됨)
- 입장: 학번 + 이름 (스프레드시트에 `명단` 탭[학번|이름]이 있으면 수강생인지 검증하고 전체 인원을 분모로 표시)
- 보이는 것: **제출 인원 수 / 전체 인원 + 진행 막대 + 내가 냈는지**. 다른 학생의 이름·제출 여부·내용은
  화면은 물론 **서버 응답에도 담기지 않는다**(`action=board`가 count와 본인 상태만 반환)
- 내 자료: 암호 입력 → 내용 확인 → `[활동지에서 이어 쓰기]` → sessionStorage 핸드오프로
  `활동지.html?sid=…&restore=1` 로 이동해 양식이 복원됨(암호까지 채워져 바로 재제출 가능)
- 미제출자는 `[활동지 열러 가기]` 버튼으로 학번이 채워진 활동지로 이동
