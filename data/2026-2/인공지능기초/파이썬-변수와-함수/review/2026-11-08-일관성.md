장 번호 참조는 모두 실제 내용과 맞습니다. 3장→10장, 4장→12장, 7장→1·6장, 12장→4장과 노트의 앞·다음 장 참조를 확인했습니다. 활동지의 “수업에서는 매개변수가 하나였죠”도 15장과 맞으며, quiz.json의 0부터 세는 장 번호도 정확합니다.

| 9장 화면 ↔ 활동지 2번 | “지켜야 하는 규칙 … 영문자 · 숫자 · 밑줄” / “한글 이름도 동작하지만” | 규칙 서술 모순 | 영어 이름 사용 관례를 문법상 필수 규칙으로 제시했다. 활동지도 같은 제한을 문법 규칙처럼 설명한다. | “이 수업에서는 영문자·숫자·밑줄로 이름을 지어요. 숫자로 시작하거나 키워드를 쓰면 안 됩니다. 한글 이름도 가능하지만 영어 소문자와 밑줄 사용을 권합니다.” |

| 활동지 2번 ↔ 자동 점검 2번 | “값 다섯 개를 골라 변수를 만들고, print()로 확인” / “변수 5개 이상” / `prints >= 1` | 지시·자동 점검 불일치 | 지시는 변수 다섯 개를 만들고 확인하라는 뜻이지만, 점검은 여섯 개 이상도 통과시키며 출력은 한 번만 있으면 통과한다. 다섯 변수의 값을 모두 확인했는지는 검사하지 않는다. | 지시를 유지한다면 점검을 “변수 정확히 5개”, “다섯 변수의 값을 모두 출력”에 맞추기. 검사 범위를 유지한다면 “변수를 5개 이상 만들고, print()로 값을 출력해 보세요. 모든 변수의 출력 여부는 직접 확인하세요.” |

| 17장 발표자 노트 ↔ 자동 점검 규칙 | “2·3·5·6번은 실행하면 자동 점검이 붙습니다.” | 기능 안내 누락 | 규칙에는 1번 과제에도 자동 점검이 설정되어 있다. 화면에서 1번에만 자동 점검 표시가 빠진 것도 같은 불일치다. | 노트: “1·2·3·5·6번은 실행하면 자동 점검이 붙습니다.” 활동지 1번에도 “자동 점검” 표시 추가. |

| 활동지 2번 자기 점검 | “문자열에는 따옴표를, 숫자에는 따옴표 없이 썼다” | 문장 구조 오류 | 앞부분은 목적어, 뒷부분은 부사어여서 병렬 구조가 맞지 않는다. | “문자열은 따옴표로 감싸고, 숫자는 따옴표 없이 썼다.” |

삭제된 연결선·Colab·옛 버튼 이름을 가리키는 잔재는 없습니다. “평소 쓰는 비밀번호는 쓰지 마세요”의 ‘비밀번호’는 일반적인 계정 비밀번호를 뜻하므로 수정 대상이 아닙니다. ‘인자/매개변수’는 구별되어 있고, ‘돌려주는 값/반환값’도 동의어로 명시되어 있어 혼용 오류로 보지 않았습니다.

화면 텍스트만으로 확인할 수 없는 애니메이션·변수 상자 등의 존재 여부는 결함으로 단정하지 않았습니다. 파일은 수정하지 않았습니다.
