## 정식 용어

| 용어 | 학생에게 처음 제시할 풀이 |
|---|---|
| Seedance / 프롬프트 | 영상을 만드는 AI 모델 / AI에게 원하는 장면을 설명하는 입력 문장 |
| 해상도 / 화면 비율 | 화면을 이루는 픽셀의 가로·세로 크기 / 화면의 가로와 세로 길이의 비 |
| 피사체 | 화면에서 보여주려는 사람이나 사물 |
| 와이드 숏 / 클로즈업 | 주변 공간까지 넓게 보여주는 화면 / 피사체의 일부를 가까이 보여주는 화면 |
| 푸시 인 | 카메라가 피사체 쪽으로 다가가는 이동 |
| 동작 / 시간 순서 | 피사체가 하는 움직임 / 일이 일어나는 앞뒤 순서 |
| 광원 / 역광 | 빛이 나오는 곳 / 피사체 뒤쪽에서 카메라 쪽으로 들어오는 빛 |
| 시작 이미지 | 이미지→영상에서 출발 화면으로 넣는 이미지 |

정식 용어는 해당 장에서만 순서대로 소개한다. 카메라 고정·동작 방향·속도는 일상어로 설명한다. ‘영화 같은’, ‘감성적인’은 관찰 가능한 지시를 대신하지 못한다. ‘주문서’, ‘단서’ 같은 비유는 해설에만 쓰며 화면의 평가 항목은 카메라·동작·빛 등으로 표기한다.

## ELI5 적용 원칙

[ELI5](https://github.com/DreambigOu/ELI5)의 설명 원칙을 고등학생 청중에 맞춘다.

1. 구조: 무엇을 조절하는지 → 스마트폰 촬영 등 익숙한 경험 → 예시 비교 → 내 프롬프트에서 고칠 문장 순서로 설명한다.
2. 어휘: 정식 용어를 처음 보여줄 때 위 표의 풀이를 붙인다. 새 용어는 한 장에 셋 이하로 제한한다.
3. 비유: 노트의 비유는 관찰을 돕는 한 문장만 쓴다. 기능을 이해한 뒤에는 실제 영상과 프롬프트로 돌아온다.
4. 문장: 한 문장에 한 지시를 쓴다. 교사 노트는 여러분에게 직접 말할 수 있는 문장으로 쓴다.
5. 어조: ‘왜 이 문장을 바꾸는가’를 먼저 묻는다. 영문 용어 암기나 전문가 흉내를 요구하지 않는다.
6. 정확성: 카메라 효과가 특정 감정을 반드시 만든다고 단정하지 않는다. 동일 프롬프트의 결과 차이와 이미지·모델·설정의 영향을 구분한다.
7. 분량: 화면에는 핵심 질문·예시·짧은 문장을 두고, 기능 예외·수업 운영·출처 확인은 교사 노트로 내린다.

## 학습 방법 검토와 설계 결정

**제안한 흐름을 채택한다.** 예시를 관찰한 뒤 언어로 설명하고 직접 바꿔 보는 과정이 첫 생성의 성공 경험과 이어진다. 다만 다음을 조정한다.

- **용어별 효과 목록 대신 ‘만들고 싶은 장면’으로 묶는다.** 디저트를 자세히 보여주기 → 공의 움직임을 전달하기 → 같은 공간의 분위기를 바꾸기처럼 각 묶음에 연출 목적을 둔다.
- **설명 후 바로 한 문장을 바꾼다.** 세 묶음을 모두 설명한 뒤에만 학생이 말하는 구조를 피한다. 이미지 비교는 구도·빛에, 짧은 영상은 이동·시간 변화에 사용한다.
- **추론은 원문 맞히기가 아니다.** ‘관찰한 사실 → 가능한 지시 → 화면 근거’로 답한다. 여러 문장이 같은 결과를 낼 수 있다. 원문은 하나의 실제 입력 사례로 공개한다.
- **한 번에는 주로 한 요소를 수정한다.** 수정한 항목을 추적하기 쉽게 하기 위한 운영 규칙이다. 한 번의 전후 비교로 엄밀한 인과관계를 증명했다고 말하지 않는다.
- **여섯 요소를 모두 변화시킬 필요는 없다.** 카메라·공간·빛을 유지하고 피사체만 움직여도 충분하다. 명확하게 ‘무엇이 유지되고 무엇이 변하는가’를 적는 것이 목표다.

| 묶음 | 함께 배울 2~3가지 | 장면 목적 | 매체와 즉시 활동 |
|---|---|---|---|
| A. 시선의 위치 | 와이드 숏, 클로즈업, 푸시 인 | 무엇을 먼저 보고 어디에 주목할지 정하기 | 같은 디저트의 넓은/가까운 이미지 + 고정/접근 영상. ‘자세히 보여줘’를 화면 지시로 바꾸기 |
| B. 움직임의 흐름 | 피사체 동작, 방향·속도, 시간 순서 | 움직임을 알아볼 수 있게 전달하기 | 같은 공의 시작·중간·끝 영상. ‘역동적’을 ‘왼쪽에서 오른쪽으로 굴러가다가 멈춘다’로 바꾸기 |
| C. 공간과 빛 | 공간 배치, 광원 방향, 빛의 변화 | 같은 장소가 어떻게 보일지 정하기 | 같은 책상 구도의 빛 비교 이미지 + 밝기가 서서히 변하는 영상. ‘감성적’을 빛과 그림자로 바꾸기 |

## Slide 2 — Seedance를 어디서 선택할까?
- form: walkthrough
- scene: metaphor: 도구함에서 카메라 꺼내기 | emotion: 안심 | intent: 서비스와 모델을 구분하고 생성 화면에 진입한다

**핵심 메시지:** 사용할 서비스에 들어가 영상 생성 화면에서 Seedance 모델을 확인한다.

**핵심 내용:** Seedance와 프롬프트의 뜻. 수업 지정 서비스 접속 → 로그인 → 영상 생성 → 모델 확인.

**절차 대본:**
1. 창: 서비스 첫 화면 · 행동: 로그인 · 확인: 개인 작업 화면에 들어왔는가.
2. 창: 제작 화면 · 행동: 영상 생성 선택 · 확인: 영상용 입력창이 열렸는가.
3. 창: 모델 선택 · 행동: 사용할 Seedance 버전 확인 · 확인: 교사의 시연과 같은 선택인가.

**형태 설계:** 실제 확인한 화면을 바탕으로 창과 포인터를 구성한다. 클릭 가능한 [seevio.ai](https://seevio.ai/ko) 링크로 접속한다. 검증 전의 메뉴 이름·버튼 위치를 실제 화면처럼 확정하지 않는다.

**발표자 노트:** “여러분이 들어가는 사이트는 도구함이고 Seedance는 그 안에서 고르는 도구라고 생각하면 됩니다.” (모델 이름 강조) “실제로는 서비스마다 메뉴와 제공 버전이 다릅니다. 여러분 화면에서도 모델 이름을 확인하면 엉뚱한 도구로 시작하는 일을 줄일 수 있습니다.”

| 도구 사용 | 설정을 확인하고 직접 요청한 기록 및 첫 결과. 대기는 별도 상태로 기록. |
| 관찰 근거 | 카메라·동작·빛 중 화면에 실제로 보이는 변화 하나를 구체적으로 설명. |
| 수정 의도 | 학습한 영상 언어를 적용해 바꾼 문장이 식별되고, 예상 결과와 연결됨. |
| 결과 성찰 | 예상과 실제의 일치·차이를 말하고 다음 수정 방향을 제안. |

영상의 미적 완성도나 높은 해상도는 성공 기준으로 삼지 않는다. 프롬프트가 반영되지 않은 결과도 관찰과 수정 근거가 분명하면 학습 증거가 된다.

## 제작 결과

React 덱을 AI쇼츠제작 허브에 등록한다. 별도 활동지는 사용자 요청으로 제외했다. 시작·끝 스케치는 종이에 그리고 변경 문장·예상·실제 관찰은 노트 공간에 남긴다. 첫 공 영상과 다른 소재의 수정 영상을 한 요소 수정의 전후 결과로 비교하지 않는다. 공개 영상과 원문은 외부 서버 연결이 필요하며 링크 대안을 함께 제공한다. 배포·클래스룸 게시는 수행하지 않는다.


기록 공간: [수업 노트 열기](https://spacekijun.lovable.app/collab). 변경 문장·예상·실제 관찰을 남긴다. 시작·끝 그림은 필요하면 종이에 그린다.


### 실제 화면 기준 walkthrough 수정 (2026-09-16 · BytePlus 시절 기록, 아래 절로 대체됨)

2장은 Models 첫 화면의 Featured → Video generation 카드 → Seedance 입력 화면을 따른다. 4장은 중앙 입력창 아래 설정 줄을 눌러 실제 설정 패널을 연다. 기본값 16:9·720P·smart time에서 Ratio 9:16 → Resolution 480P → Duration Seconds → 5s로 바꾸고 패널을 닫는다. 공개 화면에서 실제 선택까지 확인했다. 로그인·생성 접수·완료는 수업 전 교사 계정으로 확인한다. 상세 검수는 [BytePlus walkthrough 검수](./review/2026-09-16-BytePlus-walkthrough.md)에 기록했다.


### 실습 서비스 변경 — BytePlus → seevio.ai (2026-09-17)

사용자 요청으로 실습 서비스를 [seevio.ai](https://seevio.ai/ko)로 바꾸고 2·4장의 화면 시연을
실제 공개 화면 기준으로 다시 만들었다. 수업 설계(아크·활동·영상 언어)는 그대로다.

- 2장: 첫 화면에서 텍스트-동영상 탭을 눌러 문장만으로 만드는 화면으로 가고, AI 모델이
  Seedance인지 확인한다. 이 사이트는 Seedance 말고 다른 회사 모델도 함께 제공하므로
  '도구함 안의 도구' 비유가 화면에서 그대로 보인다.
- 4장: 프롬프트 칸에 문장을 넣고 그 아래 해상도 → 길이 → 가로 세로 비율 순서로 확인하거나
  바꾼 뒤 생성 버튼 앞에서 멈춘다. 설정이 메뉴에 숨어 있지 않고 입력 칸 아래에 그대로 보인다.
- 기본값이 해상도 480p·길이 5초·비율 자동이라 학생이 실제로 바꾸는 값은 9:16 하나다.
  3장의 연습 설정 자체는 그대로 두고, 시연에서는 '확인'과 '변경'을 구분해 말한다.
- 크레딧은 초당 계산이다. Seedance 2.5 480p 5초가 50크레딧이다.
- seevio.ai는 제3자 서비스이며 모델 제공업체와 제휴 관계가 없다고 사이트에 밝히고 있다.
  학생에게 '공식 서비스'로 소개하지 않는다.
