# Seedance로 첫 영상 만들기 · 교사용 안내

- [수업 덱](../../../../?deck=seedance-first-video)
- [90분 계획과 발표자 노트 설계](./plan.md)

## 수업 전에

1. 교사와 학생이 [seevio.ai 한국어 화면](https://seevio.ai/ko)에 접속한다. 첫 화면이 곧 생성 화면이므로 텍스트-동영상 탭을 누르고 AI 모델 칸이 Seedance인지 확인한다. 영문 화면으로 열리면 주소 끝에 `/ko`를 붙인다.
2. 로그인 후 사용할 모델·해상도·길이·비율과 차감될 크레딧을 확인한다. 제작 과정에서는 공개 화면의 구조와 설정까지 확인했으며, 로그인 인증과 크레딧이 차감되는 생성은 실행하지 않았다.
3. 교사 계정에서 짧은 시험 생성을 하고 접수·완료 표시와 결과 저장 위치를 확인한다. 2·4장의 시연은 화면을 단순화한 것으로, 실제 계정 화면과 함께 보여준다.
3-1. 첫 화면 오른쪽에서 자동 재생되는 홍보 영상은 노출이 있는 인물 영상일 수 있다. 교실에 띄우기 전에 먼저 확인하고, 필요하면 화면을 내려 입력 칸부터 보여 준다.
4. 15~17장의 영상이 교실 네트워크에서 재생되는지 확인한다. 영상은 버튼을 누를 때 공식 서버에서 읽는다. 연결이 막히면 아래 출처 링크로 연다.
5. 학생이 노트 공간(spacekijun.lovable.app/collab)에 변경 문장·예상·실제 관찰을 남기도록 안내한다.

## 90분 흐름

| 구간 | 진행 |
|---|---|
| 0~15분 | 목표·접속·설정·입력 시연, 첫 생성 요청 |
| 15~39분 | 카메라 범위·이동 / 피사체 동작·시간 / 공간·빛 |
| 39~53분 | 공식 영상 세 편의 관찰·프롬프트 추론 |
| 53~59분 | 개인의 첫 생성 결과 관찰 |
| 59~69분 | 공개 사례 선택과 한 요소 수정·예상 안내 |
| 69~83분 | 노트 공간, 수정 생성, 대기 중 스케치·짝 점검 |
| 83~90분 | 완료 결과 비교·공유. 미완료는 상태를 남기고 후속 확인 |

수정 생성은 가급적 73분까지 접수한다. 생성 완료시간은 보장할 수 없다. 대기 중인 결과는 ‘완료’로 바꾸지 않고 다음 모임이나 교사가 지정한 시점에 관찰을 보완한다.

## 영상과 프롬프트 출처

세 편 모두 [Google DeepMind Veo Prompt Guide](https://deepmind.google/models/veo/prompt-guide/)의 실제 공개 영상이다. Seedance 결과로 소개하지 않는다. 2026-09-16 브라우저에서 재생 및 장면을 확인했다. 각각 8초, 원본 1920×1080이다. 원본 파일을 저장소에 복제하지 않고 공식 URL을 플레이어에서 직접 참조한다.

| 슬라이드 | 사례 | 원문에서 찾을 말 | 보는 것 |
|---|---|---|---|
| 15 | 선원 | `old sailor` | 얼굴·손·바다가 화면에 담긴 범위 |
| 16 | 사탕 키보드 | `candy` | 손가락·키의 움직임과 순서 |
| 17 | 결정 꽃 | `moon-dust` | 공간·빛·인물 이동 |

설명 공개 버튼은 **학생이 먼저 말한 뒤** 누른다. 공개 원문 요약과 관찰 예시를 구분한다. 선원 원문에는 medium shot이 있지만, 실제 결과의 범위와 반드시 같다고 판정하지 않는다. 사용자가 제공한 링크의 종이배 문장 옆 영상은 재생 때 종이 조각 장면으로 나타나 제외했다.

프롬프트 전문은 공식 페이지에서 확인한다. 덱에 들어간 새 기본안은 수업용 자작 예시로, 공식 원문 번역이 아니다. 공식 사례에서 자기 장면으로 바꾼 뒤에는 ‘공식 영상과 내 생성의 차이’와 ‘같은 모델의 수정 전후 차이’를 구분한다.

## 생성 설정 안내

9:16, 약 5초 또는 가능한 짧은 길이, 제공되는 낮은 해상도, 결과 1개부터 시작한다. seevio.ai는 로그아웃 상태에서 해상도 480p·길이 5초·비율 자동·일괄 생성 1로 시작하므로, 학생이 실제로 바꾸는 값은 가로 세로 비율 9:16 하나다. 나머지는 눌러서 그대로인지 확인만 한다. 최신·고급 모델과 높은 해상도가 수업 목표는 아니다. 크레딧은 초당으로 계산되며 Seedance 2.5 기준 480p는 초당 10, 720p는 초당 20이다. 5초 영상 한 편이 480p에서 50크레딧이다. 선택 직전에 차감될 크레딧을 확인한다. 출력 해상도를 낮춘다고 입력 이미지를 흐리게 만들지는 않는다.

## 도식과 생성 이미지

케이크 사진은 imagegen 생성 이미지다. 클로즈업 비교는 같은 사진의 CSS 크롭이다. 카메라 이동·공의 동작·광원 위치는 교사가 설명하기 위한 코드 도식으로 AI 생성 영상이 아니다. 빛 도식은 광학 시뮬레이션이 아니므로 정확한 그림자·재질 계산으로 소개하지 않는다.

## 실습 기록

- 별도 활동지 없이 노트 공간(spacekijun.lovable.app/collab)을 사용한다.
- 선택한 사례·출처, 수정 전후 문장, 바꾼 요소, 예상과 실제 관찰을 남긴다.
- 생성 중에는 시작·끝 화면을 그리거나 짝에게 문장만 보여 주고 예상 장면을 비교한다.
- 같은 장면과 설정의 수정 전후를 비교한다. 첫 공 영상과 다른 소재의 수정 영상을 전후 쌍으로 취급하지 않는다.
- 대기·오류 상태는 그대로 메모하고 완료 후 관찰을 보완한다.

## 참고한 자료

[Veo 가이드](https://deepmind.google/models/veo/prompt-guide/)에서 공통 영상 언어와 공개 사례를, [Runway 가이드](https://academy.runwayml.com/guides/prompting-guide)에서 관찰하며 지시를 수정하는 원칙을 참고했다. [ByteDance Seedance 2.5 소개](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)의 고급 기능은 첫 실습에 필수로 넣지 않았다. 사용자 제공 ChatGPT 공유 대화는 본문 접근에 실패해 참고하지 않았다.


기록 공간: [수업 노트 열기](https://spacekijun.lovable.app/collab). 변경 문장·예상·실제 관찰을 남긴다. 시작·끝 그림은 필요하면 종이에 그린다.


## seevio.ai 화면 확인

2026-09-17 공개 브라우저에서 텍스트-동영상 탭, AI 모델 목록, 프롬프트 칸, 해상도·길이·가로 세로 비율·일괄 생성·생성 버튼의 배치와 기본값을 확인했다. 슬라이드의 9:16은 수업 권장값이고, 480p와 5초는 이 사이트의 기본값과 같다. 사용할 모델은 교사가 수업 계정에서 정한다. 이 사이트는 Seedance 외에 Veo·Kling·Wan 같은 다른 회사 모델도 함께 제공하는 제3자 서비스이며, 사이트 아래쪽에 모델 제공업체와 제휴 관계가 없다고 밝히고 있다. 학생에게 '공식 서비스'로 소개하지 않는다.


### 실제 화면 기준 walkthrough 수정

2장은 첫 화면에서 텍스트-동영상 탭을 눌러 문장만으로 만드는 화면으로 가고 AI 모델이 Seedance인지 확인하는 순서를 따른다. 4장은 프롬프트 칸에 문장을 넣고 그 아래 설정을 해상도 480p → 길이 5초 → 가로 세로 비율 9:16 순서로 확인하거나 바꾼 뒤 생성 버튼 앞에서 멈춘다. 설정이 메뉴에 숨어 있지 않고 입력 칸 아래에 그대로 보이는 구조를 그대로 재현했다. 로그인·생성 접수·완료는 수업 전 교사 계정으로 확인한다. 상세 검수는 [seevio.ai walkthrough 검수](./review/2026-09-17-seevio-walkthrough.md)에 기록했고, 이전 BytePlus 버전의 기록은 [같은 폴더](./review/2026-09-16-BytePlus-walkthrough.md)에 남겨 두었다.
