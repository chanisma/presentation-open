def double(x):
    return x * 2

double(3)  # → 6

괄호로 넣은 3이 x가 되어 기계를 통과하고, return이 6을 밖으로 내보낸다 — 이 왕복이 함수의 심장이다.

SCENE 05 · 헷갈림 주의

print는 말하기, return은 건네주기

"안녕"

print("안녕") — 화면에 말하고 끝. 소리처럼 퍼지고 사라져서 변수에 담을 수 없다.

result = double(3)
6

return 6 — 상자에 담아 건네주기. 받은 값은 변수 선반에 올려두고 계속 쓴다.

둘 다 화면에 6이 보일 수 있다 — 하지만 다시 꺼내 쓸 수 있는 쪽은 return뿐이다.
