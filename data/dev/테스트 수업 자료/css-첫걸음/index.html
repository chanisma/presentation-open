SCENE 03 · class와 id

class는 여럿이 다는 이름표,
id는 단 한 명의 등번호

.team
.team#captain
.team
.team { color: teal; }
#captain { border: 2px solid pink; }

id는 한 페이지에 딱 한 번. 같은 등번호를 두 명이 달면 심판(브라우저)이 헷갈린다.
