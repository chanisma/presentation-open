1차시 명세: 데이터 탐색과 문제 발견

성취 목표

데이터의 출처와 형태를 세 갈래로 구분하고, 각 갈래에서 실제 데이터를 찾을 수 있다
확보 가능한 데이터로부터 해결 가능한 문제를 도출할 수 있다

차시 산출물: 데이터 후보 3개(출처·형태·규모 기록) + 각 데이터당 문제 문장 3개 = 문제 후보 9개
준비물: 학생 1인 1기기(인터넷), 학습지, 교사 시연용 화면
시간 배분 (50분 기준, 이론 20 : 실습 30)

구간    시간    내용
도입    5분    과목 목표와 최종 산출물 예시 제시
이론    15분    데이터 3갈래 / 쓸 만한 데이터의 조건 / 데이터→문제 전환
실습    25분    데이터 탐색(15) → 문제 문장 작성(10)
정리    5분    짝 공유 1개, 과제 안내
도입 (5분)

이번 학기에 각자 자기가 찾은 데이터로 작동하는 웹사이트를 만들어 배포하게 된다는 것을 먼저 보여줍니다. 완성 예시 1~2개를 30초씩 시연하되, "코드는 AI가 쓰지만 무엇을 만들지는 여러분이 정한다"는 문장을 이 자리에서 한 번 박아두세요. 이후 3차시 명세 활동의 복선이 됩니다.

핵심 안내: 오늘은 문제부터 정하지 않는다. 문제를 먼저 정하면 그걸 풀 데이터가 없어서 학기 중반에 멈추는 일이 생기므로, 있는 데이터에서 출발한다고 명시합니다.

이론 (15분)

① 데이터는 어디에 있는가 — 세 갈래 (7분)

갈래    예시 출처    특징
공개 데이터    공공데이터포털, 국가통계포털(KOSIS), 학교알리미, 기상자료개방포털, 지자체 데이터포털    양이 많고 즉시 확보 가능, 대신 나와 멀어서 문제 도출이 어려움
학교 안 데이터    급식 메뉴 기록, 시간표, 도서 대출 목록, 동아리·행사 안내, 학교 홈페이지 공지    문제가 잘 보이지만 정리되지 않은 형태로 존재
직접 만드는 데이터    설문, 관찰 기록, 사진 기록, 2주간 자기 기록(공부시간·수면·소비)    세상에 없던 데이터라 가치가 높음, 대신 수집 시간이 필요

각 갈래를 화면으로 30초씩 실제로 열어 보여주세요. 말로만 하면 학생 대부분이 첫 번째 갈래로만 몰립니다.

② 쓸 만한 데이터의 조건 (4분)

체크 3개로 고정합니다. 학습지에도 체크박스로 넣으세요.

행이 30개 이상인가 (사례가 여러 개여야 비교·추천·필터가 가능)
열이 3개 이상인가 (속성이 하나뿐이면 할 수 있는 게 없음)
내가 직접 열어볼 수 있는가 (CSV·엑셀·표 형태. 그림, PDF 보고서, 로그인 필요 자료는 제외)

③ 데이터에서 문제로 넘어가기 (4분)

핵심 문장 틀을 하나만 줍니다.

"[누가]는 [어떤 상황]에서 [무엇]을 몰라서 불편한데, 이 데이터가 있으면 [무엇]을 알 수 있다."

시범 예시 하나를 함께 채웁니다.

데이터: 우리 학교 1년치 급식 메뉴 기록 + 잔반량
문장: "영양사 선생님은 식단을 짤 때 어떤 메뉴가 남을지를 몰라서 곤란한데, 이 데이터가 있으면 메뉴 조합별 잔반 경향을 알 수 있다."

대조를 위해 나쁜 예도 하나 보여주세요. "급식 만족도를 조사한다"는 문장은 조사에서 끝나고 아무도 덜 힘들어지지 않는다는 점을 짚습니다. 누군가가 덜 힘들어져야 문제입니다.

실습 (25분)

단계 1 — 데이터 탐색 (15분)

세 갈래에서 각각 최소 1개씩, 총 3개를 찾아 학습지에 기록합니다. 갈래별 할당을 강제하는 게 이 활동의 핵심 장치입니다.

기록 항목: 데이터 이름 / 출처(URL 또는 위치) / 형태(CSV·엑셀·웹페이지·직접수집) / 행 수와 열 수 / 열 이름 3개 이상 적기 / 조건 체크 3개

'열 이름 적기'를 반드시 넣으세요. 파일을 실제로 열어보지 않고 제목만 보고 적어오는 것을 막는 장치이고, 2차시 구조 설계로 자연스럽게 이어집니다.

세 번째 갈래(직접 만드는 데이터)는 아직 데이터가 없으므로 **"어떤 항목을 누구에게서 며칠간 모을 것인가"**를 대신 적게 합니다.

단계 2 — 문제 문장 작성 (10분)

데이터 3개 각각에 대해 위 문장 틀로 3문장씩, 총 9문장. 여기서 학생에게 명확히 요구할 것은 문장 안의 '누가'가 매번 달라야 한다는 점입니다. 같은 데이터로 학생·교사·학부모·행정실 각각에게 무엇이 가능한지 보게 하면 문제 후보의 질이 눈에 띄게 올라갑니다.

정리 (5분)

3~4명이 자기 문제 문장 중 가장 마음에 드는 것 하나씩만 발표합니다. 교사는 평가하지 말고 "그 데이터 어디서 찾았어?"만 물으세요. 다른 학생의 탐색 경로가 공유되는 게 이 시간의 목적입니다.

과제: 문제 문장 9개 중 3개에 표시해 올 것. 판단 기준은 재미가 아니라 "이 데이터를 다음 주까지 실제로 손에 넣을 수 있는가". 2차시 도입에서 이 3개 중 1개를 확정합니다.

평가 체크포인트
세 갈래를 모두 채웠는가 (한 갈래에만 몰린 경우 지도 필요)
열 이름을 구체적으로 적었는가 (파일을 실제로 열었는지 판별)
문제 문장에 수혜자가 명시되어 있는가
예상 문제와 대응

"찾을 게 없어요"가 10분 안에 나옵니다. 학교 안 데이터 목록을 미리 5~6개 뽑아 둔 예비 카드를 준비해두세요. 도서 대출 목록, 시간표, 동아리 명단 정도면 충분합니다.

거대한 국가 통계표를 가져오는 학생이 반드시 있습니다. 행 수는 많지만 자기와 무관해 문제 문장이 안 나옵니다. "이 표에서 우리 학교·우리 지역만 남기면 몇 행인가"로 좁히게 하세요.

AI에게 바로 물어보는 학생도 나옵니다. 막지 말고 조건을 붙이세요. AI가 알려준 데이터는 실제 URL을 열어 파일을 확인한 것만 학습지에 적을 수 있다고 하면, 존재하지 않는 데이터셋을 그대로 적어오는 문제가 걸러집니다.
