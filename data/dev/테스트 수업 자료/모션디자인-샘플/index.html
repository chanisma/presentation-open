01 — 스킬을 어떻게 썼나

표를 읽고, 값을 고르고, 마지막에 검수한다

이 스킬은 애니메이션 코드를 주지 않는다. 결정 순서를 준다. 그래서 작업은 아래 네 단계로 흘렀고, 8컷 모두 같은 순서를 밟았다.

STEP 1

컨텍스트 확정

“누가, 어디서, 몇 번 보나”를 먼저 못 박는다. 관객은 교실 뒷자리 학생, 매체는 프로젝터, 같은 모션을 한 학기 내내 본다.

여기서 두 가지가 결정됐다 — 콘텐츠 타입은 낮은 모션 밀도, 플랫폼 티어는 Desktop이 아니라 TV/Kiosk(1.3×).

director/context-adaptation.md §Platform Scaling, §Content Type
director/decision-framework.md §Audience, §Context

STEP 2

모션 아이덴티티 고정

퍼스널리티를 하나만 고르고 상수 3개를 박아둔다. 컷마다 감으로 정하면 8컷이 8가지 성격이 된다.

Corporate 선택 → 시그니처 이징 1개, 지속시간 3단, 등장 패턴 1개. 이후 모든 값은 여기서 파생된다.

director/motion-personality.md §Brand Motion Identity
reference/timing-easing-tables.md §Duration by Personality

STEP 3

컷별 8단계 체크리스트

감정 → 퍼스널리티 → 주 속성 → 지속 → 이징 → 히어로 → 3개 레이어 → 1/3 규칙. 여덟 칸을 채우기 전에는 코드를 쓰지 않는다.

패턴 파일에 이미 레시피가 있으면 그대로 쓰고, 없으면 표에서 값을 뽑아 조립한다.

SKILL.md §8-Step Checklist

STEP 4

품질 검수

CRITICAL 4개 규칙(선형 이징 금지 · 불투명도 단독 금지 · 1/3 화면 · 3개 레이어)을 컷마다 통과시키고, 증상별 처방표로 되돌아본다.

여기서 실제로 두 컷이 수정됐다 — 전환 컷의 이동 거리와 스태거 총량.

02 — 브랜드 모션 아이덴티티

이 덱이 쓰는 상수 세 개

스킬은 “알아볼 수 있는 모션”의 조건으로 시그니처 이징 · 지속시간 팔레트 · 등장 패턴 딱 세 가지를 고정하라고 말한다. 8컷 전부가 아래 값만 쓴다.

① 시그니처 이징

전체의 80%는 MD3 Standard 하나로 간다. 나머지는 방향 규칙 — 등장은 감속, 퇴장은 가속 — 에 따라 정해진 4개만 쓴다.

② 지속시간 팔레트

Corporate 아키타입의 3단 값에 투사 보정 1.3배를 곱한 값이 이 덱의 전부다. 그 외의 숫자는 쓰지 않는다.

티어Corporate 기본× 1.3쓰는 곳
Quick200ms260ms불릿 1줄, 라벨
Standard300ms390ms카드, 막대, 하이라이트
Slow450ms580ms타이틀 리빌, 수치 카운트

예외 — 스케일하지 않는 값. 호버 100ms · 누름 150ms · 오답 흔들림 350ms는 “보기 좋은 길이”가 아니라 지각 한계다. 투사 보정을 곱하면 반응이 굼떠 보인다.

③ 등장 패턴

모든 요소는 아래에서 20~24px + 불투명도 하나로만 들어온다. 컷마다 방향이 바뀌면 혼란이 된다는 것이 스킬의 Spatial Origin Consistency 규칙.

아키타입 기본값에서 의도적으로 벗어난 지점: Corporate의 표준 등장은 “오른쪽에서 슬라이드”지만, 투사 슬라이드는 관객이 아래에서 위로 읽어 올라간다. 방향 표의 below = arrival을 근거로 아래에서 올라오는 쪽을 택했다.

03 — 샘플

슬라이드 한 장이 살아가는 순서대로

8컷은 취향대로 고른 목록이 아니라 수업 슬라이드가 실제로 지나가는 순서다 — 표지가 열리고(01), 내용이 쌓이고(02), 데이터가 등장하고(03·04), 핵심이 강조되고(05), 학생이 답하고(06), 다음 장으로 넘어가고(07), 설명하는 동안 화면이 숨 쉰다(08). 컷 번호는 그 순서를 가리킨다.

// 선형 카운트는 "기계가 세는" 느낌이 난다. 감속 곡선을 태워
// 목표값 근처에서 속도가 줄도록 만든다 (MD3 Decelerate 근사).
function countUp(el, target, ms) {
  const t0 = performance.now();
  const tick = now => {
    const p = Math.min(1, (now - t0) / ms);
    const eased = 1 - Math.pow(1 - p, 3);          // ease-out-cubic
    el.textContent = Math.round(target * eased);
    if (p < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
}

Ambient

교사가 3분간 설명하거나 학생이 활동하는 동안 떠 있는 화면. 죽지도, 방해하지도 않아야 한다.

/* 같은 주기로 띄우면 셋이 한 몸처럼 붙어 움직인다.

04 — 품질 검수

CRITICAL 규칙 네 개를 8컷 전부에 대고 확인

스킬은 규칙에 심각도를 매긴다. CRITICAL은 “절대 깨지 말 것”. 아래는 8컷을 그 네 항목으로 훑은 결과이고, 두 항목에서 실제로 되돌아가 고쳤다.

CRITICAL 규칙결과근거 / 조치
공간 이동에 선형 이징 금지 통과 모든 transform 애니메이션이 5개 지정 곡선 중 하나를 쓴다. 선형은 어디에도 없다 — 스피너·진행바가 이 덱에 없기 때문.
중요한 상태 변화에 불투명도 단독 금지 수정함 S-02 불릿이 처음엔 페이드만 했다. 위로 20px 상승을 더해 “도착”이 읽히도록 고쳤다. S-06 판정도 색만 바꾸지 않고 스케일·위치를 함께 움직인다.
화면의 1/3 초과 이동 금지 수정함 S-07 전환의 슬라이드 변위를 100% → 26%로 줄이고 남은 거리감을 불투명도에 넘겼다. 나머지 컷의 최대 변위는 20px.
주 · 보조 · 앰비언트 3개 레이어 필수 통과 8컷 모두 세 층을 갖는다. 각 컷의 결정 시트 7번 항목에 어느 요소가 어느 층인지 적어 두었다.
스태거 총량 500ms 미만 (HIGH) 통과 최대치는 S-04 차트의 348ms(58ms × 6). S-02는 260ms.
모션 축소 대안 제공 (HIGH) 통과 prefers-reduced-motion일 때 공간 이동·클립·오버슛을 전부 제거하고 200ms 페이드만 남긴다. 앰비언트 루프는 정지. 카운트업은 최종값을 즉시 표시.
100번째 시청에도 괜찮은가 통과 한 학기 반복될 S-07 전환은 오버슛 0%·총 650ms로 가장 절제했다. 오버슛이 큰 연출은 하루 몇 번뿐인 S-06 정답 판정에만 남겼다.

06 — 실제 수업 자료에 붙이기

세 가지 덱 유형에 그대로 이식된다

모든 값은 CSS 커스텀 프로퍼티 하나로 모여 있다. 토큰 블록만 옮기면 레거시 HTML 덱이든 React 덱이든 같은 성격의 모션이 나온다.

레거시 HTML 덱

data/<그룹>/<과목>/<수업>/index.html의 <style>에 토큰 블록과 필요한 @keyframes만 복사한다. 의존성이 없다.

:root{
  --ts:1;
  --d-quick: calc(260ms * var(--ts));
  --d-std:   calc(390ms * var(--ts));
  --d-slow:  calc(580ms * var(--ts));
  --e-std:  cubic-bezier(.2,0,0,1);
  --e-emph: cubic-bezier(.05,.7,.1,1);
  --e-accel:cubic-bezier(.3,0,1,1);
}

네이티브 React 덱

클릭 빌드 단계에 붙일 때는 CSS 그대로. 씬(타임라인) 덱이라면 src/scene의 useSceneTime() t(초)를 같은 곡선의 순수 함수로 옮긴다.

// 260ms · MD3 Standard 를 t 함수로
const p  = clamp01((t - 0.13) / 0.26);
const y  = interpolate(p, [0,1], [20,0],
             { easing: bezier(.2,0,0,1) });

스태거는 delay = 0.065 * i로 동일하게 유지한다.

라이브 퀴즈 레이어

S-06 판정 컷은 live/runtime/의 학생 화면 피드백에 그대로 얹힌다. 정답은 Playful, 오답은 Corporate — 두 성격을 섞지 않는 것이 핵심이다.

오답 흔들림 350ms는 투사 보정을 곱하지 않는다. 학생 기기(모바일)에서는 오히려 0.8배 티어라 더 짧아도 된다.

모션 축소 대응

애니메이션을 거는 요소에 .mo 클래스를 함께 붙여 두면, 아래 한 블록으로 전체가 안전한 페이드로 내려앉는다.

@media (prefers-reduced-motion: reduce){
  .mo{ animation: rmFade 200ms linear both !important;
       animation-delay: 0ms !important;
       transform: none !important;
       clip-path: none !important; }
}
