## Slide 1 — 손이 100번 박수치라면? — 반복은 컴퓨터의 특기

**핵심 메시지 (Heading):** 사람은 지치지만 컴퓨터는 안 지친다 — 반복은 컴퓨터에게 시키자.

**핵심 내용 (Key Points):**
- "박수 100번 쳐!" — 사람은 힘들고, 빼먹기 쉬움
- 줄지어 선 오리들처럼 똑같은 행동을 끝없이
- 컴퓨터는 똑같은 일을 지치지 않고 정확하게
- 오늘 배울 마법의 키워드: `for`, `while`

**비주얼 가이드 (Visual Concept):**
화이트보드 중앙에 한 줄로 늘어선 작은 오리들 손그림 (검정 마커, 부리·날개를 빨간 마커로 포인트) — 끝에 점점점 ... 표시. 왼쪽 위에 지쳐있는 사람 손그림 + 말풍선 "100번 박수…?". 오른쪽에는 웃는 컴퓨터 모니터 손그림 + 말풍선 "쉽지!". 하단에 큰 글씨 "for · while" (파란 마커).

**발표자 노트 (Presenter Note):**
"여러분, '박수 100번 쳐!' 하면 어떨까요? 100까지 세다가 헷갈리고, 손도 아프죠. 그런데 컴퓨터한테 시키면 1초 만에 끝나고, 1만 번도 1초 만에 끝나요. 오늘은 이 '시키는 법'을 배웁니다."

## Slide 2 — 반복문이란? 같은 일을 반복하는 명령

**핵심 메시지 (Heading):** 반복문은 코드 한 덩어리를 정해진 만큼 반복 실행하는 명령이다.

**핵심 내용 (Key Points):**
- "이 코드를 ___번 반복해" 명령
- 두 가지 형태: **`for`**(정해진 횟수)와 **`while`**(조건이 참인 동안)
- 반복할 내용은 **들여쓰기**로 표시
- 데이터 처리·자동화의 핵심

**비주얼 가이드 (Visual Concept):**
중앙에 큰 원형 화살표(↻) 손그림 (파란 마커) — 안에 "REPEAT" 손글씨. 원 주변에 작은 코드 박스 "행동"이 화살표를 따라 빙글빙글. 좌측에 'for' 박스(파랑), 우측에 'while' 박스(빨강). 아래 한 줄: "들여쓰기로 반복할 코드 구분".

**발표자 노트 (Presenter Note):**
"반복문은 두 가지가 있어요. 횟수가 정해져 있으면 `for`, 조건이 참인 동안 돌아야 하면 `while`. 둘 다 핵심 규칙은 똑같아요 — 반복할 코드를 들여쓰기로 묶어주는 것."

## Slide 3 — for + range — 가장 기본 형태

**핵심 메시지 (Heading):** `for x in range(N):` 은 0부터 N-1까지 N번 반복하는 마법 주문.

**핵심 내용 (Key Points):**
- 형태: `for 변수 in range(N): 코드`
- `range(5)`는 0, 1, 2, 3, 4 (5개)
- 변수가 매 회 바뀌면서 코드 실행
- 콜론(:) 과 들여쓰기 4칸 필수

**비주얼 가이드 (Visual Concept):**
왼쪽 코드 박스(검정 손글씨):
```
for x in range(5):
    print(x)
```
오른쪽에 실행 흐름 도식 — `x = 0 → print(0)`, `x = 1 → print(1)`, ... `x = 4 → print(4)`. 각 단계에 작은 화살표(파랑). 아래 출력 박스 "0 1 2 3 4". 빨간 마커 강조: "⚠️ range(5)는 0~4 (5는 포함 X)".

**발표자 노트 (Presenter Note):**
"`range(5)`라고 하면 0부터 시작해서 5는 안 들어가요. 그래서 0, 1, 2, 3, 4 — 다섯 번 도는 거죠. 영어로도 'range of five'. 헷갈리지 마세요."

---

## Slide 4 — range의 3가지 모습

**핵심 메시지 (Heading):** range는 시작·끝·간격까지 자유자재로 조절할 수 있다.

**핵심 내용 (Key Points):**
- `range(N)` → 0부터 N-1
- `range(A, B)` → A부터 B-1
- `range(A, B, C)` → A부터 B-1까지 C씩
- 음수도 가능: `range(10, 0, -1)`

**비주얼 가이드 (Visual Concept):**
화이트보드에 3행 표 (손그림 격자, 파란 마커):
| 형태 | 의미 | 결과 |
|------|------|------|
| `range(5)` | 0~4 | 0,1,2,3,4 |
| `range(1, 6)` | 1~5 | 1,2,3,4,5 |
| `range(0, 10, 2)` | 0~9, 2씩 | 0,2,4,6,8 |
오른쪽에 수직선(number line) 손그림 — 0부터 10까지 눈금, 빨간 점프로 0→2→4→6→8 표시.

**발표자 노트 (Presenter Note):**
"숫자 한 개만 쓰면 시작은 0, 두 개면 시작·끝, 세 개면 간격까지. 짝수만 뽑고 싶다? `range(0, 10, 2)`. 거꾸로 세고 싶다? `range(10, 0, -1)`."

## Slide 5 — for로 리스트 순회 — 데이터 한 줄씩 꺼내기

**핵심 메시지 (Heading):** for는 숫자뿐 아니라 리스트의 모든 값을 하나씩 꺼낸다.

**핵심 내용 (Key Points):**
- 리스트: 여러 값의 묶음 `["사과", "배", "귤"]`
- `for 변수 in 리스트:` 형태
- 변수에 리스트 값이 하나씩 들어옴
- 이름 출석부, 점수 평균, 학생 분류에 유용

**비주얼 가이드 (Visual Concept):**
왼쪽에 코드 박스:
```
이름 = ["Alpha", "Bravo", "Charlie"]
for x in 이름:
    print(x, "출석")
```
오른쪽에 출석부 손그림 — 종이 한 장에 이름 3개와 체크 ✓. 가운데 변수 `x` 박스에 화살표 3개(Alpha → Bravo → Charlie). 각 호출마다 `print(x, "출석")` 결과: "Alpha 출석", "Bravo 출석", "Charlie 출석".

**발표자 노트 (Presenter Note):**
"리스트는 여러 값을 묶어놓은 거예요. for 문에 통째로 넣으면 컴퓨터가 알아서 한 개씩 꺼내줘요. 출석 부르듯이! 이게 데이터를 다룰 때 정말 강력합니다."

---

## Slide 6 — while — 조건이 거짓이 될 때까지

**핵심 메시지 (Heading):** while은 횟수를 모를 때 — 조건이 참인 동안 계속 반복한다.

**핵심 내용 (Key Points):**
- 형태: `while 조건식: 코드`
- 조건이 참이면 코드 실행 → 다시 조건 확인 → 반복
- 조건이 거짓이 되면 멈춤
- 반드시 조건을 변경하는 코드 필요 (안 그러면 무한 루프)

**비주얼 가이드 (Visual Concept):**
중앙에 회전 루프 다이어그램 (파란 마커) — "조건 확인 마름모 → True → 코드 실행 → 다시 마름모". False 가지는 빨간 마커로 "탈출 →". 왼쪽 코드:
```
x = 0
while x < 5:
    print(x)
    x = x + 1
```
오른쪽 화살표: "x를 1씩 늘려야 멈춤!"

**발표자 노트 (Presenter Note):**
"`while`은 '~인 동안'이라는 영어 뜻 그대로예요. x가 5보다 작은 동안 계속 돌아라. 그런데 핵심은 매번 x를 1씩 늘려줘야 한다는 거. 안 그러면 영원히 돌아요. 무서운 무한 루프!"

---

## Slide 7 — for vs while — 언제 무엇을 쓸까?

**핵심 메시지 (Heading):** 횟수를 알면 for, 조건만 알면 while.

**핵심 내용 (Key Points):**
- `for`: 횟수가 정해진 경우 — "5번", "리스트 다 돌기"
- `while`: 조건이 만족되는 동안 — "사용자가 'q'를 누를 때까지"
- 보통 for이 더 안전 (무한 루프 위험 낮음)
- while은 게임 메인 루프, 입력 검증에 강력

**비주얼 가이드 (Visual Concept):**
좌우 분할(파란 마커 세로선):
- 왼쪽 (for): 코드 `for x in range(5): print(x)` + 작은 도식 "1, 2, 3, 4, 5번째 끝!" + 초록 ✓ "횟수가 정해짐"
- 오른쪽 (while): 코드 `while x < 5: ...` + 작은 도식 "조건이 거짓이 될 때까지" + 노란 ⚠️ "조건 변경 필수"

**발표자 노트 (Presenter Note):**
"외울 게 아니라 상황을 생각하세요. '몇 번 반복할지 미리 알아?' 그럼 for. '뭐가 일어날 때까지 반복할지만 알아?' 그럼 while. 둘 다 똑같은 결과를 만들 수도 있지만, 더 자연스러운 게 있어요."

---

## Slide 8 — break / continue — 반복 안에서 점프하기

**핵심 메시지 (Heading):** break는 즉시 탈출, continue는 다음 회차로 점프.

**핵심 내용 (Key Points):**
- `break`: 반복문 즉시 종료 (감옥 탈출)
- `continue`: 현재 회차 건너뛰고 다음 회차로
- 조건문(if)과 함께 자주 쓰임
- 예: 입력 받다가 'q' 입력 시 종료

**비주얼 가이드 (Visual Concept):**
좌우 분할:
- 왼쪽 (break):
```
for x in range(10):
    if x == 5:
        break
    print(x)
```
도식: 0,1,2,3,4 출력 → 5에서 빨간 X "감옥 탈출!"
- 오른쪽 (continue):
```
for x in range(5):
    if x == 2:
        continue
    print(x)
```
도식: 0,1 출력 → 2 건너뛰기 → 3,4 출력 (회색 X로 2 표시)

**발표자 노트 (Presenter Note):**
"break는 '문 부수고 나가!', continue는 '이번 건 패스!'. 게임에서 적을 만나면 break으로 게임 오버, 가시 함정은 continue로 그냥 무시. 이런 식으로 흐름을 자유롭게 조절할 수 있어요."

## Slide 9 — 중첩 반복문 — 반복 안의 반복

**핵심 메시지 (Heading):** 반복문 안에 또 반복문을 넣으면 표·격자·구구단을 만들 수 있다.

**핵심 내용 (Key Points):**
- 바깥쪽 1회마다 안쪽 N회 실행 (총 N×N회)
- 구구단·구슬 격자·이미지 픽셀 처리에 활용
- 들여쓰기 8칸으로 안쪽 코드 표시
- 변수 이름을 다르게 (예: i, j)

**비주얼 가이드 (Visual Concept):**
왼쪽 코드 — 구구단 2단:
```
for i in range(2, 10):
    for j in range(1, 10):
        print(f"{i}×{j}={i*j}")
```
오른쪽에 격자 도식 (손그림 표) — 가로 9칸 × 세로 8줄. 각 칸에 작은 점. 빨간 화살표 "→" 으로 j 진행, 파란 화살표 "↓"로 i 진행. 위에 ⏱ "총 72번 실행".

**발표자 노트 (Presenter Note):**
"바깥쪽 반복문이 한 번 돌 때마다 안쪽 반복문이 처음부터 끝까지 한 바퀴를 돌아요. 그래서 곱하기. 2×9=18번? 아니죠, 8단부터 9단이니까 8×9=72번! 구구단 외울 때 손가락 이렇게 헤아리는 거랑 똑같아요."

## Slide 10 — 실습 1: 1부터 100까지 합 구하기

**핵심 메시지 (Heading):** 가우스가 어릴 때 풀던 그 문제 — for 한 줄로 끝낸다.

**핵심 내용 (Key Points):**
- 합계 변수 초기화 `total = 0`
- for로 1~100 더하기
- 결과 출력
- 정답: 5050 (가우스의 공식과 일치)

**비주얼 가이드 (Visual Concept):**
중앙에 빈칸 코드 (학생이 채울 부분 노란 형광펜):
```
total = ___          # 빈칸 1: 0
for x in range(___, ___):   # 빈칸 2, 3: 1, 101
    total = total + ___      # 빈칸 4: x
print(total)
```
오른쪽에 작은 가우스 손그림 + 말풍선 "1+2+…+100 = ?" → 큰 화살표 → 답 박스 "5050". 빨간 마커: "5초만에 끝!".

**발표자 노트 (Presenter Note):**
"옛날에 가우스라는 수학자가 어릴 때 선생님이 1부터 100까지 더하라고 했더니 몇 초 만에 5050이라고 답했대요. 우린 컴퓨터로 5초면 돼요. for 문 단 세 줄."

## Slide 11 — 실습 2: 별 직각삼각형 그리기

**핵심 메시지 (Heading):** 중첩 반복문으로 별 그림을 그려보자.

**핵심 내용 (Key Points):**
- 5줄: 1개, 2개, 3개, 4개, 5개 별
- 바깥 for: 줄 수 (1~5)
- 안쪽 for: 별 개수 (1~i)
- `print("*", end="")` 으로 줄바꿈 없이

**비주얼 가이드 (Visual Concept):**
왼쪽 코드:
```
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
```
오른쪽에 결과 박스 (손글씨):
```
*
**
***
****
*****
```
아래에 노란 마커 메모: "💡 end=''는 줄바꿈 막기".

**발표자 노트 (Presenter Note):**
"중첩 반복문의 대표 예시예요. 바깥쪽이 줄을 만들고, 안쪽이 그 줄에 별을 찍어요. `end=''`는 print가 자동으로 줄바꿈하는 걸 막는 옵션입니다. 별 5개씩 늘어나는 삼각형 완성!"

## Slide 12 — ⚠️ 무한 루프 함정 + 자주 하는 실수

**핵심 메시지 (Heading):** 반복문에서 가장 무서운 함정은 — 끝나지 않는 것.

**핵심 내용 (Key Points):**
- ❶ **무한 루프**: while에서 조건 변경 빠뜨림 → Ctrl+C 로 강제 종료
- ❷ **off-by-one**: `range(N)`은 0~N-1, N 미포함
- ❸ 들여쓰기 누락 → IndentationError
- ❹ for 변수와 리스트 헷갈림

**비주얼 가이드 (Visual Concept):**
4사분면 분할 — 각 칸에 빨간 ✗ 코드 + 초록 ✓ 코드. 중앙에 큰 ♾️ 무한 기호와 사이렌 손그림 ⚠️ (빨간 마커).
예:
```
✗ while x<5: print(x)      ✓ while x<5: print(x); x+=1
✗ for i in range(1,10):     ✓ for i in range(1,11):
   (10 미포함, 1~9만)            (10 포함, 1~10)
✗ print("hi")               ✓     print("hi")
```

## Slide 13 — 어디에 쓰일까? + 한눈에 정리

**핵심 메시지 (Heading):** 게임·영상·추천·시뮬레이션 — 반복문은 거의 모든 프로그램의 심장이다.

**핵심 내용 (Key Points):**
- 🎮 게임 메인 루프: 매 프레임 그리기
- 🎬 영상 인코딩: 프레임마다 압축
- 🎵 음악 플레이리스트: 한 곡씩 재생
- 🤖 머신러닝 학습: 데이터 수천 번 반복

**비주얼 가이드 (Visual Concept):**
왼쪽 절반: 4분할 응용 그리드(작은 아이콘 + 의사코드):
```
🎮 while not 게임끝:    🎬 for 프레임 in 영상:
   화면 그리기                압축하기

🎵 for 곡 in 플레이리스트:  🤖 for epoch in range(100):
   재생하기                   학습하기
```
오른쪽 절반: 마인드맵 — 중심 "반복문 for/while". 4갈래:
- "FORMS" (파랑) → for/while
- "TOOLS" (초록) → range, break, continue
- "TRAPS" (빨강) → 무한루프 ⚠️, off-by-one
- "USES" (검정) → 게임·데이터·자동화 → 🚀

**발표자 노트 (Presenter Note):**
"여러분이 즐기는 모든 게임의 심장에는 while True가 있어요. 영상 재생도, 음악 추천도, AI 학습도 다 반복문. 오늘 배운 4갈래 — 형태·도구·함정·쓸 곳 — 만 기억하면 반복문은 끝났어요!"
