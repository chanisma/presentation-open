## Slide 1 — 오늘도 우리는 수많은 "만약"을 만난다

**핵심 메시지 (Heading):** 우리의 하루는 "만약"의 연속, 컴퓨터에게도 이 사고를 가르쳐보자.

**핵심 내용 (Key Points):**
- "비가 오면 우산을 챙긴다" — 일상 속 조건적 행동
- "성적이 90점 이상이면 A등급" — 분기점
- 컴퓨터는 사람의 결정을 어떻게 흉내내나?
- 오늘 배울 마법의 단어: `if`

**비주얼 가이드 (Visual Concept):**
화이트보드 중앙에 갈림길 도식 — 두 갈래로 나뉘는 길 끝에 ☂️와 ☀️ 아이콘. 왼쪽 위에 사람이 고민하는 손그림. 위쪽에는 빨간 마커로 큰 글씨 "MAYBE? OR?" 와 화살표. 오른쪽에는 노란 경고 표지판에 "선택 → 결과" 표시.

**발표자 노트 (Presenter Note):**
"여러분, 오늘 학교 오는 길에 몇 번이나 선택을 했나요? 아침에 일어날까 5분만 더 잘까, 우산을 챙길까 말까. 사실 우리 뇌는 1초에도 수백 번 '만약 ~라면'을 굴리고 있어요. 오늘은 컴퓨터에게 이 '만약'을 가르치는 법을 배워봅시다."

## Slide 2 — 조건문이란? 컴퓨터의 갈림길

**핵심 메시지 (Heading):** 조건문은 어떤 조건의 참/거짓에 따라 다른 행동을 선택하는 명령이다.

**핵심 내용 (Key Points):**
- 조건문 = `if` (만약) ~ 라면, ~ 를 해라
- 결과는 단 두 가지: **참(True)** 또는 **거짓(False)**
- 마법의 키워드: `if` / `elif` / `else`
- 갈림길의 분기점에서 컴퓨터가 결정한다

**비주얼 가이드 (Visual Concept):**
중앙에 큰 손그림 마름모(다이아몬드) — 안에 "조건?" 글씨. 마름모에서 두 갈래 화살표 — TRUE는 초록색 마커로 ↘ "행동 1", FALSE는 빨간 마커로 ↙ "행동 2". 마름모 옆에 작은 메모: "조건 = 참/거짓이 결정되는 표현식".

**발표자 노트 (Presenter Note):**
"마름모 모양 보이죠? 이게 바로 갈림길이에요. 컴퓨터가 이 마름모 안의 질문에 '응(True)'이라고 답하면 오른쪽, '아니(False)'면 왼쪽으로 갑니다. 이걸 만드는 게 바로 if 문이에요."

---

## Slide 3 — 가장 단순한 if (참일 때만 행동)

**핵심 메시지 (Heading):** if 만 쓰면 — 조건이 참일 때만 한 가지 행동을 한다.

**핵심 내용 (Key Points):**
- 형태: `if 조건: 행동`
- 거짓이면 아무 일도 일어나지 않음
- 콜론(:)과 들여쓰기 4칸 필수
- 예) 점수가 60점 이상이면 "통과" 출력

**비주얼 가이드 (Visual Concept):**
왼쪽에 코드 박스(검정 마커 손글씨):
```
score = 75
if score >= 60:
    print("통과")
```
오른쪽에 한쪽으로만 갈리는 도식 — 마름모에서 TRUE는 초록 화살표 → "통과 출력", FALSE는 그냥 끝 (회색 X 표시).
하단에 빨간 마커 강조: ⚠️ "콜론(:) 잊지 마세요!"

**발표자 노트 (Presenter Note):**
"이게 가장 기본 형태예요. 마치 '시험 점수가 60점 이상이면 SNS에 자랑하기'처럼, 조건이 맞을 때만 행동하는 거죠. 조건이 안 맞으면? 아무 일도 안 일어나요. 그냥 지나가는 거예요."

---

## Slide 4 — if-else (둘 중 하나는 무조건 한다)

**핵심 메시지 (Heading):** if-else는 참이면 A, 거짓이면 B — 둘 중 하나는 반드시 실행된다.

**핵심 내용 (Key Points):**
- 형태: `if 조건: 행동A   else: 행동B`
- 양 갈래 모두 결과가 있음
- 실생활: 로그인 성공/실패, 합격/불합격
- "이것 아니면 저것" 사고

**비주얼 가이드 (Visual Concept):**
왼쪽 코드 박스:
```
password = "1234"
input_pw = "1234"
if input_pw == password:
    print("로그인 성공")
else:
    print("비밀번호 틀림")
```
오른쪽에 양 갈래 도식 — TRUE 초록 화살표 → 😄 "로그인 성공", FALSE 빨간 화살표 → 😱 "실패". 마름모 위에 "비밀번호 같나?" 손글씨.

**발표자 노트 (Presenter Note):**
"인스타그램 로그인할 때 비밀번호가 맞으면 들어가고, 틀리면 다시 입력하라고 뜨죠? 이게 if-else예요. 참일 때 갈 길, 거짓일 때 갈 길이 둘 다 정해져 있어요."

---

## Slide 5 — if-elif-else (선택지가 여러 개일 때)

**핵심 메시지 (Heading):** elif는 "그러면 만약~"의 줄임 — 여러 갈래에서 가장 먼저 맞는 것 하나만 실행된다.

**핵심 내용 (Key Points):**
- 위에서부터 조건을 차례로 검사
- 처음으로 참이 되는 분기 하나만 실행
- 어느 것도 참이 아니면 `else`로
- 예: 나이에 따른 학생 구분 (초/중/고/성인)

**비주얼 가이드 (Visual Concept):**
왼쪽 코드 박스:
```
age = 17
if age <= 13:
    print("초등학생")
elif age <= 16:
    print("중학생")
elif age <= 19:
    print("고등학생")
else:
    print("성인")
```
오른쪽에 사다리형 도식 — 마름모가 위에서 아래로 3개 연결되어 점점 좁아지는 흐름. 각 단계마다 TRUE는 옆으로 빠지는 화살표, FALSE는 아래로 이어짐. 마지막 단계 아래에 else 박스.

**발표자 노트 (Presenter Note):**
"학원에서 '초등부, 중등부, 고등부, 성인부' 강의실로 나누는 것과 똑같아요. 나이를 확인해서 위에서부터 차례차례 검사하는 거죠. 한 번 들어맞으면 나머지는 검사도 안 해요."

---

## Slide 6 — 조건을 만드는 도구: 비교 연산자

**핵심 메시지 (Heading):** 조건을 만들려면 두 값을 비교해야 한다 — 비교 연산자 6총사.

**핵심 내용 (Key Points):**
- 같다: `==` (등호 두 개! 한 개는 대입)
- 다르다: `!=`
- 크기 비교: `>`, `<`, `>=`, `<=`
- 비교 결과는 항상 True 또는 False

**비주얼 가이드 (Visual Concept):**
화이트보드에 표 형태(손그림 격자):
| 연산자 | 의미 | 예시 |
|--------|------|------|
| `==` | 같다 | 5 == 5 → True |
| `!=` | 다르다 | 5 != 3 → True |
| `>` | 크다 | 5 > 3 → True |
| `<` | 작다 | 5 < 3 → False |
| `>=` | 크거나 같다 | 5 >= 5 → True |
| `<=` | 작거나 같다 | 5 <= 3 → False |
빨간 마커 강조: ⚠️ "`=` 와 `==` 헷갈리지 말기!"

**발표자 노트 (Presenter Note):**
"여기서 가장 자주 실수하는 게 등호예요. 수학에서는 등호 한 개 쓰지만, 파이썬에서는 '같다'를 물어볼 때 반드시 `==` 두 개! 한 개는 '값 넣기'예요. 명심하세요."

## Slide 7 — and / or — 여러 조건을 한 줄로

**핵심 메시지 (Heading):** 중첩 if를 쓰기 전에 and와 or을 떠올리자 — 코드가 훨씬 깔끔해진다.

**핵심 내용 (Key Points):**
- `and`: 좌우 모두 참이어야 참 (둘 다 만족)
- `or`: 좌우 중 하나만 참이어도 참
- `not`: 참/거짓 뒤집기
- 예: "17 이상 AND 19 이하"는 고등학생

**비주얼 가이드 (Visual Concept):**
중앙에 큰 벤다이어그램 2개 (파란 마커):
- 왼쪽: AND — 두 원의 교집합 부분만 색칠
- 오른쪽: OR — 두 원의 합집합 전체 색칠
아래에 비교 코드 (Before/After):
```
# Before (중첩)
if age >= 17:
    if age <= 19:
        print("고등학생")

# After (and)
if age >= 17 and age <= 19:
    print("고등학생")
```
화살표로 "→ 한 줄로!" 강조.

**발표자 노트 (Presenter Note):**
"중첩 if도 가능하지만, and를 쓰면 한 줄로 끝나요. '17 이상 그리고 19 이하' — 이걸 그대로 코드에 옮기면 됩니다. 영어 문장처럼 자연스럽죠?"

## Slide 8 — 직접 해보기 1: 짝수일까 홀수일까?

**핵심 메시지 (Heading):** 입력 받은 숫자가 짝수인지 홀수인지 판별해보자.

**핵심 내용 (Key Points):**
- 입력 함수: `int(input("숫자: "))`
- 짝수 판별 도구: `n % 2 == 0` (2로 나눈 나머지가 0)
- if-else로 두 갈래 분기
- 예상 출력: "짝수입니다" / "홀수입니다"

**비주얼 가이드 (Visual Concept):**
화이트보드에 빈 칸이 있는 코드 (학생이 채울 부분은 노란 형광펜):
```
n = int(input("숫자: "))
if n % 2 ___ 0:        # ← 빈칸 1
    print("___입니다")   # ← 빈칸 2
___:                    # ← 빈칸 3
    print("___입니다")   # ← 빈칸 4
```
오른쪽에 결과 예시 박스: 입력 7 → "홀수입니다", 입력 12 → "짝수입니다".

**발표자 노트 (Presenter Note):**
"자, 직접 해볼 차례예요. 빈 칸 4개에 들어갈 것을 친구랑 같이 채워봅시다. 힌트: 'n을 2로 나눈 나머지가 0이면 짝수'예요. 3분 드릴게요!"

## Slide 10 — 자주 하는 실수 — 디버깅 노하우

**핵심 메시지 (Heading):** 조건문에서 초보자가 가장 많이 빠지는 함정 4가지.

**핵심 내용 (Key Points):**
- ❶ `==` 와 `=` 혼동 → "비교는 두 개, 대입은 한 개"
- ❷ 콜론(:) 빠뜨림 → SyntaxError
- ❸ 들여쓰기 누락 → IndentationError
- ❹ elif 자리에 if 반복 → 조건이 겹치면 의도와 다른 결과

**비주얼 가이드 (Visual Concept):**
4사분면 분할 — 각 칸에 빨간 X 코드(잘못) + 초록 ✓ 코드(맞음). 사분면 중앙에는 노란 경고 표지판 ⚠️ 큰 그림. 각 항목 옆에 작은 손그림 아이콘(등호, 콜론, 화살표 등).
예:
```
✗ if x = 5:       ✓ if x == 5:
✗ if x > 5        ✓ if x > 5:
✗ print("hi")     ✓     print("hi")
```

**발표자 노트 (Presenter Note):**
"여러분이 조건문을 처음 쓸 때 99% 만나게 될 에러들이에요. 미리 보고 가면 나중에 '아, 그거구나!' 하고 빨리 고칠 수 있어요. 특히 등호 헷갈리지 마세요!"

## Slide 11 — 조건문, 일상 어디에 쓰이고 있을까?

**핵심 메시지 (Heading):** 조건문은 우리가 매일 쓰는 앱과 기계의 뇌 속에 숨어있다.

**핵심 내용 (Key Points):**
- 🚗 자율주행: 빨간 신호면 멈춤
- 📱 알람: 평일 7시면 알림
- 🎬 추천: 좋아한 영화와 비슷하면 추천
- 🎮 게임: HP가 0이면 게임 오버

**비주얼 가이드 (Visual Concept):**
4분할 그리드 — 각 칸에 손그림 아이콘(자동차, 핸드폰, TV, 게임 컨트롤러)과 짧은 의사코드:
```
🚗 if 신호 == "빨강":
       정지

📱 if 요일 == "평일" and 시간 == 7:
       알람

🎬 if 영화_유사도 > 0.8:
       추천

🎮 if HP <= 0:
       game_over()
```

**발표자 노트 (Presenter Note):**
"여러분이 지금 쓰는 모든 앱과 기계 안에는 수천, 수만 개의 if 문이 돌아가고 있어요. 알람, 추천, 게임… 다 if예요. 조건문을 마스터하면 이런 똑똑한 기능을 직접 만들 수 있어요."

## Slide 12 — 수학 응용: 이차방정식 근 판별기

**핵심 메시지 (Heading):** 수학 시간에 배운 판별식 D = b²−4ac, 조건문으로 자동 판별해보자.

**핵심 내용 (Key Points):**
- D > 0 → 서로 다른 두 실근
- D == 0 → 중근 (한 개의 실근)
- D < 0 → 두 허근
- 조건문 한 번에 수학적 분석 완성

**비주얼 가이드 (Visual Concept):**
왼쪽 코드 박스(손글씨 스타일):
```
a = 1
b = -5
c = 6
D = b**2 - 4*a*c

if D > 0:
    print("서로 다른 두 실근")
elif D == 0:
    print("중근")
else:
    print("두 허근")
```
