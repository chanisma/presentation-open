AI 피지컬 컴퓨팅 제품 설계

팀이 기획한 아이디어를 실제로 만들 수 있도록 외관 · 코드 · 회로를 구체화하는 설계 활동입니다.
팀원이 각자 핵심 역할을 맡아 활동지를 작성하고, 결과는 팀별로 한 시트에 모입니다.

전체 흐름
1단계팀·역할 선택
2단계역할별 설계 작성
3단계AI 프롬프트 활용
4단계팀 시트로 통합
💡 팀별로 한 행에 모든 역할의 결과가 모입니다. 같은 팀명으로 다른 학생이 제출하면 그 행의 해당 역할 컬럼만 갱신됩니다. 부품·핀·클래스 이름같이 겹치는 결정은 팀원들과 미리 합의해 같은 값을 입력해 주세요.
세 가지 핵심 역할
✏️
제품 디자이너
제품 외관을 2~3개 구도로 스케치하고 ChatGPT로 산업디자인 블루프린트를 만듭니다.
  • MOCK 스케치 첨부
  • 블루프린트 프롬프트 자동 생성
  • 디자인 자기 평가 (장점·한계)
💻
프로그래밍 코드 설계
부품 핀과 동작 시나리오를 정리하고 Arduino + HTML 코드 생성 프롬프트로 코드를 만듭니다.
  • 부품별 핀·역할 표
  • 분류 결과 → 동작 매핑
  • Arduino/HTML 프롬프트 자동 생성
  • 생성된 코드 붙여넣기 저장
🔌
아두이노 장치 설계
실제 부품 사진을 ChatGPT에 첨부해 회로도 설명을 받고 UNO 핀 매핑을 정리합니다.
  • 부품 실물 사진 첨부
  • 사진 기반 회로도 프롬프트
  • AI 회로도 결과 캡처
  • Arduino UNO 핀 매핑 표
🧠
이미지 분류 모델 생성
인터넷에서 이미지를 수집해 Teachable Machine으로 분류 모델을 학습시킵니다.
  • 학습 클래스 설계 (최소 10장/클래스)
  • 인터넷 검색 이미지 첨부
  • 테스트 결과 캡처 (2장/클래스)
  • 모델 URL 코드 담당과 공유
시작 전 준비
  • 팀명 — 활동지 첫 화면에서 등록된 팀 목록 중 본인 팀을 선택합니다.
  • 부품 합의 — 코드·회로 담당이 동일한 부품 리스트와 핀 매핑을 사용해야 합니다.
  • 클래스 합의 — TM 모델 담당이 정한 클래스 이름과 모델 URL을 코드 담당이 그대로 사용해야 합니다.
  • 이미지 자료 — 디자이너는 종이 스케치 2~3장, 회로 담당은 실제 부품 사진, TM 담당은 인터넷에서 다운로드한 클래스별 10장 이상.
  • Chrome 또는 Edge — Web Serial API와 자동 파일 다운로드를 위해 필수.
