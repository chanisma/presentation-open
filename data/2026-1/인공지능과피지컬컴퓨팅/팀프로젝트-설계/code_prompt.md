# HTML 코드 생성 조건
- Teachable Machine에서 내보낸 이미지 분류 모델을 HTML 페이지에서 불러와야 한다.
- HTML 페이지는 웹캠을 실행하고 실시간으로 이미지를 분류해야 한다.
- 분류 결과(class label)에 따라 Arduino UNO로 명령값을 전송해야 한다.
- Arduino와 HTML 페이지는 Web Serial API를 사용하여 시리얼 통신해야 한다.
- 사용자가 직접 Arduino 포트를 선택할 수 있도록 “Arduino 연결” 버튼을 만들어야 한다.
- 웹캠 시작 버튼을 포함해야 한다.
- 현재 인식된 class label과 confidence 값을 화면에 표시해야 한다.
- confidence가 일정 기준 이상일 때만 Arduino로 명령을 보내야 한다.
- 기본 confidence 기준값은 0.85로 설정한다.
- 같은 명령이 반복해서 너무 자주 전송되지 않도록 중복 전송 방지 로직을 포함한다.
- 명령 전송 간격은 최소 1000ms 이상으로 설정한다.
- Arduino로 전송하는 데이터는 한 글자 또는 짧은 문자열로 구성한다.
- 예: class A → "A\n", class B → "B\n", class C → "C\n"
- Arduino 코드는 Serial.readStringUntil('\n') 또는 Serial.read() 방식으로 명령을 받아 동작해야 한다.
- HTML 코드는 Chrome 또는 Edge 브라우저에서 실행 가능하도록 작성한다.
- Web Serial API는 HTTPS 또는 localhost 환경에서 동작한다는 설명을 포함한다.
- Teachable Machine 모델 URL을 사용자가 수정할 수 있도록 코드 상단에 상수로 작성한다.
- 예: const MODEL_URL = "여기에 Teachable Machine 모델 URL 입력";
- HTML, CSS, JavaScript를 하나의 HTML 파일 안에 작성한다.
- 학생들이 이해할 수 있도록 코드에 한국어 주석을 자세히 작성한다.
