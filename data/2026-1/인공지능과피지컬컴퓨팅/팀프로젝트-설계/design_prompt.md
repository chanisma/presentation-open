학생이 스케치한 피지컬 컴퓨팅 장치(mockup sketch)를 기반으로 한 초고해상도 산업디자인 블루프린트 포스터.

원본 학생 스케치의 형태와 아이디어를 유지하면서,
전문 엔지니어링 컨셉 디자인 수준으로 정교하게 발전시킨 기술 일러스트레이션.

스타일:
- 정교한 블루프린트 / 기술 도면 스타일
- 짙은 네이비 또는 코발트 블루 배경
- 정밀한 흰색 테크니컬 라인 아트
- 정투영 도면 구성
- 정면도, 측면도, 평면도, 원근 투시도 포함
- 엔지니어링 드래프팅 스타일
- 얇은 작도선과 치수 가이드
- 부품 라벨 및 설명 콜아웃
- 현실적인 장치 비율
- 은은한 그리드 종이 배경
- 미니멀하면서 균형 잡힌 인포그래픽 구성
- 교육용 STEM 프로젝트 발표 스타일
- 산업 제품 컨셉 시트 느낌
- 깔끔한 타이포그래피와 기술 기호
- exploded component diagram(분해도) 섹션 포함
- 배선 경로 및 센서 위치 표시
- 미래지향적이지만 실제 제작 가능한 디자인

중요:
- 학생 스케치의 전체 형태와 아이디어를 유지할 것
- 원본 컨셉을 과하게 재설계하지 말 것
- 학생의 창의성을 유지하면서 전문성과 가독성을 향상시킬 것
- 고등학교 공학 프로젝트 팀의 실제 프로토타입 제안서처럼 보이게 할 것
- 포토리얼 스타일 금지
- 기술 일러스트 및 블루프린트 표현에 집중
- 복잡하거나 지저분한 배경 금지
- 깔끔하고 균형 잡힌 포스터 레이아웃
