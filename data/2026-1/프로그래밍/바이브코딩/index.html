VIBE CODING · 02

💬바이브 코딩이란?

바이브 코딩(Vibe Coding) = 원하는 것을 일상 언어로 설명하면 AI가 코드를 작성하는 개발 방식. 사람은 코드를 한 줄씩 치는 대신 요청하고, 확인하고, 다듬는 역할을 맡습니다.

VIBE CODING · 03

⚖️직접 코딩 vs 바이브 코딩

무엇이 같고 무엇이 달라질까요?

직접 코딩과 바이브 코딩의 비교
구분 직접 코딩 바이브 코딩
코드 작성 사람이 한 줄씩 입력 AI가 생성
사람의 역할 문법에 맞게 구현 기획 · 요청 · 검증 · 개선
중요한 능력 문법 지식, 디버깅 표현력 + 기초 지식 + 판단력
속도와 깊이 느리지만 깊게 이해 빠르지만 반드시 검증 필요
VIBE CODING · 04

🤔AI가 다 해 주는데, 왜 배웠을까?

내비게이션이 있어도 운전은 내가 하는 것처럼

읽을 수 있어야 한다

AI가 만든 코드가 무엇을 하는지 대략이라도 파악해야 믿고 쓸 수 있습니다

판단할 수 있어야 한다

결과가 내 의도와 맞는지, 이상한 부분은 없는지 결정하는 것은 사람의 몫입니다

고칠 수 있어야 한다

문제가 생긴 위치를 짚어낼 수 있어야 AI에게 정확한 수정을 요청할 수 있습니다

우리가 배운 HTML · CSS · JavaScript는 바이브 코딩의 운전면허입니다.

VIBE CODING · 05

지식 ① 웹의 구조를 알면 요청이 정확해진다

우리가 이미 배운 것이 바이브 코딩의 무기가 됩니다

🧱

HTML — 구조

"버튼을 추가해 줘"가 아니라 "header 안에 버튼을"이라고 말할 수 있습니다

🎨

CSS — 디자인

"예쁘게"가 아니라 "배경색, 둥근 모서리, 그림자"로 구체화할 수 있습니다

⚡

JS — 동작

"클릭하면 반응하게"를 "버튼에 클릭 이벤트를"로 표현할 수 있습니다

용어를 아는 만큼 AI와의 대화 정확도가 올라갑니다.

VIBE CODING · 06

📋지식 ② 무엇을 만들지 스스로 정리하기

13차시 프로젝트에서 했던 기획·설계가 바로 이것입니다

  • ①

    목적 — 왜 만드는가

    이 페이지(기능)가 해결하려는 문제를 한 문장으로 정리합니다

  • ②

    대상 — 누가 쓰는가

    사용자가 누구인지에 따라 화면과 말투, 기능이 달라집니다

  • ③

    기능 — 무엇을 하는가

    필요한 기능을 목록으로 적고 우선순위를 매깁니다

  • ④

    화면 — 어떻게 보이는가

    손그림이라도 좋으니 화면 배치를 먼저 상상해 둡니다

VIBE CODING · 07

✍️지식 ③ 좋은 프롬프트의 4원칙

  1. 01

    맥락 주기

    내가 만드는 것과 현재 상태를 먼저 설명합니다 — "나는 독서 기록 페이지를 만드는 중이야"

  2. 02

    구체적으로 말하기

    "예쁘게" 대신 "배경은 어두운 남색, 글자는 흰색, 버튼은 둥글게"

  3. 03

    작게 나누기

    한 번에 하나의 기능만 요청하고, 확인한 뒤 다음 기능으로 넘어갑니다

  4. 04

    형식 정하기

    "HTML 파일 하나로", "기존 코드는 유지하고" 처럼 결과물의 형태를 지정합니다

VIBE CODING · 08

🗣️같은 요청, 다른 결과

프롬프트가 달라지면 AI의 답이 달라집니다

✕아쉬운 프롬프트

  • "웹사이트 만들어 줘"
  • "더 예쁘게 해 줘"
  • "오류 났어. 고쳐 줘"

✓좋은 프롬프트

  • "독서 기록 웹페이지를 만들어 줘. 제목, 책 목록, '추가' 버튼이 필요해. HTML 파일 하나로."
  • "책 카드의 모서리를 둥글게 하고, 마우스를 올리면 그림자가 생기게 해 줘."
  • "추가 버튼을 눌러도 반응이 없어. 콘솔에 이 오류가 떠: Uncaught TypeError..."
VIBE CODING · 09

🔍지식 ④ AI의 결과는 반드시 검증한다

코드가 만들어졌다고 끝이 아닙니다

  • ①

    직접 실행해 보기

    브라우저에서 열어 모든 버튼과 입력을 하나씩 눌러 봅니다. 의도대로 움직이나요?

  • ②

    개발자 도구(F12) 열기

    Console 탭의 빨간 오류 메시지를 확인합니다. 오류 메시지는 문제의 위치를 알려 주는 단서입니다

  • ③

    오류를 그대로 전달하기

    오류 메시지를 복사해서 AI에게 붙여넣으면, 훨씬 정확한 수정을 받을 수 있습니다

VIBE CODING · 10

🔁지식 ⑤ 한 번에 완성되지 않는 게 정상

바이브 코딩은 이 루프를 돌리는 일입니다

STEP 1

요청

4원칙에 맞춰 작게 요청

STEP 2

실행 · 확인

브라우저에서 직접 동작 확인

STEP 3

피드백

다른 점·오류를 구체적으로 전달

REPEAT

다시 요청

만족할 때까지 루프 반복

실력 차이는 루프를 얼마나 정확하고 빠르게 도는가에서 생깁니다.

VIBE CODING · 11

⚠️꼭 알아야 할 주의점

AI는 강력하지만 완벽하지 않습니다

환각(Hallucination)

AI는 그럴듯하지만 틀린 코드와 설명을 만들 수 있습니다. 그래서 검증이 필수입니다

보안 · 개인정보

비밀번호, API 키, 친구의 개인정보를 프롬프트에 넣지 않습니다

이해 없는 복붙

설명할 수 없는 코드는 내 것이 아닙니다. 모르는 부분은 AI에게 설명을 요청하세요

저작권 · 출처

생성된 코드와 이미지에도 저작권 문제가 있을 수 있음을 의식합니다

VIBE CODING · 12

🧪실습: 내 프로젝트에 바이브 코딩 적용하기

오늘 배운 5가지 지식을 모두 사용해 봅시다

  1. 01

    기능 고르기

    내 웹사이트 프로젝트에 추가하고 싶은 기능을 딱 1가지 정합니다

  2. 02

    프롬프트 작성

    4원칙(맥락 · 구체성 · 작게 · 형식)에 맞춰 프롬프트를 먼저 글로 써 봅니다

  3. 03

    요청하고 검증

    AI에게 요청한 뒤 브라우저에서 실행하고, F12 콘솔로 오류를 확인합니다

  4. 04

    최소 1번 개선

    아쉬운 점을 구체적으로 피드백해서 한 단계 더 다듬어 완성합니다

🙌

코드를 잊되, 생각은 잊지 말 것

바이브 코딩의 시대에도 기획하고 판단하는 것은 사람입니다

오늘의 핵심

  • ✓바이브 코딩 = 말로 요청하기 + 사람의 검증
  • ✓기초 지식이 있어야 정확히 요청하고 판단할 수 있다
  • ✓작게 요청하고, 실행해 보고, 반복해서 개선한다
