# [수업 가이드] 알고리즘: 컴퓨터에게 일을 시키는 가장 정직한 방법

본 가이드는 고등학교 1학년 정보 수업을 위한 50분 차시의 학습 지침서입니다. 학생들이 '알고리즘'이라는 추상적인 개념을 일상의 비유를 통해 쉽게 이해하고, 실습을 통해 논리적 사고력을 기를 수 있도록 설계되었습니다.

---

## 1. 수업 개요 및 목표

*   **핵심 질문:** "내가 머릿속으로 문제를 푸는 방법을 컴퓨터에게 똑같이 시키려면 어떻게 적어줘야 할까?"
*   **학습 목표:**
    1.  알고리즘의 의미를 이해하고 '라면 끓이기' 비유를 통해 설명할 수 있다.
    2.  알고리즘의 3대 구조(순차, 선택, 반복)를 구분하고 흐름도로 표현할 수 있다.
    3.  라이트봇(Lightbot) 실습을 통해 논리적인 절차를 직접 설계하고 최적화할 수 있다.

---

## 2. 시간 배분 및 상세 활동 계획

### [도입] 컴퓨터로 문제를 해결한다는 것 (8분)
컴퓨터는 빠르지만 사람처럼 '알아서' 해주지는 못한다는 점을 강조하며 흥미를 유발합니다.

*   **주요 내용:** 컴퓨팅 사고력의 정의, 컴퓨터의 강점(속도, 반복)과 약점(정확한 절차 필요).
*   **교사 발문 예시:**
    1. "여러분, 지도 앱이 길을 찾아주거나 갤러리가 강아지 사진만 골라내는 비결이 무엇일까요?"
    2. "사람에게 '라면 좀 끓여줘'라고 하면 알아서 하지만, 컴퓨터에게 똑같이 말하면 왜 아무것도 못 할까요?"
    3. "컴퓨터에게 일을 시키기 위해 '하나부터 열까지 아주 자세하게 적어준 절차서'를 무엇이라 부를까요?"
*   **학생 활동:** 컴퓨터가 해결해주는 일상의 문제(스팸 차단, 추천 알고리즘 등) 떠올리기.

### [핵심 개념] 알고리즘의 정의와 구조 (20분)
알고리즘의 유래부터 성질, 그리고 이를 구성하는 3가지 기본 구조를 배웁니다.

*   **주요 내용:**
    *   **유래:** 9세기 수학자 '알 콰리즈미'의 이름에서 유래(코딩 이전에 존재한 '생각하는 방법').
    *   **알고리즘의 5가지 성질:**
        | 성질 | 의미 | 라면 비유 |
        | :--- | :--- | :--- |
        | **입력** | 외부에서 들어오는 재료 | 라면, 물, 가스 |
        | **출력** | 나오는 결과물 | 완성된 라면 |
        | **명확성** | 단계가 애매하지 않음 | '조금' 대신 '500mL' |
        | **유한성** | 언젠가는 끝남 | 무한히 끓이지 않음 |
        | **효과성** | 실행 가능함 | 마음으로 냄비 데우기 금지 |

    *   **알고리즘 3대 구조:**
        1.  **순차 구조:** 시작부터 끝까지 순서대로 실행 (예: 기본 라면 조리법).
        2.  **선택 구조:** 조건에 따라 경로가 갈라짐 (예: 계란을 넣을까 말까?).
        3.  **반복 구조:** 조건이 만족될 때까지 반복 (예: 면이 익을 때까지 1분씩 더 끓이기).

*   **교사 발문 예시:**
    1. "알고리즘은 프로그래밍 언어가 생기기 1100년 전부터 있었다는데, 왜 '생각하는 방법'이라고 할까요?"
    2. "라면 끓이기에서 '계란을 넣을 것인가?'라는 질문은 흐름도에서 어떤 모양(◇)으로 그려야 할까요?"
    3. "1부터 100까지 더할 때 하나씩 더하는 것보다 가우스처럼 규칙을 찾는 것이 왜 더 좋은 알고리즘일까요?"

### [실습] 알고리즘 설계 및 라이트봇 도전 (15분)
종이에 흐름도를 그려보고, 게임을 통해 논리적 절차를 조립해 봅니다.

*   **활동 1: 종이 흐름도 그리기**
    *   **미션:** "떡볶이집 줄이 5명 이상이면 빙수집에 가고, 아니면 친구를 기다렸다가 떡볶이를 먹는다."
    *   **산출물:** 순차, 선택, 반복이 포함된 손 그림 흐름도.
*   **활동 2: 라이트봇(Lightbot) 게임 실습**
    *   **단계별 진행 절차:**
        1.  **접속:** 안내된 라이트봇 링크(Hour of Code 등)에 접속합니다.
        2.  **기초 다지기:** 레벨 1-3, 1-5를 차례로 클리어하며 전진, 회전, 불 켜기 명령을 익힙니다.
        3.  **구조 이해:** 명령 블록을 MAIN 영역에 배치하는 것이 알고리즘의 '순차 구조'임을 이해합니다.
        4.  **심화 도전:** 레벨 2-1에 도전하여 함수(P1, P2)를 활용해 반복되는 동작을 묶어봅니다.
        5.  **기록:** 가장 효율적으로(명령 수를 적게) 클리어한 스테이지의 명령 배치를 확인합니다.
    *   **산출물:** 클리어 화면 캡처 또는 종이에 베껴 적은 명령 리스트.
*   **교사 발문 예시:**
    1. "로봇이 파란 타일에 불을 다 켜게 하려면 어떤 순서로 명령을 조립해야 할까요?"
    2. "똑같은 동작이 반복될 때, 일일이 명령을 넣는 것과 함수를 쓰는 것 중 어느 쪽이 더 깔끔할까요?"
    3. "여러분이 방금 만든 명령 순서가 바로 컴퓨터 과학에서 말하는 무엇일까요?"

### [마무리] 정리 및 다음 시간 예고 (7분)
학습 내용을 회고하고 알고리즘이 우리 삶에 주는 가치를 공유합니다.

*   **주요 내용:** 알고리즘은 사고를 정리하는 도구라는 점 강조.
*   **교사 발문 예시:**
    1. "오늘 배운 알고리즘의 3가지 구조 중 가장 기억에 남는 것은 무엇인가요?"
    2. "여러분의 일상 중에서 알고리즘으로 만들어보고 싶은 작은 문제가 있나요?"
    3. "컴퓨터가 내 명령을 못 알아듣는다면, 그건 누구의 논리가 부족하기 때문일까요?"
*   **학생 제출물:** 한 문장 회고 쪽지 (인상 깊었던 내용 + 알고리즘으로 해결해보고 싶은 일상의 문제).

## 3. 학습 점검 퀴즈 및 심화 탐구

### 단답형 퀴즈 (Short-answer Quiz)
1.  **질문:** 어떤 문제를 해결하기 위한 유한한 단계의 명확한 절차를 무엇이라고 하는가?
    *   **정답:** 알고리즘
2.  **질문:** 9세기 페르시아의 수학자로, 알고리즘이라는 단어의 어원이 된 인물은?
    *   **정답:** 알 콰리즈미 (Al-Khwārizmī)
3.  **질문:** 알고리즘의 3대 구조 중 주어진 조건에 따라 실행 경로가 달라지는 구조는?
    *   **정답:** 선택 구조
4.  **질문:** 알고리즘의 성질 중 '모든 단계가 애매하지 않고 확실해야 한다'는 성질은?
    *   **정답:** 명확성

### 에세이 연습 (Essay Prompts)
1.  **알고리즘의 효율성:** 1부터 100까지 숫자를 더할 때, 1씩 99번 더하는 방식과 가우스의 방식(짝을 지어 곱하기) 중 어느 것이 더 효율적인지 '시간'과 '정확성'의 관점에서 서술해 보세요.
2.  **일상 속 알고리즘:** 유튜브의 영상 추천 시스템이나 지도 앱의 길 찾기 시스템이 우리 삶을 어떻게 바꾸었는지, 만약 이 알고리즘들이 사라진다면 어떤 불편함이 생길지 논리적으로 설명해 보세요.

## 4. 용어 사전 (Glossary)

*   **알고리즘(Algorithm):** 문제를 해결하기 위해 정해진 일련의 절차나 규칙. 유한한 단계 내에 끝나야 하며 명확해야 함.
*   **순차 구조(Sequence):** 명령을 위에서 아래로 순서대로 하나씩 실행하는 가장 기본적인 구조.
*   **선택 구조(Selection):** '만약 ~라면'과 같은 조건에 따라 실행할 명령의 방향을 결정하는 구조.
*   **반복 구조(Iteration):** 특정 조건이 유지되는 동안 동일한 명령을 여러 번 되풀이하여 실행하는 구조.
*   **컴퓨팅 사고력(Computational Thinking):** 사람이 해결해야 할 문제를 컴퓨터가 처리할 수 있는 형태로 분해하고 논리적 절차를 만드는 능력.
*   **흐름도(Flowchart):** 알고리즘의 진행 과정을 미리 약속된 기호와 화살표를 사용하여 시각적으로 나타낸 그림.
