> 대상: 고등학교 교사 (프로그래밍 비전공자) · AI 전문적 학습 동아리 연수
> 스타일: Whiteboard 손글씨 마커 (검정/파랑/빨강/초록)

각 슬라이드는 손그림 화이트보드 한 장이다. 사람·컴퓨터·말풍선·화살표·박스를 마커로 그린 느낌으로.

## Slide 1 — 표지: 말로 만드는 코딩, 바이브코딩

**핵심 메시지 (Heading):** 클로드코드를 활용한 바이브코딩 — 코드를 몰라도, 말만 하면 만들어집니다

**핵심 내용 (Key Points):**
- 부제: "AI에게 말을 걸어 수업 도구를 만드는 시간"
- 대상: 프로그래밍이 처음인 선생님들
- 오늘의 목표: 직접 한 개의 웹페이지를 내 손으로(=말로) 완성하기

**비주얼 가이드 (Visual Concept):**
화이트보드 중앙에 큰 손글씨 제목 "바이브코딩". 왼쪽에 선생님 손그림이 말풍선으로 "구구단 게임 만들어줘!"라고 말하고, 오른쪽에 웃는 컴퓨터 모니터 손그림이 화면에 완성된 게임을 띄운다. 둘 사이를 파란 마커 화살표가 잇는다. 하단에 초록 마커로 작은 글씨 "코드 한 줄 몰라도 OK ✓".

**발표자 노트 (Presenter Note):**
"안녕하세요 선생님. 오늘은 코딩을 '배우는' 시간이 아니라, 코딩을 '시키는' 시간입니다. 우리가 한국어로 부탁만 하면 AI가 진짜 작동하는 웹페이지를 만들어 줘요. 끝날 때쯤이면 여러분 손으로 만든 결과물 하나를 가지고 가실 겁니다."

## Slide 2 — 도입 비유: 요리사에게 주문하듯

**핵심 메시지 (Heading):** 레시피를 외울 필요 없어요. 원하는 요리를 '주문'하면 됩니다

**핵심 내용 (Key Points):**
- 예전 코딩 = 직접 칼질하고 불 조절하는 요리 (문법을 다 알아야 함)
- 바이브코딩 = 셰프에게 "이런 요리 해주세요" 주문하기
- 우리가 할 일: 무엇을 원하는지 '잘 설명'하는 것

**비주얼 가이드 (Visual Concept):**
왼쪽 절반에 빨간 마커로 ✗ 표시 — 지친 사람이 칼·냄비·불 앞에서 땀 흘리는 손그림, 위에 "직접 다 만들기(옛날 코딩)". 오른쪽 절반에 초록 마커로 ✓ — 손님이 메뉴판을 보며 셰프에게 말풍선 "파스타 주세요!", 셰프(컴퓨터 모자 쓴 요리사)가 완성된 접시를 내미는 손그림, 위에 "주문하기(바이브코딩)". 가운데 세로 점선으로 두 세계를 가른다.

**발표자 노트 (Presenter Note):**
"식당에서 우리가 직접 요리하지 않죠? '봉골레 파스타 주세요' 하면 됩니다. 바이브코딩이 딱 그래요. 문법을 외우는 게 아니라, 무엇을 원하는지 또박또박 말하는 능력이 핵심입니다. 그건 선생님들이 이미 매일 하시는 일이에요."

## Slide 3 — 바이브코딩이란 무엇인가

**핵심 메시지 (Heading):** 자연어(우리말)로 부탁하면, AI가 코드를 써 주는 새로운 방식

**핵심 내용 (Key Points):**
- '바이브(vibe)' = 분위기·느낌. 느낌으로, 대화하듯 코딩
- 사람은 '무엇을' 원하는지 말하고, AI(클로드코드)는 '어떻게'를 책임짐
- 결과를 보고 "이건 이렇게 바꿔줘" 다시 말하며 점점 완성
- 2025년, OpenAI 안드레 카파시가 만든 말 — 이미 전 세계가 이렇게 일함

**비주얼 가이드 (Visual Concept):**
중앙에 원형 순환 화살표(루프) 3단계: ① 파란 박스 "사람: 말로 부탁" → ② 초록 박스 "AI: 코드 작성" → ③ 빨간 박스 "함께 확인·수정" → 다시 ①로. 순환 화살표는 검정 마커. 가운데에 ♻️ 같은 느낌. 하단에 노란 형광펜 강조 "사람=무엇을 / AI=어떻게".

**발표자 노트 (Presenter Note):**
"바이브코딩은 대화하듯 코딩하는 거예요. 내가 원하는 걸 말하면 AI가 코드를 쓰고, 결과를 같이 보면서 '여기 색 바꿔줘' 하고 다듬어 갑니다. 이 주고받기를 몇 번 하면 어느새 완성돼 있어요."

## Slide 4 — 교사가 바이브코딩을 배우면 할 수 있는 일

**핵심 메시지 (Heading):** 머릿속 아이디어를, 학생들이 쓰는 진짜 도구로

**핵심 내용 (Key Points):**
- 수업용 미니 게임·시뮬레이션 (개념을 눈으로 보여주기)
- 인터랙티브 학습지·퀴즈·받아쓰기 연습기
- 학급 운영 도구 (자리뽑기, 모둠편성, 타이머, 발표순서)
- 학부모·학생 안내 홈페이지, 행사 페이지
- 핵심: 업체에 맡기거나 비싼 프로그램 살 필요 없이 '내가 원하는 그대로'

**비주얼 가이드 (Visual Concept):**
중앙에 선생님 손그림(머리 위에 💡 전구), 거기서 사방으로 4갈래 파란 마커 화살표가 뻗어 각각 작은 손그림 박스로: (좌상) 게임 컨트롤러 + "수업 게임", (우상) 체크리스트 + "학습지·퀴즈", (좌하) 모둠 표 + "학급 운영 도구", (우하) 브라우저 창 + "안내 홈페이지". 네 박스를 초록 마커로 가볍게 동그라미.

**발표자 노트 (Presenter Note):**
"가장 좋은 점은 '내 수업에 딱 맞게' 만들 수 있다는 거예요. 시중 프로그램은 우리 반 상황을 모르잖아요. 받아쓰기 단어를 우리 교과서 단어로, 게임 난이도를 우리 반 수준으로 — 전부 내 마음대로입니다."

## Slide 8 — 기초 지식 (1): 웹페이지를 이루는 세 가지 언어

**핵심 메시지 (Heading):** 우리가 직접 쓰진 않지만, 이름만 알아두면 든든해요

**핵심 내용 (Key Points):**
- HTML = 뼈대·구조 (제목, 문단, 버튼이 '무엇인지')
- CSS = 디자인·꾸미기 (색, 글꼴, 배치 '어떻게 보일지')
- JavaScript(JS) = 동작·기능 (클릭하면 움직이는 '무슨 일이 일어날지')
- AI가 이 세 가지를 알아서 써 줍니다 — 우리는 이름만!

**비주얼 가이드 (Visual Concept):**
집🏠 짓기 비유. 손그림 집 한 채를 3겹으로: ① 파란 마커 - 집의 뼈대(기둥·벽 골조)에 라벨 "HTML = 뼈대", ② 빨간 마커 - 페인트·지붕·창문 꾸밈에 라벨 "CSS = 꾸미기", ③ 초록 마커 - 문이 열리고 전등이 켜지는 손그림에 라벨 "JS = 동작". 하단에 검정 글씨 "→ AI가 다 써줌. 우리는 이름만 알기 ✓".

**발표자 노트 (Presenter Note):**
"집을 지을 때 뼈대 세우고, 페인트 칠하고, 문이 여닫히게 하죠. 웹페이지도 똑같아요. HTML이 뼈대, CSS가 꾸미기, JS가 움직임. 외우실 필요 없어요. AI가 다 써주니까요. 다만 이 이름들이 나오면 '아, 그거구나' 하시면 됩니다."

## Slide 9 — 기초 지식 (2): 프론트엔드 vs 백엔드

**핵심 메시지 (Heading):** 손님이 보는 '홀'과, 주방 뒤 '주방'의 차이

**핵심 내용 (Key Points):**
- 프론트엔드 = 화면, 눈에 보이는 부분 (식당의 홀·메뉴판)
- 백엔드 = 데이터 저장·처리, 뒤에서 일하는 부분 (주방·창고)
- 오늘 만들 도구는 대부분 '프론트엔드'만으로 충분 (브라우저에서 바로 동작)
- 데이터를 모으거나 로그인이 필요하면 백엔드가 등장

**비주얼 가이드 (Visual Concept):**
식당 단면도 손그림을 세로 점선으로 둘로 나눔. 왼쪽(파란 마커): 손님이 앉은 홀, 메뉴판, 예쁜 인테리어 — 라벨 "프론트엔드 = 화면(눈에 보임)". 오른쪽(빨간 마커): 주방에서 요리사·냉장고·창고 — 라벨 "백엔드 = 처리·저장(뒤에서)". 가운데 주문서가 양쪽을 오가는 화살표. 하단 초록 마커 강조 "오늘 실습 = 프론트엔드만으로 충분 ✓".

**발표자 노트 (Presenter Note):**
"식당에 홀과 주방이 있죠. 화면처럼 눈에 보이는 게 프론트엔드, 데이터를 저장하고 처리하는 뒤편이 백엔드예요. 오늘 만들 게임이나 학습지는 대부분 화면(프론트엔드)만으로 돌아갑니다. 그래서 더 쉬워요."

## Slide 10 — 기초 지식 (3): 알아두면 좋은 도구 3가지

**핵심 메시지 (Heading):** 만든 작품을 저장하고, 세상에 공개하는 길

**핵심 내용 (Key Points):**
- GitHub(깃허브) = 내 작품을 저장·보관하는 '클라우드 사물함'
- GitHub Desktop = 어려운 명령어 없이 클릭으로 GitHub 쓰는 프로그램
- 배포(Deploy) = 내 페이지에 주소(URL)를 붙여 누구나 보게 하기 (예: vercel, github pages)
- 클로드코드 = 우리의 'AI 코딩 비서' (VS Code 안에서 대화)

**비주얼 가이드 (Visual Concept):**
