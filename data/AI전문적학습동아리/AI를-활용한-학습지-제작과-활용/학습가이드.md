# AI 활용 학습지 제작과 데이터 환류: 교사를 위한 종합 학습 가이드

본 가이드는 한국 교사 전문적 학습공동체를 위해 기획되었습니다. Claude Code와 같은 AI 도구를 활용하여 학생용 활동지를 제작하고, 수집된 데이터를 분석하여 수업에 다시 반영하는 전체 파이프라인을 9개의 핵심 주제로 나누어 살펴봅니다.

---

## [주제 1] 지난 시간 회고: presentation-builder 스킬의 이해

### 1. 핵심 메시지
지난 차시에서 경험한 `presentation-builder`는 단순한 도구가 아니라, 특정 작업에 최적화된 전문 지식 패키지인 '스킬(Skill)'의 힘을 보여주었습니다. 자연어 한 줄로 전문가 수준의 HTML 슬라이드를 만드는 경험을 통해 AI가 단순 비서를 넘어 구현 전문가로 진화했음을 이해합니다.

### 2. 구체 예시
*   **프롬프트:** "중학교 2학년 과학 '기권과 우리 생활' 단원을 위한 10페이지 분량의 발표 자료를 세련된 디자인으로 만들어줘."
*   **결과물:** 30가지 디자인 스타일 가이드와 라이브 코드 에디터가 포함된 단일 `index.html` 파일.

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 지난주에 제작한 HTML 파일을 브라우저에서 열어보고, 별도의 설치 프로그램 없이도 폰트나 디자인이 유지되는지 확인하세요.
*   **학생 활동:** AI가 만든 슬라이드 안의 'Live Code Editor' 영역에서 간단한 코드를 수정하며 화면이 어떻게 바뀌는지 관찰해 보세요.

### 4. 예상 질문 (FAQ)
*   **Q: 스킬과 일반 프롬프트의 차이는 무엇인가요?**
    *   A: 스킬은 단순한 명령문 모음이 아니라, 참조 문서, 디자인 시스템, HTML 템플릿, 이미지 검색 절차 등이 포함된 '미니 라이브러리'입니다. 특정 키워드에 따라 최적화된 프로세스가 자동으로 가동됩니다.

## [주제 2] 인식의 전환: "스킬 사용 = 웹 사이트 개발"

### 1. 핵심 메시지
우리가 AI 스킬로 자료를 만드는 것은 단순히 문서를 만드는 행위를 넘어, 하나의 '정적 웹 사이트(Static Web App)'를 개발하는 과정입니다. 이 시각의 전환이 있어야만 AI에게 더 복잡하고 인터랙티브한 기능을 요구할 수 있습니다.

### 2. 구체 예시
*   발표 자료 안에 들어 있는 CSS(디자인), JavaScript(슬라이드 이동 로직), HTML 마크업은 현대 웹 개발의 핵심 요소입니다.

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 제작된 HTML 파일의 소스 코드를 AI에게 보여주며 "이 코드의 구조를 교사의 관점에서 설명해 줘"라고 요청해 보세요.
*   **학생 활동:** "웹 사이트를 만든다"는 마음가짐으로 본인의 발표 자료에 어떤 기능(버튼, 입력창 등)이 더 필요할지 아이디어를 내보세요.

### 4. 예상 질문 (FAQ)
*   **Q: 코딩을 모르는 교사도 개발이 가능한가요?**
    *   A: 네, 워드 프로세서로 글을 쓰면 보이지 않는 곳에서 마크업 언어가 생성되듯, 교사는 자연어로 의도만 전달하면 AI가 코드를 작성하고 실행합니다.

## [주제 3] 바이브 코딩 (Vibe Coding)의 이해

### 1. 핵심 메시지
안드레아 카파시가 소개한 '바이브 코딩'은 사람이 코드를 직접 타이핑하는 대신, AI와 대화하며 의도(Vibe)를 전달하여 프로그램을 만드는 방식입니다. 교사는 '기획자'가 되고 AI는 '구현자'가 됩니다.

### 2. 구체 예시
*   "3학년 학생들이 프로젝트 주제를 제출하면 구글 시트에 저장되는 폼을 만들어줘"라는 의도 표현 한 번으로 개발 프로세스를 시작하는 것.

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 바이브 코딩의 5단계(의도 표현 → 위임 → 확인 → 피드백 → 반복)를 따라가며 아주 작은 수정 사항(예: "배경색을 연한 파란색으로")을 AI에게 시켜보세요.

### 4. 예상 질문 (FAQ)
*   **Q: 결과가 마음에 들지 않으면 어떻게 하나요?**
    *   A: "이 부분이 어색해요", "폰트가 너무 작아요"와 같은 느낌(Vibe)을 그대로 AI에게 다시 전달하세요. 보통 3~5회 반복하면 완성도가 급격히 높아집니다.

## [주제 4] activity-sheet-builder 스킬 소개

### 1. 핵심 메시지
`activity-sheet-builder`는 학생용 활동지(기획서, 설문지, 성찰일지)를 만들고, 제출된 데이터를 Google Sheets에 자동으로 누적하는 강력한 스킬입니다.

### 3. 교사/학생 활동 지시문
*   **교사 활동:** Claude Code 환경에서 `activity-sheet-builder`를 설치하고 목록에 정상적으로 뜨는지 확인하세요.
*   **학생 활동:** 교사가 제공한 인터랙티브 활동지에서 텍스트 입력뿐만 아니라 이미지 첨부 기능이 작동하는지 테스트해 보세요.

### 4. 예상 질문 (FAQ)
*   **Q: 유료 도구가 필요한가요?**
    *   A: 구글 계정만 있으면 Google Apps Script를 통해 무료로 서버 기능을 구현할 수 있어 추가 비용이 들지 않습니다.

## [주제 5] Google Sheets와 Apps Script 설정 가이드

### 1. 핵심 메시지
Google Apps Script는 활동지 데이터가 구글 시트로 들어오게 하는 '우체국' 역할을 합니다. AI가 준 코드를 복사하여 붙여넣고 '웹 앱'으로 배포하는 것이 핵심입니다.

### 2. 구체 예시
*   **배포 설정값:** 실행자(나), 액세스 권한(모든 사용자 - Anyone).

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 
    1. 새 구글 시트 생성.
    2. [확장 프로그램] → [Apps Script] 클릭.
    3. AI가 생성한 `Code.gs` 내용을 붙여넣고 저장.
    4. [배포] 버튼을 눌러 생성된 '웹 앱 URL'을 따로 복사해 두기.

### 4. 예상 질문 (FAQ)
*   **Q: '모든 사용자'에게 권한을 주면 위험하지 않나요?**
    *   A: URL을 모르는 외부인은 접근할 수 없으며, 지정된 형식의 데이터 추가 외에는 시트 수정이 불가능하므로 수업용으로는 안전합니다.

## [주제 6] Apps Script URL을 활동지에 연결하기

### 1. 핵심 메시지
복사한 URL을 코딩 없이 AI에게 전달하여 활동지와 시트를 연결합니다. 이것이 진정한 바이브 코딩의 실천입니다.

### 2. 구체 예시
*   **프롬프트:** "방금 발급받은 Apps Script URL은 `https://script.google.com/...`이야. 이걸 활동지 코드에 연결해서 제출 시 데이터가 시트로 전송되게 해줘."

### 3. 교사/학생 활동 지시문
*   **교사 활동:** AI에게 URL 연결을 시킨 후, 코드가 어떻게 바뀌었는지 설명해달라고 요청하여 작동 원리를 가볍게 이해해 보세요.

## [주제 7] 활동지 라이브 테스트 및 문제 해결

### 1. 핵심 메시지
실제 배포 전 테스트를 통해 데이터 전송의 안정성을 확보합니다. 실패할 경우 AI에게 에러 메시지를 보여주고 즉시 수정합니다.

### 2. 구체 예시 (장애 대응)
| 증상 | 원인 | 처방 |
| :--- | :--- | :--- |
| 데이터 안 들어옴 | 배포 권한 설정 오류 | '모든 사용자'로 재배포 |
| 한글 깨짐 | 인코딩 설정 미흡 | AI에게 "JSON.parse 확인해 줘" 요청 |

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 2~3개의 가짜 데이터를 입력해 보고 구글 시트에 행이 실시간으로 추가되는지 확인하세요.
*   **학생 활동:** (현장) 칠판의 QR코드를 스캔하여 모바일 기기로 활동지에 접속해 보세요.

## [주제 8] 수집 데이터의 AI 분석 및 환류

### 1. 핵심 메시지
수집된 데이터는 단순 보관용이 아닙니다. AI를 통해 시각화된 리포트를 만들고 이를 다음 수업의 피드백으로 활용하여 교육적 가치를 극대화합니다.

### 2. 구체 예시
*   **분석 요청:** "수집된 `responses.csv` 파일을 분석해서 학생들의 공통적인 오개념을 찾아내고 시각화 리포트를 HTML로 만들어줘."

### 3. 교사/학생 활동 지시문
*   **교사 활동:** 분석된 결과(Excel의 요약 라벨 등)를 바탕으로 다음 차시 모둠 구성을 어떻게 변경할지 기획해 보세요.
*   **학생 활동:** 전체 응답을 요약한 키워드 클라우드를 보며 우리 반의 생각을 공유해 보세요.

## [주제 9] 학교 업무 응용 및 확장

### 1. 핵심 메시지

### 2. 구체 예시
*   **학부모 상담:** 상담 전 사전 설문을 모아 AI로 요약하여 상담 전략 수립.
*   **수행평가:** 서술형 응답을 AI가 1차 채점하고 교사가 검수하는 시스템 구축.

### 3. 교사/학생 활동 지시문
*   **교사 활동:** "이 시스템을 우리 학교의 어떤 업무에 적용하면 좋을까?"를 주제로 동료 교사와 브레인스토밍해 보세요.

## 📖 용어 사전 (Glossary)

*   **Skill (스킬):** Claude Code에서 특정 작업을 수행하기 위해 패키징된 전문 지식 및 도구 모음.
*   **presentation-builder:** 텍스트 명령으로 HTML 기반 발표 자료를 생성하는 전용 스킬.
*   **activity-sheet-builder:** 인터랙티브 활동지를 만들고 구글 시트와 연동해 주는 스킬.
*   **Vibe Coding (바이브 코딩):** 코드를 직접 쓰지 않고 의도 전달과 대화만으로 개발하는 차세대 개발 방식.
*   **doPost(e):** 외부 웹 페이지에서 보낸 데이터를 Apps Script가 받아 처리하는 입구 역할을 하는 함수.
*   **정적 웹 앱 (Static Web App):** 서버 측의 복잡한 연산 없이 HTML, CSS, JavaScript만으로 구동되는 가벼운 웹 애플리케이션.
