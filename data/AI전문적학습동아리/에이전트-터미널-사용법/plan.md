# 에이전트 터미널 사용법과 활용 · 덱 계획 (영상용)

> 스페이스기전 데스크(교사판)·학생판 독의 «에이전트 터미널»을 처음 쓰는 선생님을 위한 영상 덱이다. 기능을 여는 법에서 그치지 않고
> «에이전트에게 무엇을 어떻게 시키면 수업과 업무가 편해지는가»까지 실제 실행 화면으로 보여 준다. 덱을 만든 뒤 자막만 들어간 mp4로 내보낸다.

## 실화면 사용 방식

- **터미널 화면(B-*)**: node-pty 가상 터미널에서 실제 `claude`·`codex`를 돌리고 xterm.js로 1920×1080에 그린 진짜 화면이다. 덱의 «화면 틀»에 넣고 단계마다 확대한다(터미널 글자는 작으므로 확대가 필수). 녹화 클립(B-01·B-02 등)은 움직임이 필요한 장에서만 쓴다.
- **독·패널(A-*)**: NEIS_helper `app/web`의 실제 독·패널을 가짜 응답으로 렌더한 화면이다. 패널 캡처는 패널만 잘린 크기라 «화면 틀» 대신 덱 위에 직접 크게 놓고 강조한다. A-12는 1920×1080 바탕화면 합성.
- **설치 창**: 실제 설치를 다시 돌리지 않았으므로, `agent.py install_text()`의 문구를 그대로 쓴 PowerShell 창 목업으로 그린다(4장). 목업이라는 점을 노트에 적는다.
- **화면에서 알아 둘 것**(tour.md): 완료 화면 입력칸의 흐린 글은 Claude Code의 «다음 요청 제안»이다 / 경로가 임시 폴더라 길다 / Claude Code 화면 문구는 영어, 답은 한국어 / 모델 표시(«Opus 5.5 · Claude Max»)는 이 PC 계정 기준이며 선생님 계정에 따라 다르다 / B-02는 이 PC에 깔린 추가 도구 때문에 권한 확인이 12번 나왔다(선생님 PC에서는 더 적다).
- **피할 것**: claude.ai 문서를 만든 B-03 첫 시도 화면(쓰지 않음), 실제 개인정보(연습 폴더는 «학생01»~«학생30»·«교사A~D» 가짜 데이터만).

## ELI5 적용 원칙 (이 수업 기준)

외부 ELI5 스킬(https://github.com/DreambigOu/ELI5)의 원칙을 **에이전트를 처음 다루는 교사**에 맞게 적용한다(보정 표의 «교사(연수)» — 동료에게 말하듯, 교실·업무에서 가져온 비유, 설계 의도와 한계까지).

1. **구조**: 장마다 자막이 ① 지금 하는 일 ② 조작 ③ 그래서 선생님에게 무엇이 편해지는가/무엇을 조심하는가 순서. 마지막 자막이 so what.
2. **어휘**: 단추·화면 문구는 원문(영어 화면은 원문 + 우리말 뜻). «에이전트·터미널·프롬프트·샌드박스·권한»은 처음 나올 때 한 문장 풀이. 개발 내부 용어(PATH, pty, MCP)는 쓰지 않는다.
3. **비유**: 학교 업무에서 가져온다(조수에게 업무 지시·결재·교무수첩·학습지 원본). 비유는 화면 라벨을 대체하지 않는다.
4. **문장**: 자막 한 줄에 생각 하나, 완결 문장. 주어는 «선생님» 또는 생략.
5. **어조**: 과장 없이 차분하게. «에이전트가 다 해 준다»가 아니라 «초안을 빨리 만들고, 확인은 선생님이 한다».
6. **정확성**: 수치·문구는 사실 관계 표만. 이 PC 기준 실측값은 «이 PC에서 약 ○초»로. 단순화한 자리는 노트에 «실제로는 …».
7. **분량**: 한 장에 새 용어 셋 이하.

## 영상·자막 공통 설계

- 자막 띠: 화면 아래 130px, 짙은 먹색 반투명 위 흰 글자 33px, 최대 두 줄. 화면 틀·도형은 침범 금지.
- 자막 시각: walkthrough·scene은 `[{at, text}]`, build는 단계마다 한 줄.
- 장 머리: 왼쪽 위 장 표시(예: «② 준비 · 2/4») + 헤드라인.
- 화면 틀: 1404×790(x 250 · y 142) 기본, 왼쪽 여백에 단계 칩 열, 오른쪽 여백에 «우리말 뜻» 칩(영어 화면 문구 번역).
- 장면 길이: walkthrough 13~18초, build 단계당 4~6초, scene 12~16초. 마지막 자막 뒤 2초.

## Slide 1 — 답해 주는 AI, 일해 주는 AI
- form: scene
- scene: metaphor: 왼쪽 «상담 창구»(말풍선이 오가는 채팅 창)와 오른쪽 «내 책상»(폴더 위에서 파일이 실제로 생기고 바뀌는 탐색기)이 같은 요청 한 줄을 받는 대비 | emotion: 호기심 | intent: 챗봇과 에이전트의 차이를 15초 안에 체감시킨다
- 장 표시: ① 시작하며

**핵심 메시지:** 챗봇은 답을 말해 주고, 에이전트는 선생님의 폴더에서 파일을 직접 읽고 만들고 고친다.

**형태 설계:** 가운데 위에 같은 요청 한 줄 «설문응답.csv를 요약해서 파일로 저장해 줘»가 타이핑된다(t0~3). 왼쪽 작은 채팅 창: 답 문단이 생기지만 «파일은 직접 저장해 주세요» 꼬리(t3~8). 오른쪽 큰 칸(dominant): 실화면 B-02 완료 화면 조각 + 폴더 목록에 «설문 결과 요약.md»·«설문 결과 그래프.html»이 새로 생기는 애니메이션(t3~10). t10~14 오른쪽 아래 «읽기 → 계획 → 허락 → 만들기» 네 칸 띠. 헤드라인 «답해 주는 AI, 일해 주는 AI»(킥커 «에이전트 터미널 사용법과 활용»).

**자막:**
- (0s) 에이전트 터미널은 선생님의 폴더에서 AI 에이전트를 여는 기능입니다.
- (3s) 챗봇은 답을 말해 주지만, 파일을 만들고 정리하는 일은 선생님 몫으로 남습니다.
- (7s) 에이전트는 폴더의 파일을 직접 읽고, 새 파일을 만들고, 고칩니다.
- (11s) 대신 무엇을 할지 먼저 말하고, 선생님이 허락하면 진행합니다.

**발표자 노트:** 같은 요청 한 줄이 왼쪽 채팅 창에서는 답 문단으로, 오른쪽 폴더에서는 실제 파일 두 개로 끝납니다. 에이전트는 «내 책상에 앉아 일하는 조수», 챗봇은 «전화 상담 창구»라고 생각하면 됩니다. 실제로는 에이전트도 같은 종류의 AI 모델을 쓰지만, 파일을 읽고 명령을 실행하는 도구를 쓸 수 있다는 점이 다릅니다. 선생님이 할 일은 «무엇을 맡길지»와 «결과가 맞는지»를 정하는 것입니다.

## Slide 2 — 이 영상의 길
- form: build
- 장 표시: ① 시작하며

## 저작 기록 (2026-10-16)

- **실화면**: 독·패널(A-*)은 NEIS_helper `app/web`의 실제 독·패널을 가짜 응답으로 렌더한 화면, 터미널(B-*)은 node-pty 가상 터미널에서 실제 Claude Code 2.1.301·Codex 0.155.1을 돌려 xterm.js로 그린 화면이다(`reference/tour.md`). 연습 폴더에는 가짜 데이터만 넣었다(«학생01»~«학생30», «교사A~D»). 덱은 쓰는 컷만 `screens/`(jpg)로 둔다. 결과 파일 화면(`R-설문그래프`, `R-퀴즈-*`)은 실제로 만들어진 html을 브라우저로 찍었다.
- **클립**: 13장은 `reference/B-01-파일정리.mp4`의 세 구간(승인 입력 · 권한 확인 · 완료)을 이어 붙인 `media/c13-approve.mp4`(17.5초). 16장은 원본이 278초로 길어 스틸로 만들었다.
- **설치 창(4장)**: 실제 설치를 다시 돌리지 않았으므로 `agent.py install_text()` 문구 그대로의 목업이며, 화면에 그렇게 표시했다.
- **촬영 중 생긴 일**: B-03 첫 시도에서 Claude Code가 이 PC 계정의 커넥터로 claude.ai 비공개 문서 «학습지 초안»을 만들었다(덱에는 쓰지 않음, 삭제 여부는 사용자 결정). 이후 촬영은 로컬 파일만 만들도록 막았다. 이 PC의 Claude Code 기본 모드가 auto라 교사 PC 첫 설치와 같은 화면을 보이려고 `--permission-mode default`로 찍었다.
- **포인터 검산**: 실화면이라 `measure_pointer.mjs` 대신 원본 이미지에서 잰 좌표를 덱 좌표로 바꾸고 캡처로 확인했다. 터미널은 키로 고르는 화면이라 포인터 대신 키 칩(↓·Enter·1)으로 보였다.
- **화면에 남은 것**: 터미널 머리의 경로가 임시 폴더라 길고(사용자 폴더 이름이 보임), 모델 표시(«Opus 5.5 · Claude Max»)는 이 PC 계정 기준이다. 노트와 칩에 «선생님 계정에 따라 다름»을 밝혔다.
